# Справочник

[Каталог классов](classes.md) содержит все 784 известных имени, class ID и платформы: [373 типа движка](engine-classes.md) и [411 игровых типов](game-classes.md). Ссылки ведут к имеющимся карточкам и общим исходникам.

Регистрационная база и физическое C++-наследование различаются. Само присутствие класса в каталоге не означает полного описания его методов. В карточках отдельно указаны layout, поля serializer, поведение и неизвестные части.

Машиночитаемый реестр: [classes.json](classes.json). Навигация по всем карточкам и тематическим статьям: [полный каталог](../catalog.md).
