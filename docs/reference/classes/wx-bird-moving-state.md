# `wxBirdMovingState`

`wxBirdMovingState` (Class ID `1D533B00`) — потомок `wxCharacterState` с selector `0`. [Общая реализация](../../../Winx/Code/wxBirdMovingState.cpp) сохраняет собственные hooks PC/PS2. Исходный размер — `44` на обеих платформах: word `3C` первоначально равен `0`, byte `40` — `1`. Здесь они описаны как счётчик повторов и флаг необходимости playback по их использованию. Переносимый layout не является игровым ABI.

| Операция | PC | PS2 |
| --- | ---: | ---: |
| Фабрика | `402C60` | `3F3BA0` |
| Vtable | `6F8948` | `49A300` |
| Вход, PC slot `1C` | `517E60` | `2E5800` |
| Обновление, PC slot `30` | `517E90` | `2E55F0` |
| Обработка события, PC slot `3C` | `517F70` | `2E5570` |

Вход устанавливает word `3C` в `0`, byte `40` в `1`, затем вызывает вход [wxCharacterState](wx-character-state.md). База освобождает pending handle и вызывает виртуальное обновление `30`. Выход и остальные hooks используют общую базу.

Обновление при byte `40 != 0` готовит и запускает анимацию. Если счётчик ненулевой, RNG не вызывается и ключ сохраняется до общей маски `FF9FFFF0`. При нулевом счётчике первый unsigned RNG draw по модулю `3` выбирает ветвь:

| Остаток | Изменение ключа | Изменение счётчика |
| ---: | --- | --- |
| `0` | `key &= F07FFF8F` | Остаётся `0` |
| `1` | `(key & F0FFFF8F) \| 00800000` | Остаётся `0` |
| `2` | `(key & F07FFFDF) \| 50` | Второй RNG draw: `(draw & 3) + 1` |

Во всех ветвях затем применяется `FF9FFFF0`. Lookup, сброс completion-записей и playback идут без сравнения или освобождения старого handle; режим — `false`, interrupt — `true`. После playback сохраняется handle и очищается byte `40`.

При byte `40 == 0` обновление запрашивает completion с потреблением записей, включая пустой handle. Только при завершении устанавливает byte `40` и уменьшает ненулевой счётчик на один. Новый playback выполняется в следующем обновлении, а не в той же ветви. Базовый reset не изменяет word `3C` и byte `40`.

Событие читает имя через `event+1C -> tag+10`. Точное имя `event_jump` вызывает owner-службу PC `5296C0` / PS2 `2E6D00`, `event_land` — PC `529090` / PS2 `2E6CF0`. Другие имена ничего не вызывают. На PC сравниваются 11 байт, включая завершающий ноль; на PS2 используется строковое сравнение. Copy пуст и унаследован от `spBaseObject`; clone получает начальные поля и пустые привязки. Деструктор не останавливает анимацию.

[wxBirdMovingStateHost](../../../Winx/Analysis/Host/wxBirdMovingStateHost.h) предоставляет оригинальный RNG, имя события и две owner-службы. Собственный RNG не подменяет игровой. Полные эффекты jump/land находятся за обязательным host-контрактом без успешных заглушек. [C++ проверка](../../../Winx/Tests/wxBirdMovingStateTests.cpp) охватывает цикл playback/completion, счётчик, число RNG draws, clone и точное сравнение тегов. Полная игровая сцена остаётся внешней зависимостью.
