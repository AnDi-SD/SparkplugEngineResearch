# wxVineClimbingState

Class ID `40280331`, физическая и регистрационная база `wxCharacterState`.
Native размер PC/PS2 — `3C`, selector — `16`; собственных полей после базы
нет. Конструктор, RTTI/factory, fresh clone и собственные state hooks находятся
в `Winx/Code/wxVineClimbingState`. Copy и Reset наследуются от базы.

Update `30` читает два угла из owner entity (`158/15C` PC, `164/168` PS2),
затем движение из прямого control (`owner12C/138`, float word `4`). При
движении `< 0.2f` обнуляет направление. Иначе проверяет условия по порядку:

| Условие | Направление в key bits `70` |
| --- | --- |
| Первый угол `<= pi/4` | `10` |
| Первый угол `>= 3*pi/4` | `20` |
| Второй угол `>= 3*pi/4` | `30` |
| Второй угол `<= pi/4` | `40` |
| Ни одно условие | `0`, затем обнуление control word `4` |

PC верхняя граница — произведение float32 `3F490FDB` на `3` без float32 spill;
PS2 использует отдельную константу `4016CBE4`. После выбора update применяет
маску `F007FFFF`, выполняет animation lookup, при изменении handle освобождает
pending и запускает mode=true, interrupt=true. Совпадение handle пропускает
playback. PC сохраняет поведение unordered-сравнений; PS2 профиль ограничен
конечными входами и signed zero.

Первый вход `1C` подготавливает movement cache без сброса найденного node,
применяет `(key & FFA7807F) | 00200000`. Ненулевой byte `50` прямого control
выбирает направление `20`, вызывает общую turn-службу, выставляет flag
entity-control (`178` PC / `184` PS2), поворачивает owner node на pi вокруг
оси `(0,1,0)` и вызывает node hook с аргументом `0`. Нулевой byte выбирает
направление `10`. Затем маска `F07FFFFF`, lookup и mode=false playback
**без освобождения старого pending**, запись handle и очистка once flag `1C`.
Завершение движения в этой фазе использует только вертикальную составляющую,
затем обнуляется прямой control word `4`; результат false.

Повторный вход потребляет completion. При завершении обнуляет entity flag,
подготавливает movement и вызывает базовый вход с виртуальным update.
При незавершении выполняет вертикальное завершение движения и очистку control.

Первый выход `20` освобождает pending, подготавливает movement и выставляет
entity flag. Key получает `(key & FFDFFFFF) | 00400000`. Ненулевой прямой
byte `50` выбирает направление `10`. При нулевом byte читает две высоты
entity-control (`130/1EC` PC, `13C/1F8` PS2):

- При разности `<= 50` выбирает направление `20`, применяет `F07FFFFF`,
  запускает mode=false, interrupt=true, сохраняет handle, очищает flag `1E`,
  завершает полное движение и обнуляет прямой control word `4`. Результат false.
- При разности `> 50` обнуляет entity flag, вызывает reset-службу control,
  перемещает owner node на `-20` вдоль его оси и вызывает node hook с `0`.
  Затем сразу возвращает результат базового выхода. Эта ветвь сохраняет
  once flag `1E`, исходные bits направления и прямой control word `4`;
  animation lookup и завершающий movement helper не вызываются.

PC сравнивает разность высот в x87 binary80. Host-функция
`HeightDifferenceAbove50ForAnalysis` отдельно сохраняет проверенную границу
для nearest-even с 64 значащими битами: при `50 - (-2^-58)` ветвь ранняя,
при `50 - (-2^-59)` разность округляется к `50`. Это узкая численная модель,
не универсальная эмуляция x87. PS2 сохраняет float32 subtraction.

Повторный выход потребляет completion. При завершении обнуляет entity flag,
подготавливает movement и возвращает базовый выход; иначе завершает полное
движение и очищает прямой control. Permission `34` наследует true.

Заимствованные owner, consumer, actor control и node подключаются через
`wxVineClimbingStateHost`. Общий movement cache остаётся в базе состояния;
turn preparation, reset-служба, node rotation/translation и virtual hook
имеют явные внешние границы. PS2 matrix/accumulator операции раннего выхода
требуют отдельного квалифицированного host и не заменяются PC-арифметикой.
Полная игровая сцена и эти внешние службы ещё не закрыты. Наличие исходников
означает восстановление описанной собственной логики, а не полную готовность
класса в игре. Проверка — `WinxVineClimbingStateTests`.
