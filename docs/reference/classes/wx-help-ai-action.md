# wxHelpAIAction

`wxHelpAIAction` (`0x67435487`) зарегистрирован с базой
[`wxAIAction`](wx-ai-action.md). [Переносимая реализация](../../../Winx/Code/wxHelpAIAction.h)
содержит ограниченный PC-вход действия. Исходные имена методов и файлов неизвестны.

## PC-вход

Объект занимает `0x468` байт; базовая часть — `0x3A8`.
[Независимый PC32 layout](../../../Winx/Analysis/PC/wxHelpAIActionAbi.h)
не накладывается на переносимый C++ объект. Собственные байты `3A8..467`
передаются как явное состояние после создания; указатели из этого снимка
не превращаются в переносимые указатели или новые владельцы.

Вход читает owner из `+20`, actor из `owner+144`, command из `actor+130`.
Затем последовательно записывает:

1. word `command+4 = 0`;
2. byte самого действия `+3AC = 0`;
3. word самого действия `+460 = 0`.

Другие собственные байты, длительность `+370` и word `+374` сохраняются.
Command уже захвачен до первой записи. Изменение привязок owner/actor/command
на этой границе не меняет адрес текущей записи; следующий вход читает привязки
заново. Метод не вызывает helpers и не использует свой стековый аргумент.
Нулевой EAX не интерпретируется как восстановленный boolean return.

[Host-протокол](../../../Winx/Analysis/Host/wxHelpAIActionHost.h) предоставляет
только заимствованное хранилище и явно разрешённый профиль. По умолчанию профиль
не разрешён. Missing owner/actor/command и непустой граф дочерних действий
дают аналитический отказ, а не модель native fault или rollback.

Открыты исходные типы owner/actor/command, остальная семантика собственных
полей, полный constructor, Copy/Clone, notification, другие hooks, холодный
запуск и gameplay. Native lifecycle служит отдельным подтверждением типа
receiver; переносимый destructor не воспроизводит весь native lifecycle.
Существование класса на PS2 не переносит на неё PC layout или этот профиль.
