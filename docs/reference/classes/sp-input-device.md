# spInputDevice

Общий слой сопоставления логических команд физическим кодам устройства.
Class ID `0x4C615DE6`, регистрационная база `spCrossPlatform`, присутствует
в PC и PS2. Обе регистрации имеют нулевой factory; Clone возвращает null.
Физический объект содержит именованный префикс, вторичный интерфейс в `+14`,
два списка по 12 байт в `+18` и `+24` и пять рабочих слов в `+30..+43`.
Реконструкция хранит пары в переносимом контейнере и отдельно отмечает
неинициализированные рабочие слова; соответствие host ABI не заявляется.

PC append `004D69D0` добавляет пару `(physical, logical)` в конец активного
списка. Clear `004D66E0` удаляет его элементы, сохраняя рабочие слова.
Обёртки сначала обходят весь активный список и записывают физические коды
всех совпавших пар в рабочие слова в исходном порядке. Дубликаты сохраняются.
Неиспользованная часть рабочих слов не очищается.

| Вторичный slot | Поведение | PC | PS2 |
| --- | --- | --- | --- |
| 1 | Логическое OR с остановкой после первого true | `004D67A0` | `0016CCE0` |
| 2 | То же для второго запроса | `004D6800` | `0016CBD0` |
| 3 | Запрос только первого физического кода; при отсутствии пары 0 | `004D6860` | `0016CAE0` |
| 4 | Второй целочисленный запрос первого кода; при отсутствии пары 0 | `004D68B0` | Не установлен |
| 5 | Первый код и ещё три 32-битных аргумента; без пары вызов пропускается | `004D6900` | `0016C9D0` |
| 6 | Float-запрос первого кода; без пары `+0.0` | `004D6960` | `0016C8E0` |

Рабочая область принадлежит объекту. Вложенный запрос из callback может
перезаписать коды, которые продолжит читать внешний Boolean-запрос.
Изменение самого списка из callback происходит после сбора кодов и не
меняет уже сохранённую последовательность.

Оригинал не ограничивает число совпадений пятью: шестая запись выходит за
установленную рабочую область. Переносимая реализация явно отклоняет этот
домен до изменения состояния. Отсутствующий callback при непустом
сопоставлении также возвращает аналитическую ошибку. Это наши проверки
допустимости, а не восстановленные fallback игры.

Физические запросы передаются через явно обозначенную host-границу.
Опрос ОС и конкретных устройств не входит в этот класс. Создание, удаление
и переключение именованных групп второго списка пока не восстановлены;
полное состояние подсистемы ввода этим файлом не закрывается.
