# wxCharacterStateMachine

`wxCharacterStateMachine` зарегистрирован с Class ID `D32F3AA1` и базой
`wxEntity` на PC и PS2. Его физическая база также `wxEntity`. Переносимая
реализация находится в [wxCharacterStateMachine.h](../../../Winx/Code/wxCharacterStateMachine.h)
и [wxCharacterStateMachine.cpp](../../../Winx/Code/wxCharacterStateMachine.cpp).
База `wxEntity` восстановлена частично, но полная привязка к сцене не установлена;
поэтому переносимый класс хранит
подтверждённый протокол собственных полей отдельно от 32-битного ABI и
обращается к игровому observer через обязательный
[host](../../../Winx/Analysis/Host/wxCharacterStateMachineHost.h).

| Свойство | PC | PS2 |
| --- | ---: | ---: |
| Размер | `224` | `230` |
| Factory | `4016A0` | `3F75A0` |
| Constructor | factory path | `2B48D0` |
| Vtable | `6F6680` | `49B490` |
| Вход в состояние | `4FABA0` | `2B40B0` |
| Reset | `4FAC00` | `2B3D80` |
| Выбор следующего | `4FAD70` | `2B3F70` |
| Push / pop | `4FAF30` / `4FACE0` | inline в `2B4100` / `2B4010` |
| Code → mode | `4FAC50` | `2B3D20` |

[PC layout](../../../Winx/Analysis/PC/wxCharacterStateMachineAbi.h) и
[PS2 layout](../../../Winx/Analysis/PS2/wxCharacterStateMachineAbi.h) фиксируют
смещения, а не размер переносимого C++ объекта. Конструктор задаёт kind `68`,
current/previous/data/depth/mode = `0`, gate = `1`, last byte flag = `1` и
обнуляет 42 слота состояний. Два стека по пять слов лежат после этих слотов;
неизвестные native bytes не объявляются нулевыми.

Вход вызывает slot 7 текущего `wxCharacterState` с адресом current data;
успешный ответ очищает gate. Reset обнуляет индексы и data, depth и mode,
ставит gate `1`, прямо вызывает slot 7 состояния 0 и затем ставит last flag
`1`. Этот прямой вызов **не** очищает gate. Выбор следующего сохраняет previous
state/data, вызывает slot 19 с next data, переносит data, сообщает `0x2720`,
после уведомления ставит gate `1`, включает три флага выбранного состояния
и пытается войти. Базовый slot 19 выбирает состояние 0; потомки могут выбрать
другое. Push сохраняет state/data и сообщает `0x2722` до suspend и выбора;
pop восстанавливает сохранённую пару, очищает gate и сообщает `0x2723` до
resume. Code→mode задаёт `0→0`, `1→5`, `3→6`; другие проверенные коды не меняют
mode. Slot 11 допускает flags, только если `(flags & 0x18) == 0`.

Уведомления `0x1C` и `0x1E` передаются внешним update-обработчикам, чьи тела
пока не установлены. `0x27F3` вызывает Reset; прочие сообщения передаются
текущему состоянию, если оно есть. Observer, состояния и scene binding
передаются снаружи. Работа с ними не выдаётся за восстановление всей игровой
сцены. Переносимый clone ограничен исходным состоянием: Copy изменённой машины
не проверен. Методы push/pop исследованы только для допустимых глубин `0/4`
и `1/5`; защиту перед индексированием в оригинальных локальных телах не
обнаружили. Переносимый вызов отклоняет выход за пределы этих массивов как
нарушение ещё не установленной предпосылки вызывающего кода.

Проверка `WinxCharacterStateMachineTests` сравнивает поля и порядок событий
switch/push/pop/reset с сохранёнными PC сценариями и проверяет независимые
PS2 размеры и адреса. Исходная матрица содержит 35 PC и 33 парных PS2 случая;
PS2 push установлен статически, а часть callback-ветвей проверена только до
границы исходного consumer. Тяжёлый tick, нормальные привязки владельца,
живые observer и Copy изменённого объекта остаются открытыми.
