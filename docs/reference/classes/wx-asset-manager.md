# wxAssetManager

Восстановленная часть игрового менеджера путей к ресурсам: выбор языка, две индексные таблицы каталогов, сборка пути и открытие файлового потока. Общий код: [wxAssetManager](../../../Winx/Code/wxAssetManager.h). Внешние службы реестра, приложения и потоков заданы через [host](../../../Winx/Analysis/Host/wxAssetManagerHost.h).

## Идентичность и размещение

Оба executable содержат имя `wxAssetManager`, Class ID `0x46E341B9` и прямую регистрацию от `spBaseObject`. Factory выделяет `0x180` байт. У объекта есть вторичная vtable singleton support по `+0x10`; переносимый C++ класс её не воспроизводит. [PC](../../../Winx/Analysis/PC/wxAssetManagerAbi.h) и [PS2](../../../Winx/Analysis/PS2/wxAssetManagerAbi.h) фиксируют подтверждённые смещения: root `+0x14`, language mode `+0x18`, language directory `+0x1C`, 19 указателей категорий с `+0x20`, 69 указателей подкатегорий с `+0x6C`. Factory публикует singleton; деструктор безусловно обнуляет его. Clone создаёт новый пустой менеджер и использует унаследованный Copy, не переносит root и таблицы.

## Инициализация

Режим языка `1/2/3/4` задаёт соответственно `French\\`, `German\\`, `Italian\\`, `Spanish\\`; прочие значения дают `English\\`. PS2 выставляет корень `data\\`. PC получает `MediaPath` из 32-битного вида `HKLM\Software\Konami\Winx Club`, затем читает `LanguageID`: точные значения `1036`, `7`, `16`, `10` устанавливают режимы `1`, `2`, `3`, `4`, прочие допустимые значения — `0`. Если значение `LanguageID` отсутствует или превышает буфер, остаётся прежний режим приложения. Результат успешного чтения передаётся настройкам приложения и обновляет языковой каталог. При отсутствующем или слишком длинном PC `MediaPath` оригинал завершает процесс; переносимая реализация сообщает об этом исключением.

Категории имеют диапазон `0..18`, подкатегории — `0..68`. Пустые и повторяющиеся записи сохраняются по исходным индексам. Например, category `1` — `Levels\\`, `3` — `Sounds\\`, `5` — `Movies\\`, `7` — `Voices\\`, `13` — `Fonts\\`, `17` — `OneLiners\\`; subcategory `51` — `Location\\`, `68` — `SUBTITLE\\`. Таблицы в C++ сверены с записями конструктора PC `0x00593240` и PS2 `0x002785D0`.

## Путь и поток

Сборка конкатенирует `root + category + subcategory + optional language directory + filename` без нормализации разделителей. Подкатегория пропускается только при `category=3, subcategory=51`. Язык добавляется при `category=3, subcategory=51`; при `category=5` или `13`, кроме `subcategory=68`; и всегда при `category=7` или `17`. Проверка вместимости строгая: длина без завершающего NUL должна быть меньше capacity. Открытие использует capacity `0x12C`, режим потока `1` или `2`; неудача открытия сообщает путь и освобождает поток.

Нативный код индексирует таблицы без проверки границ и требует валидный root. Переносимый метод возвращает `false` для неинициализированного объекта или индекса вне таблиц; выходная строка в этих случаях не меняется. Возвращаемый `unique_ptr` владеет созданным host-потоком.

## Границы

Асинхронная загрузка и регистрация связанных ресурсов проходят через другие подсистемы и здесь не заявлены как восстановленные. Имена методов `ForAnalysis`, представление строк и host-интерфейс аналитические. PC реестр и PS2 корень принадлежат разным платформенным ветвям, а реконструкция пути общая.
