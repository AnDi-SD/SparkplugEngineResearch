# wxBacoAttackAIAction

`wxBacoAttackAIAction` — действие `wxAIAction` с class ID `013B1195` на PC и PS2. [Переносимый класс](../../../Winx/Code/wxBacoAttackAIAction.h) реализует проверенные поля, Copy/clone, вход, выход и запрос смены действия. [Host](../../../Winx/Analysis/Host/wxBacoAttackAIActionHost.h) предоставляет игровые команды, registry, восприятие и границу активных обработчиков состояний. Физические представления описаны отдельно для [PC](../../../Winx/Analysis/PC/wxBacoAttackAIActionAbi.h) и [PS2](../../../Winx/Analysis/PS2/wxBacoAttackAIActionAbi.h).

| Свойство | PC | PS2 |
| --- | --- | --- |
| Размер / vtable | `3CC` / `7099E8` | `3D0` / `4923C0` |
| Factory | `5B82A0` | `244C70` |
| Copy / clone | `5B8210` / `5B8340` | `2446E0` / `244B80` |
| Цель, состояние, следующие слова и byte | `3A8`, `3AC`, `3B0..3B8`, `3BC` | `3AC`, `3B0`, `3B4..3BC`, `3C0` |

После PC factory цель равна null, состояние — `4`, слова `3B0/3B4` — нулю, слово `3B8` содержит биты `0.03f` (`3CF5C28F`), byte `3BC` равен нулю. Хвост `3BD..3CB` конструктор PC не заполняет. Данные PS2 подтверждают размер и смещение собственных полей; полное исполнение её конструктора не заявляется. `Copy` сначала очищает базовое состояние получателя, затем переносит пять собственных слов `3A8..3B8` и byte `3BC`. Clone создаёт новый объект и применяет `Copy`. Цель остаётся заимствованным указателем.

Вход (PC `5B8190`, PS2 `2447E0`) ставит command `1D=1`, берёт цель через registry lookup, записывает состояние `4`, float `90000` в `3B4/3B8`, обнуляет byte `3BC/3C0`, слово `3B0/3B4` и общее слово `354/358`. При пустой цели запрашивает у владельца действие key `1` с параметром `0`; запрос следует после записей. Выход обнуляет command bytes `1D`, затем `20`, и очищает только указатель цели. Запрос цели вызывает поиск ближайшей цели и при её отсутствии запрашивает key `1`, parameter `0`, не записывая результат поиска в действие. Уведомление класса пустое и не пересылает сообщение дочернему действию.

Диспетчер PC `5B88A0` и PS2 `2448A0` выбирает отдельные активные тела для состояний `0..4`, после чего возвращает true. Значение вне диапазона сбрасывает состояние в `0` и тоже возвращает true. Тела этих пяти обработчиков, в частности их движение, таймеры и анимация, пока не восстановлены: host получает номер состояния и обязан реализовать соответствующее поведение. Этот класс сам по себе ещё не завершает создание трёх действий в `wxBacoAIBehavior`.

Основа реконструкции: парные локальные контракты `ai-action-construction`, `ai-action-modified-copy`, `ai-attack-entry`, `ai-exit-cleanup`, `ai-perception-control` и исходные окна dispatcher. [Общий контракт wxAIAction](wx-ai-action.md) описывает базовый Copy и границы его реализации.
