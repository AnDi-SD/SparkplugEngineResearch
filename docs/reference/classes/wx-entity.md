# wxEntity

`wxEntity` имеет Class ID `796A1869`, регистрационную и физическую базу
[spEntity](sp-entity.md) на PC и PS2. Переносимый
[wxEntity](../../../Winx/Code/wxEntity.h) наследует общую базу. Явный
[wxEntityHost](../../../Winx/Analysis/Host/wxEntityHost.h) предоставляет
менеджеры, удаление и связанные игровые объекты. Native layout не
накладывается на переносимый C++ объект.

| Контракт | PC | PS2 |
| --- | ---: | ---: |
| Размер | `124` | `130` |
| Factory | `401110` | `3F8570` |
| Constructor | `4DA7C0` | `286CA0` |
| Vtable | `6F4EB8` | `49B8D0` |
| Copy | `4D9700` | `286AB0` |
| Расчёт флагов | `4DA930` | `286460` |

[PC ABI](../../../Winx/Analysis/PC/wxEntityAbi.h) и
[PS2 ABI](../../../Winx/Analysis/PS2/wxEntityAbi.h) фиксируют отдельные
размеры. Конструктор задаёт bytes `28=0`, `38=39=1`, `48=0`, `88=1`,
words `3C=4B095440`, `40=500`, `44=43160000`, `4C/50/54/74/78/7C/80/84=0`.
Два массива по 16 слов заполнены `7F7FFFFF`: PC с `8C` и `CC`, PS2 с `90`
и `D0`. Собственная область переносимой реализации использует аналитические
PC смещения; PS2 offsets после `8C` берутся из отдельного ABI, а не из
массива C++ объекта. Назначение непрозрачных полей не выводится из default.

Оригинальный factory вызывает добавление в engine-список, затем удаляет
объект из него и добавляет в game-список. После возврата объект есть только
в game-списке; удаление очищает списки. Эти операции выполняет host с
сохранением порядка. PC factory/default clone/delete были исполнены в игре;
PS2 constructor и vtable проверены отдельно.

Copy сначала вызывает parent Copy. При его отказе собственные поля не
меняются. При успехе он переносит только bytes `28/38/39` и word `3C`, затем
передаёт clone-manager hook с class hash `796A1869`. Другие указатели,
cached список, внутренние объекты и padding этим методом не копируются.
Изменённый источник проверен в оригинале на PC; PS2 собственный prefix
сопоставлен до границы исходного clone-manager consumer.

Расчёт флагов начинается с `FFFFFF00`. Ненулевой byte `38` и успех всех
cached predicates дают bit `2`; пустой список успешен, обход останавливается
после первого false. Ненулевой byte `39` и byte `40` оригинального timer
дают bit `8`. Если word `3C` равен `7F7FFFFF`, дистанционная часть
пропускается. Иначе квадрат расстояния больше порога даёт bit `10`;
равенство его не даёт. Переносимый host предоставляет сами predicates,
timer, квадрат расстояния и запись в связанный record. Для конечных входов
ветви PC/PS2 сопоставлены; обработка NaN/Inf и полный PS2 COP1 расчёт
не объявляются эквивалентными.

`WinxEntityTests` проверяет constructor, маршрут менеджеров, success/failure
Copy с побайтовой сохранностью остальных собственных полей, короткое
замыкание cached predicates, граничное расстояние и sentinel. Нормальная
scene binding, встроенные объекты, полный teardown и методы `spEntity`
остаются открытыми.
