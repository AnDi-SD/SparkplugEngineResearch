# spPS2InputDevice

Платформенная основа PS2: Class ID `0x48B004B2`, регистрационная и
установленная физическая база `spInputDevice`. Factory регистрации равен
нулю, Clone `001F0D70` возвращает 0. PC-класс `spDXInputDevice` имеет
отдельную identity и поля.

Конструктор `001F0D20` вызывает `spInputDevice` (`0016CFD0`), записывает
primary `004914F0`, secondary `00491514` в `+14` и byte `+44=0`.
Полное выравнивание и размер выделения для самостоятельной основы не
установлены; ABI-файл описывает только подтверждённый префикс.
Деструктор `001F0CB0` восстанавливает эти таблицы и вызывает общий
деструктор. Дополнительного release устройства в этой ветви нет.

Рабочие операции общего слоя описаны в [spInputDevice](sp-input-device.md).
Вызовы конкретных аппаратных интерфейсов, startup, polling и группы кодов
пока не восстановлены. Нулевые и неустановленные slots исходной основы
не превращаются в успешную имитацию устройства.

Исходники: [spPS2InputDevice.h](../../../Sparkplug/Code/SparkplugPS2/spPS2InputDevice.h),
[spPS2InputDevice.cpp](../../../Sparkplug/Code/SparkplugPS2/spPS2InputDevice.cpp).
