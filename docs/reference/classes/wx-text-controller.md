# wxTextController

`wxTextController` (Class ID `9F1535F7`) физически наследует
[spBaseObject](sp-base-object.md). PC factory `5A8790` выделяет `340` байт,
вызывает общий Base constructor и устанавливает vtable `707B20`; getter
`5A8620` возвращает registration record `766EF0`. Имена исходного файла,
методов и собственных полей неизвестны.

[Переносимый исходник](../../../Winx/Code/wxTextController.cpp) представляет
ограниченный Reset `5A8490` над явно переданным captured-состоянием.
Исходный factory не инициализирует собственные слова, поэтому обычный
zero-default constructor и factory в переносимом API не предоставлены.
Raw 32-bit слова не преобразуются в указатели host.

Reset обнуляет три диапазона по `54` слова (`220`, `118`, `28`) и четыре
группы по шесть слов (`100`, `208`, `1F0`, `10`). Последние `18` слов
`2F8..33C` сохраняются. Метод не вызывает других игровых функций,
не освобождает встреченные raw-значения и не изменяет Base-поля.
Собственный destructor `5A8630` вызывает этот Reset перед Base destructor.
Native offsets отделены в [PC ABI](../../../Winx/Analysis/PC/wxTextControllerAbi.h).

Семантика raw-связей, selection `5A85A0`, частично защищённый getter
`5A8540`, native factory/Clone с неинициализированными полями, произвольный
жизненный цикл, PS2 и игровая интеграция остаются открытыми. Наличие
определения класса не означает его полного восстановления.
