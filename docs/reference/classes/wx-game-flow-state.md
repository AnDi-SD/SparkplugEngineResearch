# wxGameFlowState

Описание отдельных известных частей класса. Наличие карточки не означает полного восстановления всех методов.

## Восстановленная часть

Общая реализация — [wxGameFlowState.h](../../../Winx/Code/wxGameFlowState.h)
и [wxGameFlowState.cpp](../../../Winx/Code/wxGameFlowState.cpp). Portable API
сохраняет подтверждённые поля PC-конструктора, sentinel setter, последовательный
getter, шесть пустых/true hooks, таблицу ресурсов и условное переназначение кодов.
Имена методов с `ForAnalysis` и размещение исходников являются аналитическими.

PC-конструктор получает borrowed input из member `18` внешнего singleton,
создаёт собственный [spTaskTimer](sp-task-timer.md), вызывает Reset и Start,
затем сбрасывает глобальную таблицу. Внешние singleton/clock/storage задаёт
обязательный [host](../../../Winx/Analysis/Host/wxGameFlowStateHost.h).
Готовность singleton и делитель часов не выводятся из поведения host.
Нулевой делитель отвергается portable guard до сброса таблицы.

Собственный Copy наследует действительный no-op `spBaseObject`: поля
назначения, его таймер и input сохраняются. Clone создаёт новое состояние,
заново получает input, запускает отдельный таймер и повторяет глобальный
сброс; время, коды и runtime source не переносятся. Destructor освобождает
свой таймер и не освобождает borrowed input. Нативные padding и word `28`,
которые конструктор не пишет, не получают придуманных нулевых значений.

PS2-конструктор дополнительно загружает три текущих global word; portable
конструктор квалифицируется только для PC. PS2 setter/getter и шесть
листовых hooks рассматриваются отдельно от полного PS2 lifecycle.

Setter независимо пропускает каждое значение `FFFFFFFF`; это sentinel, а
не безусловная запись всех трёх аргументов. Getter читает и записывает три
слова последовательно, сохраняя порядок при совпадении выходных адресов.

Сброс PC-таблицы переносит все 56 source pointers. Элемент source `39`
становится destination `26`, source `26..38` — destination `27..39`;
остальные индексы сохраняются. Затем обнуляются 56 cache pointers без вызовов
их освобождения. В portable storage источники, назначения и cache раздельны;
загрузка STX и владение ресурсами этим сбросом не восстанавливаются.

Переназначение кодов реализовано с явными входами lower-state и signed word
профиля `514`; правила приведены в
[описании game flow](../../game/flow/game-flow-navigation-remap.md).
Получение состояния контроллера и активная навигация между HUD-объектами
остаются отдельными операциями. Полный класс и игровой сценарий меню открыты.

## Конструктор, владение и clone

Destructor удаляет owned timer`2C` через его virtual deleting destructor,
обнуляет`2C`, вызывает base cleanup. Borrowed`30` не освобождается. PC wrapper
освобождает память состояния при `flags &1`. PS2 освобождает её при
**положительном signed16 значении аргумента** и отдельно допускает null this.
Разница native ABI сохранена; это не общий boolean-контракт.

## Листовые операции

Шесть собственных virtual hooks базового класса — действительные пустые методы:
два возвращают true, четыре выполняют return без значения. На PC это slots
`1C..30`, addresses `5A7DB0 /5B7A00`; на PS2 slots`24..38`, addresses
`33C2D0 /33C2C0 /33C2B0 /33C2A0 /33C290 /33C280`. PS2 имеет два header words
перед первым function pointer. Все шесть PS2 leaves исполнены. Для void hooks
случайное содержимое return register не получает семантического значения.

## Общая таблица 56 STX имён

PS2 reset имеет другую раскладку исходных globals и stack spills, но 56 записей
в`4C40F0..4C41CF`. Строгая straight-line provenance прослеживает каждый global
load до store и аргументы единственного вызова `4076A8(4C41E0,0,E0)`.
Это статический анализ, **не запуск PS2 reset**. Callee использует EE/MMI;
generic MIPS decoder не выдаётся за исполнение этого пути. Его full arbitrary
input behavior отдельно не закрыт.
