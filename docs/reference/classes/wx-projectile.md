# `wxProjectile`

`wxProjectile` зарегистрирован с Class ID `1ACF3C70` и базой `wxEntity` на PC и PS2. Исходные объекты обеих платформ имеют размер `EC`. Общая частичная реализация находится в [Winx/Code](../../../Winx/Code/wxProjectile.cpp), внешний `spActor` и объекты ссылок подключаются через [wxProjectileHost](../../../Winx/Analysis/Host/wxProjectileHost.h). Переносимый класс использует `spNamedObject` как C++ основу: исходный PC Copy вызывает его метод напрямую, а фактическая конструкция снаряда минует конструктор `wxEntity`. Регистрационная цепочка RTTI ссылается на восстановленный `wxEntity`. Аналитический массив `EC` байт не накладывается на C++ объект.

| Контракт | PC | PS2 |
| --- | ---: | ---: |
| Factory | `4018E0` | `3F6FA0` |
| Constructor | путь factory | `2C5030` |
| Vtable | `6F6B04` | `49B2B0` |
| Copy | `4FFC10` | `2C3450` |

После успешного родительского Copy переносятся слова `10,28,34,38,40,44,48,4C,50,54,2C,9C`, байты `30,A0` и указатели ссылок `14,58,5C,D4`. Значения слов, включая float и NaN, переносятся побитно. Для каждой ссылки сначала уменьшается 16-битный счётчик старого объекта, затем увеличивается счётчик нового, даже если адреса одинаковы. Удаление при последней ссылке вынесено в host. Остальные байты назначения сохраняются.

PC Copy удаляет прежний `spActor` назначения и создаёт новый экземпляр с обычными начальными настройками. Он не копирует текущие настройки Actor источника. Переносимая версия вызывает для этих действий host. Сохранены [PC](../../../Winx/Analysis/PC/wxProjectileAbi.h) и [PS2](../../../Winx/Analysis/PS2/wxProjectileAbi.h) константы ABI. [WinxProjectileTests](../../../Winx/Tests/wxProjectileTests.cpp) проверяет заводскую регистрацию, выбранные поля, счётчики ссылок, повторный Copy и замену Actor.

Источники: `.private/research/projectile-contracts-2026-09-10.json`, `.private/research/probe_projectile_copy.py` и результаты в `local-data/results/native-cycle-20260910-1900/projectile/`. Оригинальный PC Copy измерен до выделения Actor в шести сценариях ссылок и полностью ещё в двух сценариях Actor. PS2 собственная часть Copy измерена от точки после успеха родителя до исходного allocator; полный PS2 Actor lifecycle и сложное уничтожение ссылок остаются открытыми. Другие виртуальные методы и игровая физика снаряда здесь ещё не восстановлены.
