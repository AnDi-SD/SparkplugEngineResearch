# wxIceGargoyleAttackAIAction

`wxIceGargoyleAttackAIAction` имеет идентификатор `0x1B4441B7` и физическую
базу `wxAIAction`. PC factory — `0x5AF6E0`, размер — `0x3E8`, таблица из 24
слотов — `0x709308`. На PS2 factory находится по `0x251F00`, размер составляет
`0x3EC`, таблица — `0x4927A0` с двумя нулевыми словами перед 24 слотами.
Имена файлов и переносимых методов предполагаются; PC и PS2 ABI отделены от
переносимого C++ объекта.

| PC-поле | Начальное состояние | Наблюдаемая роль |
| --- | --- | --- |
| `3A8..3B0` | Три слова данных `7600E0` | Точка движения |
| `3B4` | 0 | Переключатель источника следующей точки |
| `3B8..3C0` | 0 | Направление движения |
| `3C4` | Конструктор не записывает | Скорость для фаз 2/3 |
| `3C8`, `3CC` | 0 | Слова неизвестной роли |
| `3D0`, `3D1`, `3D2` | 1, 1, 0 | Копируемые байты неизвестной роли |
| `3D4` | `0.5f` | Порог выбора следующей фазы |
| `3D8` | null | Заимствованный Node текущей цели |
| `3DC` | 0 | Фаза |
| `3E0` | 0 | Время: deadline или отметка, в зависимости от фазы |
| `3E4` | 0 | Защёлка фазы 3 |

В соответствующем PS2 layout собственные поля смещены на четыре байта.
Исполнение и арифметика PS2 стадий отдельно не квалифицированы.

## Жизненный цикл и сообщения

Copy `0x5AF370` сначала выполняет общий Copy `wxAIAction`, затем переносит
слова в порядке `3D8`, `3DC`, `3E0`, `3A8`, `3AC`, `3B0`, `3D4`, байты
`3D0`, `3D1`, слова `3C8`, `3CC` и байт `3D2`. Направление, скорость,
переключатель `3B4` и защёлка `3E4` сохраняются у назначения. Clone создаёт
новый объект и выполняет этот Copy. Его скорость остаётся неинициализированной;
в переносимой реализации это явное `optional` без значения. Сам конструктор
не задаёт скорости нулевой default.

Указатель Node заимствован: Copy, Clone и деструктор не увеличивают и не
уменьшают его ссылки. Переносимый Copy ограничен назначением того же типа и
квалифицированным состоянием общей базы.

Entry `0x5AF810` получает настоящий текущий `wxTargetManager`, его слово `28`
и слово `18` выбранной записи. Записывает этот Node либо null в `3D8`, фазу 2,
время 0 и переключатель 0. Null вызывает селектор владельца `(0, 0)`.
Переносимый код читает `CurrentWordsForAnalysis()[2]` непосредственно; host
предоставляет только заимствованные данные записи `18`, различая известный
null и неизвестную привязку.

Query использует общий PC `0x5ADBC0`: получает Perception владельца,
исполняет настоящий общий FindNearest и при отсутствии результата повторно
читает владельца для селектора `(0, 0)`. Кэш Node не изменяется.
Exit `0x5AF260` очищает командные байты `20` и `21`, повторно читая владельца
и команду между записями, затем обнуляет кэш Node.

Notify `0x5AF350` передаёт код `0x2717` дополнительному слоту `44`, операции
`0x5AF630`. Остальные сообщения идут в настоящий общий Notify `wxAIAction`.
При уже установленной фазе 3 специальная операция сразу возвращается.
Иначе она читает указатель `character138` и слово сообщения `18`; ненулевому
внешнему receiver предназначен пакет `0x2718`. Его native class и доставка
остаются открытыми. При null receiver собственное тело выполняется полностью:
скорость и время становятся нулевыми, фаза — 3, к порогу прибавляется `0.2f`.
Сначала записывается float-результат суммы, затем её неокруглённое до float
значение сравнивается с `0.8f`; строго больший результат зажимается до `0.8f`.

## Обновление

PC Update `0x5AF790` получает Node из текущего TargetManager заново при каждом
вызове, затем всегда исполняет слот `58`, операцию `0x5AFCC0`. После неё читает
фазу и вызывает слот `48`, `4C`, `50` или `54` для значений 0, 1, 2 или 3.
Другие значения оставляют только результат общей подготовки. Завершившийся
нативный Update возвращает true. Два других обычных bool update имеют
буквальное общее тело true.

Подготовка получает cached WORLD X/Z цели раньше LOCAL X/Z владельца,
нормализует плоское направление и строит матрицу через `0x420470` с данными
up-vector `740328`. Для канонического `{0,1,0}` первая строка — общий
`Cross(up, forward)`, вторая — up, третья — forward. Неполностью определённая
ветвь совпавших векторов здесь недостижима, поскольку forward Y равен 0.
Вызов yaw `0x597140` выполняется, его результат отбрасывается. Затем владелец
читается заново, записывается LOCAL orientation Node, отмечается dirty и
вызывается настоящий общий Node UpdateWorld.

Фаза 0 (`0x5AF450`) при нулевом времени обнуляет защёлку и скорость,
исполняет реальный квалифицированный Reset команды и сохраняет
`now + 500 + RNG % 1501` с uint32 wrap. Время снимается до RNG. При ненулевом
времени и `now <= time` стадия ждёт. После строгого истечения снимает RNG;
`RNG * 2^-32 < threshold` выбирает фазу 1, иначе 2. Время обнуляется.

Фаза 1 (`0x5AF530`) при нулевой отметке выставляет командный байт `21` в 1
и сохраняет текущее время. Нулевое время оставляет этот путь повторяемым.
При ненулевой отметке условие `(state140 & 0x7F80) == 0x480` очищает байт `21`
и выбирает фазу 0 для `RNG < 0x80000000`, иначе 2. Отметка времени сохраняется.

Фаза 2 (`0x5AF990`) снимает LOCAL-позицию до своей ветки. При нулевом времени
нулевой переключатель выбирает точку тремя последовательными RNG:
`x = RNG * (200/2^32) + 1650`, `y = RNG * (150/2^32) + 1500`,
`z = RNG * (540/2^32) + 460`, с отдельными float stores. Ненулевой переключатель
выбирает одну из четырёх заимствованных записей `742BF4..742C20` по `RNG & 3`.
Затем сохраняется now, вычисляется нормализованное направление от снятой
позиции к точке, обнуляется скорость и инвертируется текущий переключатель.

При ненулевой отметке строгое сравнение squared distance с 400 сбрасывает
фазу и время при близости. Иначе, пока скорость меньше 400, к ней прибавляется
`delta * 200`. Зажима после прибавления нет. Дальнейшее движение повторно
читает delta и Node владельца. Скорость X сохраняет extended-точность до
умножения на delta; скорости Y/Z предварительно округляются до float.
Приращения X/Y также округляются до float, а приращение Z сохраняет
extended-точность до сложения с исходной координатой.

Фаза 3 (`0x5AF870`) сохраняет `speed - delta1 * 980`, затем снимает LOCAL-позицию
и повторно читает delta и Node для изменения Y на `delta2 * storedSpeed`.
При нулевой защёлке командный байт `5C` равен 1 до состояния `state130 == 0xA`;
это состояние очищает байт и выставляет защёлку. После выхода из `0xA` при
выставленной защёлке время, скорость и защёлка обнуляются, фаза становится 2.

Движение фаз 2/3 только изменяет LOCAL-позицию и dirty. Cached WORLD-поза
остаётся результатом подготовки до движения и обновляется следующим
Node UpdateWorld.

Дополнительный слот `5C` (`0x5AF5E0`) проверяет строгое попадание Y цели внутрь
интервала `owner1CC < targetY < owner1B4`. Сначала читается верхняя граница
`1B4`, затем при необходимости нижняя `1CC`. При попадании вызывается селектор
`(5, 0)` с ранее сохранённым владельцем.

## Граница реализации

Активный Update по умолчанию имеет профиль `HooksOnly` с явным отказом.
`PcFiniteGeometry` допускает конечные координаты с модулем не больше 4096,
направление движения с компонентами до 4, известную скорость до 8192 и
`abs(delta) <= 1`. Владелец использует настоящий plain, unparented Node с null
Scene, без детей и collision-объектов. Условия проверяются по мере обращения
к данным; отказ после подготовки не отменяет уже выполненные изменения.
Скорость требуется известной только на путях, действительно читающих её.

Используются настоящие общие TargetManager, Perception, GameTimer, RNG и Node.
Нормализация и yaw переиспользуют существующие конечные адаптеры; импорт
`MSVCR71!_CIacos` имеет явную математическую замену host `acos`. Остальные
численные stores и сравнения используют общий nearest64 accumulator.
Произвольная побитовая тождественность x87/CRT и другие rounding modes не
заявляются. Reset команды — отдельный квалифицированный внешний receiver;
его original class name остаётся неизвестным.

Открыты PS2 execution, холодные сервисы и загрузка ресурсов, ненулевая
brain-доставка, унаследованные pathfinding/serialization hooks, произвольные
состояния общей базы и игровой цикл. Полнота класса не заявляется. False при
диагностическом отказе переносимого bool wrapper не приписывается оригиналу.
