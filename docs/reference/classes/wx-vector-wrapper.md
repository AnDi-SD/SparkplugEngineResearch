# wxVectorWrapper

`wxVectorWrapper` (`1F793E0D`) — объект с тремя 32-битными компонентами после
физической базы `spBaseObject`. Регистрация PC и PS2 также указывает эту базу.
Обе версии выделяют `0x1C` байт; компоненты находятся по смещениям
`10`, `14`, `18`. Конструктор записывает в них нули. Имена публичных методов
и исходный путь заголовка не восстановлены.

Общая реализация находится в
[wxVectorWrapper.h](../../../Winx/Code/wxVectorWrapper.h) и
[wxVectorWrapper.cpp](../../../Winx/Code/wxVectorWrapper.cpp).
Нативные layout и адреса описаны отдельно для
[PC](../../../Winx/Analysis/PC/wxVectorWrapperAbi.h) и
[PS2](../../../Winx/Analysis/PS2/wxVectorWrapperAbi.h).

## Copy и Clone

Copy сначала вызывает базовую операцию `spBaseObject`, которая не переносит
поля базы, затем записывает три компоненты и завершает копирование через
clone manager. Поля базы назначения остаются прежними. Clone создаёт новый
объект, регистрирует пару source/destination в общем clone manager и вызывает
Copy через виртуальную таблицу исходного объекта. Компоненты нового объекта
не ссылаются на storage источника.

На PC первая компонента переносится целочисленным `MOV`; вторая и третья
проходят через `FLD/FSTP` x87. На PS2 все три компоненты переносятся через
`LWC1/SWC1` без арифметики. Представление payload целыми словами сохраняет
знаковый ноль, subnormal, infinity и проверенные NaN payload без случайного
преобразования средствами host FPU.

## Границы переносимой реализации

`CopyPlatformForAnalysis` — собственный выбор профиля, а не поле оригинала.
PC выбран по умолчанию. PC-профиль отказывает до изменения назначения, если
вторая или третья компонента содержит signaling NaN: аппаратный результат,
управление исключениями и исходное control word x87 остаются открытыми.
Signaling NaN в первой компоненте допускается, поскольку её Copy использует
целочисленную передачу. PS2-профиль сохраняет все raw 32-bit patterns.
Профиль назначения не переносится при Copy; Clone сохраняет профиль
источника. Проверка типа назначения и предварительный отказ — собственные
ограничения аналитического API, не воспроизведение нативных ошибок.

Сопоставление покрывает PC factory, виртуальные RTTI/Copy/Clone и освобождение
объектов, а также полный PS2 constructor и Copy на исходных instruction words
с явно заданной моделью stack, raw FPR transfer и scalar control. Это
квалификация ограниченных операций: PS2 heap/deletion, аппаратные исключения,
потребители свойств и игровой runtime отдельно не квалифицированы. Цель
проверки — `WinxVectorWrapperTests`.
