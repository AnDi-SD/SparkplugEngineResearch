# wxTrollBeforeFightAIAction

Registered ID `03197B06`, base `wxAIAction`; native size `3B8` bytes on PC and `3BC` on PS2. Four own words hold phase, latch, next-decision time and cooldown. The common source implements all four stage bodies, Query handshake, Entry/Exit, no-op Notify, dispatcher and four-word Copy directly. Host/profile configuration is our integration state and is separate from the native layouts.

Entry clears all four words. Tick sends phase1/2/3 to command22/23/24 respectively; phase0 and every unsigned phase greater than3 use stage0. A command stage with latch0 sets its command byte; latch1 clears it; other latches reset phase and latch only. Phase2 with latch0 also writes cooldown=current time+12000 on every Tick, with uint32 wrapping. Query always reads the character state, then advances latch0 to1 when phase1/2/3 sees state5/6/7, and latch1 to2 when the state becomes zero. Notify forwards no messages. Exit clears command bytes1D,20,21,22,23,24 while preserving own words.

Stage0 with next-decision zero calls the command's actual external Reset, samples GameTimer, consumes the shared RNG and stores time+1000+RNG%2501. Otherwise it samples time and waits for strict unsigned time>next-decision. An expired decision consumes RNG; on PC, RNG<`80000000` additionally reads time again and chooses phase2 only when cooldown is strictly less than that second sample. Other decisions choose phase1. Both paths clear latch and next-decision. PC's x87 conversion and exact power-of-two scaling before comparison with0.5 are represented by this exact integer predicate.

The PS2 integer profile executes its integer branches and reports `UnqualifiedPs2RandomPredicate` after the expired branch has consumed RNG, before applying the unqualified floating predicate. It preserves the original prefix rather than borrowing the PC numeric boundary. The Boolean Tick wrapper's false for that analytical guard is ours; ordinary native Tick returns true.

The component reuses the actual shared RNG algorithm and reads a real GameTimer's shared `spTaskTimer` prefix. The external command record's native class name is unknown: constructor/table evidence is PC `599430`/`703090` and PS2 `3731D0`/`494710`, with Reset at `5992E0`/`3730E0`. Its adapter must implement that precise external operation, not an arbitrary success return. The source owns every Troll stage decision; none is delegated to a stage callback.

PC component evidence uses actual action factories/RTTI and GameTimer; PS2 uses guarded construction-proven layouts and the explicit scalar/SP stack/DIVU profile with interpreted integer control transfers and checked delay slots. This is a bounded instruction model, not a general EE CPU claim. PS2 own Copy suffix is conditional on parent success. Native allocator failure, null/faulting graphs, cold GameTimer composition, the PS2 floating predicate, full PS2 lifetime and whole AI/game execution remain open.
