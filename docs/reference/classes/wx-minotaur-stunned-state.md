# `wxMinotaurStunnedState`

`wxMinotaurStunnedState` (Class ID `7D863ED6`) — потомок `wxCharacterState` с selector `28`. Восстановленные собственные операции находятся в [Winx/Code](../../../Winx/Code/wxMinotaurStunnedState.cpp). Размер исходного объекта — `3C` на обеих платформах; дополнительных полей после общей базы нет. Переносимый C++ объект не накладывается на исходный ABI.

| Операция | PC | PS2 |
| --- | ---: | ---: |
| Фабрика | `403E60` | `3F0BA0` |
| Vtable | `6F9C40` | `499400` |
| Вход, PC slot `1C` | `521BA0` | `305A40` |
| Обновление, PC slot `30` | `521B60` | `305A20` |
| Проверка перехода, PC slot `34` | `521B20` | `305BB0` |

Вход задаёт ключ `(key & F0010000) | 00010000`, запрашивает анимацию по профилю owner и запускает её с `mode=false`, `interrupt=true`. Он не освобождает прежний pending handle. Новый handle сохраняется после запуска, затем через виртуальный slot `30` последовательно обнуляются byte `60` и word `4` внешнего control-объекта. Метод возвращает `true`; once-флаги не меняются.

Обычное обновление `30` выполняет только эти две записи. Проверка перехода `34` содержит особую ветвь target `11`: сначала вызывается потребляющий запрос завершения `(handle, true)`. При `false` состояние освобождает pending handle общим stop/fade helper и возвращает `true`. При `true` запрос выполняется **ещё раз**, и возвращается его новый результат. Первый вызов может удалить completion-записи, поэтому второй результат бывает `false`. Для остальных target выполняется один запрос. Нулевой handle тоже передаётся получателю; локального short circuit здесь нет.

Slot `38` возвращает `false`: на PC он унаследован, на PS2 имеет собственный эквивалентный leaf. Остальные hooks принадлежат [общей базе](wx-character-state.md). Унаследованный пустой Copy не переносит runtime-поля и host-привязки. Clone сохраняет selector `28` и значения свежего конструктора. Деструктор и reset не вызывают stop/fade.

[wxCharacterControlStateHost](../../../Winx/Analysis/Host/wxCharacterControlStateHost.h) предоставляет внешний control по `owner+12C` на PC или `owner+138` на PS2, а также анимационные службы. Название и полный смысл byte `60` остаются неизвестными. [C++ проверка](../../../Winx/Tests/wxControlStateTests.cpp) покрывает вход, обновление, остановку при переходе и повторное потребление completion. Полная игровая сцена остаётся внешней зависимостью.
