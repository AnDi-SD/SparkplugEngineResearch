# spAudioBankEntry: физический Name и ограниченный пустой профиль PC

`spAudioBankEntry` имеет ID `0x6A5024D0`. Регистрационная база движка —
`spBaseObject`, поэтому engine RTTI не считает запись `spNamedObject`.
Физический префикс содержит настоящий Named: конструктор конкретной DX-записи
вызывает общий Base, Named и AudioBankEntry на одном полном receiver и
последовательно устанавливает их таблицы. Регистрационную цепочку и физическое
C++-наследование следует рассматривать отдельно.

[Переносимая реализация](../../../Sparkplug/Code/Sparkplug/spAudioBankEntry.h)
физически наследует общий `spNamedObject`, сохраняя регистрационную базу Base.
Имена методов и сырых полей аналитические. Независимый native factory базовой
записи отсутствует; размер полного базового объекта этим контрактом не задан.

## Известные поля конструктора

Физический name по PC-смещению `10` первоначально null. Собственные поля,
подтверждённые внутри конкретной DX-записи:

| Смещение PC | Ширина | Значение |
| --- | --- | --- |
| `14` | byte | `0` |
| `18` | UInt32 | `1` |
| `1C`, `20`, `24` | UInt32 | `0` |
| `28` | byte | `0` |
| `2C` | UInt32 | `0` |
| `30` | byte | `0` |

Смысл собственных полей пока не восстановлен. Значение padding не моделируется
как native default. Только слово `18` имеет явный fixture setter для
подачи захваченного скалярного состояния; это не оригинальный метод загрузки
или изменения аудиоресурса.

## Copy и владение именем

PC Copy использует настоящий Named entry `413120`: освобождает прежнюю ссылку
назначения, обнуляет её, затем вновь читает имя источника и удерживает его.
Разные записи разделяют одно имя. Self-Copy очищает имя, поскольку освобождение
назначения происходит до повторного чтения источника. Собственные сырые поля
не копируются и остаются неизменными.

Переносимый override проверяет физический Entry destination и использует
общий protected `CopyNameToForAnalysis`. Обычный Named wrapper имеет отдельный
engine RTTI guard; его применение здесь отвергло бы физически совместимый
Entry. Сам общий wrapper этим классом не меняется. Другие виды назначения
переносимый ограниченный профиль отвергает до эффектов.

Имя хранится существующим общим shared owner. Это техническая замена native
интернированной записи с byte-счётчиком, без совпадения ABI или численного
равенства счётчика и `use_count`. Контракт времени жизни охватывает null name
либо имя с сохраняющимся внешним владельцем. Записи снимают свои ссылки, а
внешнее имя остаётся живым и неизменным. Финальное удаление native name pool
не описано.

Полный оригинальный Copy также может лениво создать отдельный глобальный
контекст на 24 байта через `412540`. Он не принадлежит AudioBankEntry и не
освобождается деструктором записи. Этот native эффект и время жизни глобального
контекста отделены от переносимой операции над полем имени и переданного
caller'ом `spCloneManager`.

## Ограничение времени жизни

Source-конструктор требует явный marker
`CapturedEmptyProfileForAnalysis::NonzeroUnassignedE0WithNullResources`.
Это host-допуск к конкретному захваченному DX-профилю, не оригинальный enum,
поле или default неизвестных байтов. Неявного переносимого RTTI factory нет.
Базовый Clone явно отказывает: он не наследует Named factory как вымышленный
производитель AudioBankEntry. Конкретный
[DX Clone](sp-dx-audio-bank-entry.md) имеет отдельную реализацию.

Загрузка, воспроизведение, непустые SDK-ресурсы, глобальные менеджеры, native
последний владелец имени, произвольные callbacks/reentry, PS2 и весь класс
остаются вне этого поднабора. Непустой AudioBank ещё не является producer
записей в этом контракте.
