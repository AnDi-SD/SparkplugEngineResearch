# `wxDialogueState`

`wxDialogueState` (Class ID `16651EBE`) — потомок `wxCharacterState` с selector `32`. [Общая реализация](../../../Winx/Code/wxDialogueState.cpp) сохраняет собственные hooks диалога PC/PS2. Исходный размер — `3C` на обеих платформах, собственного хвоста нет. Переносимый класс не является overlay игрового ABI.

| Операция | PC | PS2 |
| --- | ---: | ---: |
| Фабрика | `5A6920` | `2CB200` |
| Vtable | `7068A8` | `493560` |
| Вход, PC slot `1C` | `5A6A20` | `2CAFC0` |
| Обновление, PC slot `30` | `5A6A60` | `2CAE30` |
| Проверка перехода, PC slot `34` | `5A6A00` | `2CB030` |

Вход сначала отправляет сообщение через внешнюю игровую службу: источник — само состояние, code `27BA`, параметр `0E`, два следующих слова `0`. Затем меняет ключ на `(key & FFFFFFF8) | 8` и вызывает вход [wxCharacterState](wx-character-state.md): освобождение pending handle, виртуальное обновление `30`, результат `true`. Выход использует общий hook базы.

Обновление сначала вычисляет `(key & F007FF88) | 8`. Поле action `(key >> 7) & FF` сохраняется только для значений `28..57` включительно. В остальных случаях применяется дополнительная маска `FFFF8070`; она очищает также установленный mode `8`. Эта особенность сохранена как в игре.

После lookup одинаковый handle пропускает release/play. При изменении handle старый обязательно останавливается: эта ветвь подавляет fade независимо от owner predicate. Новая анимация запускается с `mode=true`, `interrupt=true`; её fade-параметр по-прежнему выбирается через predicate. Handle сохраняется после playback.

Переход `34` разрешён при game state, отличном от `70`. Target не участвует в проверке. Copy унаследован от `spBaseObject` и пуст. Clone сохраняет новый selector и начальные флаги, но не переносит привязки и pending handle; деструктор не останавливает анимацию.

[wxDialogueStateHost](../../../Winx/Analysis/Host/wxDialogueStateHost.h) предоставляет игровое сообщение и game state, кроме общих анимационных зависимостей. Это обязательный внешний контракт без успешной реализации по умолчанию. [C++ проверка](../../../Winx/Tests/wxDialogueStateTests.cpp) охватывает все значения action, сообщения, переходы, clone и порядок callbacks. Полный игровой цикл диалога остаётся зависимостью сцены и внешних менеджеров.
