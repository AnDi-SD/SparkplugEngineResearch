# wxFrogBackFlipState

Состояние с class ID `26702041`, физической и регистрационной базой
`wxCharacterState`. PC и PS2 выделяют `0x3C` байт; селектор `10` равен `25`.
Собственного хвоста нет. Реализация: [заголовок](../../../Winx/Code/wxFrogBackFlipState.h)
и [методы](../../../Winx/Code/wxFrogBackFlipState.cpp).

Вход `1C` сначала выполняет общую подготовку движения с false. Затем заменяет
ключ на `(key & F0080850) | 00080850`, ищет анимацию, запускает её с mode=false,
interrupt=true и сохраняет handle после playback. Старый pending не освобождается,
совпадение handles не проверяется; виртуальный update не вызывается.

Update `30` выполняет общую службу движения с false, затем обнуляет слово
control `4`. Permission `34` игнорирует аргумент и всегда выполняет consuming
completion query, включая null pending. Остальные hooks и Reset унаследованы.
Clone создаёт свежий объект: runtime-поля, кэш движения и handles не копируются.

Анимационные службы и узлы остаются заимствованными зависимостями.
Общий [host движения](../../../Winx/Analysis/Host/wxCharacterMovementStateHost.h)
явно отделён от оригинального класса. Проверка — `WinxFrogBackFlipStateTests`.
Она проверяет последовательность entry/update/query/reset/clone; сравнение с
оригиналом включает порядок обращений к полям и внешним службам.

Численная эквивалентность PC установлена для проверенных конечных входов,
а не всех возможных float32. Вращение PS2 требует ещё не квалифицированного
адаптера аккумулятора EE. Подтверждённые PS2-prefixes охватывают кэш, key,
аргументы queue/query и порядок очистки control. Полная игровая интеграция
и полный класс пока не объявляются завершёнными.
