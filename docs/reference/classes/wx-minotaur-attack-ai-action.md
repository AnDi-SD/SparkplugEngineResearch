# wxMinotaurAttackAIAction

`wxMinotaurAttackAIAction` (`0x5B6B6464`) физически наследует `wxAIAction`.
PC factory `0x5B8E80` создаёт объект `0x3C8`, вызывает конструктор `0x5B8DF0`
и устанавливает таблицу `0x709AC8` из 17 слотов. Getter `0x5B8E40` возвращает
запись `0x767730`. На PS2 factory — `0x25FA60`, размер — `0x3CC`, таблица —
`0x492BC0` с двумя нулевыми заголовками. Имена путей и переносимых методов
предполагаются; физические layouts отделены от C++ объекта.

| PC-поле | Начальное состояние | Наблюдаемая роль |
| --- | --- | --- |
| `3A8` | null | Заимствованная цель-actor |
| `3AC` | 0 | Фаза |
| `3B0` | 0 | Deadline |
| `3B4` | 0 | Слово случайного порога, единицы открыты |
| `3B8` | `0.3f` | Порог отдельного facing-метода |
| `3BC`, `3BD` | 0 | Байты состояния |
| `3C0` | null | Заимствованная кэшированная команда |
| `3C4` | Конструктор не записывает | Слово неизвестной роли |

PS2 смещает эти поля на четыре байта. Переносимая реализация хранит `3C4`
как `optional`: отсутствие значения сохраняет различие неизвестного и нуля.
Padding не получает придуманного семантического default.

Copy `0x5B9090` выполняет общий Copy базы, затем переносит слова `3A8`, `3AC`,
`3B0`, `3B4`, `3B8`, байт `3BC` и слово `3C0` в этом порядке. Байт `3BD` и
слово `3C4` остаются у назначения. Clone создаёт новый объект и выполняет
Copy; у него `3BD` остаётся нулевым, а `3C4` — неизвестным. Цель и команда
заимствованы без AddRef/Release. Переносимый Copy ограничен тем же типом и
квалифицированными состояниями общей базы.

## Hooks

Entry `0x5B8F50` выставляет командный байт `1D`, получает настоящий Perception
владельца и исполняет общий FindNearest. После него читает владельца заново,
сохраняет цель, фазу 0, байт `3BC` 0, deadline 0 и команду этого владельца.
Null-цель приводит к селектору `(1, 0)` с сохранённым владельцем. Этот путь
ограничен входом в селектор: его возврат и последующий RNG открыты.

При имеющейся цели Entry снимает настоящий общий RNG и сохраняет float
`250000 + RNG * float(0x386A6000)`. Это точный множитель оригинала;
переносимая арифметика использует существующий nearest64 accumulator и
отдельный float store. Новый генератор или возврат RNG через callback
не используются.

Query `0x5B4970` исполняет тот же настоящий FindNearest. Отсутствие результата
вызывает селектор `(1, 0)` с повторно прочитанным владельцем; кэш цели не
изменяется. Exit `0x5B8E60` очищает `1D` и `20` кэшированной команды,
повторно читая кэш между записями, затем обнуляет цель.

Notify `0x5B8FF0` игнорирует `0x27A4`, остальные обычные сообщения передаёт
общему Notify `wxAIAction`. Код `0x271C` при нулевом `3BC` немедленно
возвращается. Иначе байт сообщения `18` определяет запись `command60`:
нулевой payload даёт 1, ненулевой — 0. Команда читается заново после записи.
Если её байт `60` ненулевой, снимаются now и затем RNG, фаза становится 3,
deadline — `now + 2000 + RNG % 1001` с uint32 wrap. Иначе фаза становится 2;
deadline сохраняется. Слово сообщения `18` целиком не требуется: читается
только его первый байт и только на соответствующем пути.

## Ограниченное обновление

Update `0x5B9760` использует буквальную jump-table. Для фаз 0..5 вызовы идут
по адресам `5B9680`, `5B96E0`, `5B91D0`, `5B9130`, `5B9580`, `5B92C0`.
Фаза 3 — восстановленная операция ожидания. Значение больше 5 сбрасывается
в 0. Завершившийся native Update возвращает true.

Фаза 3 `0x5B9130` сначала проверяет байт `60` кэшированной команды. Если он
ненулевой, читает `owner144 -> character124 -> state130` и записывает
`state != 0x1C` в байт `60` ранее сохранённой команды. Затем заново читает
кэш команды, очищает её байт `20` и обнуляет `3BC`. При строгом беззнаковом
`now > deadline` снимает RNG, сбрасывает фазу в 0 и записывает тот же
случайный float-порог, что Entry. Deadline сохраняется; равенство не истекает.

По умолчанию `HooksOnly` отказывает в активном Update до изменений.
Явный профиль `PcCooldown` выполняет фазу 3 и сброс неизвестного номера фазы.
Фазы 0, 1, 2, 4, 5 остаются явным `UnqualifiedPhase`: их facing, pathfinding,
геометрия и защищённый внешний reset `0x4D96A0` не подменяются успешными
заглушками в профиле `PcCooldown`. False диагностического wrapper не
приписывается оригиналу.

Дополнительный opt-in `PcCooldownAndFiniteMovement` допускает также
ограниченную фазу 2, `0x5B91D0`. Сначала очищаются байт `20` кэшированной
команды и `3BC`. Позиция WORLD владельца снимается перед WORLD-позицией
кэшированной цели-actor, через их настоящие Node. LOCAL-позиции здесь не
используются. Разности и сумма `(dz*dz + dy*dy) + dx*dx` сохраняют
nearest64-точность до сравнения с float `237500`.

При значении не больше порога вызывается настоящий общий position-yaw
`0x5970B0` с аргументами target, затем origin: направление идёт от цели к
владельцу. Он игнорирует Y в направлении и переиспользует нормализацию
`0x41D2D0`. Затем в заново прочитанную кэшированную команду записывается
motion `1.0f`, а после очередного чтения кэша — float yaw в слово `8`.
Даже совпавшее плоское направление проходит тот же общий helper.

Строго большее расстояние переводит фазу в 3 и записывает motion 0. Следующий
native шаг разрешает `owner144 -> character12C` и вызывает защищённый
`0x4D96A0`. Переносимый код сохраняет предшествующие собственные изменения
и возвращает `UnqualifiedControllerReset`; получатель и тело reset не
подменяются callback и не объявляются восстановленными. Native-проверки этого
пути заканчиваются на входе в reset без исполнения первой инструкции.

Численный профиль фазы 2 допускает конечные XYZ владельца и цели в
`[-1024,1024]` и стабильные привязки геометрии при чтении и чистой математике.
Проверки выполняются по мере обращения к данным; диагностический отказ не
отменяет уже выполненную очистку байта команды и `3BC`. Yaw использует общий
конечный [PC-адаптер](../../../Winx/Analysis/PC/wxPlanarAngleMath.h), включая
явную математическую замену `MSVCR71!_CIacos` через host `acos`. Произвольная
побитовая тождественность CRT/x87, другие rounding modes и PS2 арифметика
не заявляются. Фазы 0, 1, 4, 5 остаются открытыми и в новом профиле.

Используются общие Perception, GameTimer и RNG. Доступ к заимствованным полям
команды и персонажа отделён через узкий host. Открыты прочие фазы, холодные
сервисы, произвольные состояния общей базы, PS2 execution и игровой цикл.
Полнота класса не заявляется.
