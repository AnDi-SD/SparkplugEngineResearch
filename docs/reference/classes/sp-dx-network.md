# `spDXNetwork`

PC-реализация сокетов WinSock с регистрационной базой `spNetwork`. Class ID:
`spDXNetwork` — `0x41FB6C73`, [spNetwork](sp-network.md) — `0x18B4576A`. У базы отсутствует
factory, а Clone возвращает null. В известном каталоге PS2 этих классов нет;
реализация для PS2 не установлена.

У `spNetwork` первые 16 слотов основного интерфейса ведут на purecall;
последний слот `40` возвращает null. Переносимая база сохраняет это различие.

Восстановлены factory, Clone, копирование имени, destructor и все 17 методов
основного сетевого интерфейса. [Исходники](../../../Sparkplug/Code/SparkplugDX/spDXNetwork.h)
используют явно заданный [платформенный адаптер](../../../Sparkplug/Analysis/Host/spDXNetworkHost.h).
Имена методов с `ForAnalysis`, исходные заголовки и пространство имён — наши
обозначения: оригинальные объявления C++ не найдены. Адаптер предоставляет
вызовы WinSock; готового системного backend в этом компоненте нет.

## Объект PC

Объект занимает **64 байта**. Основная таблица сетевого интерфейса находится
по `+0`, вторичный объектный интерфейс `spCrossPlatform` — по `+4`. Factory и
accept возвращают complete object, объектный Clone — secondary pointer `+4`.
Delete adjustor вычитает четыре. Эти интерфейсы подтверждены отдельно от RTTI.
Переносимые классы сохраняют два интерфейса, но не размер и смещения PC;
точный [ABI](../../../Sparkplug/Analysis/PC/spDXNetworkAbi.h) описан отдельно.

| Смещение | Поле | Начальное значение |
| --- | --- | --- |
| `00` | network vtable | `006EF928` |
| `04` | CrossPlatform / named object | object vtable `006EF90C` |
| `18` | признак подключения, byte | `0` |
| `1C` | тип сокета, uint32 | `1`; `0` — UDP, `1` — TCP |
| `20` | IPv4 в host byte order, uint32 | `FFFFFFFF` |
| `24` | порт в host byte order, uint16 | `FFFF` |
| `28` | SOCKET, uint32 | `FFFFFFFF` |
| `2C` | sockaddr, 16 байт | не инициализирован |
| `3C` | собственная строка локального IPv4 | null |

Переносимый sockaddr хранит маску известных байтов. Незаписанная память
оригинала не объявляется нулевым адресом. Padding не относится к полям.

## Создание, копирование и освобождение

Первый объект вызывает `WSAStartup(0x0202)` и увеличивает общий счётчик даже
при отказе запуска. Следующие объекты используют тот же счётчик. Последний
destructor вызывает `WSACleanup` **до** закрытия своего сокета. Результаты
startup, cleanup и closesocket игнорируются.

Destructor закрывает сокет только при ненулевом признаке подключения `18` и
валидном handle. Открытый или привязанный сокет без подключения требует явного
Close: оригинал оставляет его открытым. Close возвращает true, закрывает любой
валидный handle, записывает `FFFFFFFF` и обнуляет `18`. При исходном invalid
handle Close не меняет `18`. Закрытие не удаляет handle из общих наборов.

Clone создаёт свежий объект и регистрирует пару secondary pointers. Затем
наследуемый copy копирует только общее имя. Сокет, адрес, порт, тип, признак
подключения, sockaddr и кэш строки не копируются. Прямой copy имени сохраняет
существующее сетевое состояние получателя.

Copy наследуется от общей `spNetwork`: при самокопировании оригинальный порядок
освобождения/чтения очищает имя и сохраняет сетевое состояние.

## Сетевые операции

| Слот primary | Переносимое обозначение | Поведение |
| --- | --- | --- |
| `00` | Open | При существующем handle возвращает true независимо от типа; иначе создаёт IPv4 UDP `(2,2,17)` или TCP `(2,1,6)`. Неизвестный тип — false. Тип сохраняется и при отказе socket. |
| `04` | Connect | Записывает полный sockaddr через htonl/htons; при успехе сохраняет host address/port и устанавливает `18`. При отказе сохраняется новый sockaddr, остальные поля не меняются. |
| `08` | Bind | Адрес `FFFFFFFF` заменяется на ANY `0`. После успешного bind sockaddr обнуляется, вызывается getsockname и сохраняются ntohl/ntohs. Признак подключения не устанавливается. |
| `0C` | Listen | Вызывает listen с backlog `5`; invalid handle или SOCKET_ERROR — false. |
| `10` | Accept | Создаёт свежий объект для принятого handle, устанавливает `18`, копирует тип и возвращённые байты sockaddr, сохраняет адрес/порт. |
| `14` | Close | Явное закрытие описано выше. |
| `18` | SetBlocking | FIONBIO `8004667E`; аргумент byte `0` даёт `1`, любой ненулевой byte — `0`. |
| `1C` | AddToSet | Добавляет handle в общий выбранный набор. |
| `20` | RemoveFromSet | Удаляет первое совпадение и сдвигает остаток. |
| `24` | ClearSet | Обнуляет только счётчик выбранного набора. |
| `28` | Select | Вызывает select с nfds `0`, seconds `0`, microseconds `timeout * 1000`, true только при результате `> 0`. |
| `2C` | Send | Передаёт буфер и размер в send с flags `0`; возвращает число байтов либо `-1`. |
| `30` | SendTo | Перезаписывает sockaddr адресом назначения; sendto с flags `0`. Host address/port объекта не обновляются. |
| `34` | Receive | recv с flags `0`; возвращает число байтов, `0` или `-1`. |
| `38` | ReceiveFrom | recvfrom пишет во внутренний sockaddr, длина на входе `16`. Первые два слова аргументов игнорируются; их исходные типы неизвестны. Host address/port не обновляются. |
| `3C` | GetLocalAddress | gethostname с ёмкостью `256`, gethostbyname, первый IPv4 и ntohl; ленивое создание текста адреса. |
| `40` | GetLocalAddressText | Возвращает кэш; если его нет, вызывает предыдущий метод. |

При invalid handle операции Connect, Bind, Listen и SetBlocking возвращают
false, передача и приём — `-1`, без вызова WinSock.

Bind передаёт в getsockname указатель на свой первый аргумент: начальная длина
равна исходному адресу, **не 16**. Результат getsockname игнорируется. Если
вызов не записал sockaddr, после успешного bind сохраняются нулевые адрес и
порт. Эта особенность сохранена.

Accept при invalid handle возвращает слово из общего глобального поля:
в исходном PC-образе это `FFFFFFFF`. При отказе accept вызывает WSAGetLastError;
`10035` даёт null, другая ошибка — тот же глобальный sentinel. Переносимое
представление возвращает владельца нового объекта и отдельное `failureWord`,
чтобы не превращать `FFFFFFFF` в C++-указатель. Длина sockaddr после accept
определяет размер копирования; при длине меньше 16 остаток остаётся неизвестным.

Локальный числовой IPv4 запрашивается при каждом GetLocalAddress, но строка
создаётся один раз и не обновляется. Например, после смены адреса с `1.2.3.4`
на `5.6.7.8` числовой результат меняется, а текст остаётся `1.2.3.4`.

## Общие наборы и границы

Три набора общие для объектов: `0` — read, `1` — write, `2` — exception.
Ёмкость каждого — 64 handle. Add допускает повторы и `INVALID_SOCKET`;
при полном наборе возвращает true без записи. Remove удаляет первое совпадение,
при отсутствии handle возвращает true. Clear не очищает хвост массива.
Неизвестный selector возвращает false. Select передаёт наборы как изменяемые
выходы WinSock. Умножение таймаута выполняется в 32 битах без нормализации:
`FFFFFFFF * 1000` становится signed microseconds `-1000`.

Factory требует явно установленного общего host; прямой constructor может
принять его отдельно. Отсутствие host вызывает явную ошибку. Общий счётчик и
наборы находятся в этом host, который представляет одну среду движка.

Проверены законченные операции и освобождение при заданных ответах внешних
служб. Работа с настоящими сокетами, взаимодействие сетевых менеджеров и
потоков остаются за границей компонента. Нет доказанного PS2-аналога.
Оригинал не проверяет null hostent, неинициализированный hostname при отказе
gethostname и длину accept свыше 16: эти аварийные области не выдаются за
переносимое поведение. Адаптер должен предоставлять валидные hostname/hostent,
а длина accept ограничена 16 с явной ошибкой при выходе за эту границу.
