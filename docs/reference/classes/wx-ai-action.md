# wxAIAction

Базовое действие AI, class ID `490A6EB5`, регистрационная и физическая база — `spBaseObject` (`415352A1`). Подтверждённая переносимая часть находится в [wxAIAction.h](../../../Winx/Code/wxAIAction.h) и [wxAIAction.cpp](../../../Winx/Code/wxAIAction.cpp). Обзор 35 известных потомков и их размеров: [семейство AIAction](../../game/ai/ai-action-family.md).

Реализованы construction defaults, RTTI/factory/clone, очистка destination при Copy, notification-forwarding и простые virtual hooks. Поиск пути и два крупных movement hooks исследованы, но ещё не перенесены в общий код; наличие класса не означает готовности AI персонажа.

## Notification и жизненный цикл

Notification читает первое 32-битное слово сообщения. При code `1C` сначала вызывается собственный virtual PC slot `24` (переносимый `vfunc_2C`). Затем поле current `+10` читается заново. Если оно ненулевое, тому объекту передаётся тот же указатель сообщения через notification virtual. Повторное чтение существенно: hook может заменить current.

Общая очистка сначала рассматривает current как заимствованную ссылку. Если у текущего действия собственный current ненулевой, вызывается его PC slot `2C` — сброс word; затем ссылка родителя обнуляется. Объекты native-контейнера, напротив, принадлежат действию и удаляются виртуально. После этого очищаются `wxPathFinder`, контейнер и `spBaseObject`. Переносимый `std::vector<unique_ptr<spBaseObject>>` выражает только подтверждённое владение, но не выдаётся за native tree layout или его порядок обхода.

Copy использует направление `source.vfunc_14(destination, manager)`. Он очищает current и owned-container получателя, затем вызывает пустой base Copy. Остальной payload базы не переносится и не сбрасывается. Поэтому clone, создающий свежий destination через factory, сохраняет constructor defaults, а не runtime-путь, owner или таймер source.

## Открытые movement hooks

PC slot `40` принимает целевую позицию. Он ставит внешний флаг owner в true и сравнивает квадрат расстояния с literal `10000.0f`. При меньшем расстоянии флаг снимается и возвращается true. Иначе вызывается общий path/movement helper, внешняя команда получает `1.0f`, возвращается false. PS2 код использует те же связи и literal; его EE-пролог содержит `SQ/LQ`, поэтому полное generic-MIPS исполнение не заявляется.

PC slot `3C` работает с целевым объектом и порогом расстояния: читает обе позиции, учитывает текущую цель owner, collision/visibility helper, path helper и угловую коррекцию команды движения. Его полный контракт и общий helper `58EA90` ещё требуют отдельных входных графов и differential-проверок. В переносимом классе эти два virtual slots намеренно отсутствуют: успешная заглушка исказила бы поведение потомков.

Portable-класс не совместим с native layout и не предназначен для подстановки в память игры. Реальные scene root, navigation graph, owner/character/movement records и derived AIAction остаются внешней границей текущей реализации.
