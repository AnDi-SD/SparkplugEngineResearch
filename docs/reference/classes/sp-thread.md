# spThread

Абстрактный интерфейс потока выполнения в известной PC сборке. Class ID
`0x3DFE3B16`, регистрационная база `spCrossPlatform` (`0x20A72504`), фабрика
отсутствует. Общие исходники —
[spThread](../../../Sparkplug/Code/Sparkplug/spThread.h).

Физический объект содержит отдельный первичный thread interface vptr в начале
и `spCrossPlatform` subobject со смещения `+4`. Базовый prefix занимает `0x20`
байт: uint32 параметр тела находится по `+0x18`, непрозрачный байт — по
`+0x1C`; конструктор обнуляет оба. Три байта `+0x1D..+0x1F` не записываются.
Переносимая иерархия объединяет интерфейсы без заявления о native ABI.

Первичный интерфейс содержит семь операций: Create, Wait, проверка активности,
Resume, Suspend, Sleep и Terminate. Эти имена описывают подтверждённые вызовы
Win32 в [spPCThread](sp-pc-thread.md), точные исходные имена API не восстановлены.
Вторичный интерфейс предоставляет обычные RTTI, Clone и NamedCopy.

Смысл непрозрачного байта за пределами его очистки в Resume не установлен.
Параметр тела отделён от аргумента Win32 start routine: start routine получает
адрес полного объекта, а не значение uint32 поля `+0x18`.
