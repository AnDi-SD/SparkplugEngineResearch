# spTimer

Общие исходники: [spTimer.h](../../../Sparkplug/Code/Sparkplug/spTimer.h),
[spTimer.cpp](../../../Sparkplug/Code/Sparkplug/spTimer.cpp).
Класс `149C778B` физически наследует `spBaseObject` на PC и PS2;
регистрационная база — `415352A1`. Native размер обеих платформ — `0x24`.
Portable представление сохраняет поведение и не является совместимым ABI.

| Offset | Состояние |
| --- | --- |
| `00–0F` | `spBaseObject` |
| `10` | байт активности, default `0` |
| `14` | unsigned накопление, default `0` |
| `18` | unsigned отсчёт последнего запуска, default `0` |
| `1C` | байт включения лимита, default `0` |
| `20` | unsigned лимит, default `0` |

Паддинг `11–13`, `1D–1F` не инициализируется. Native constructor принимает
байт: любой ненулевой аргумент вызывает часы и запускает таймер. Default factory
создаёт остановленный таймер. Clone создаёт объект с начальными значениями;
унаследованный Copy — успешный no-op, собственное состояние не переносится.
Destructor выполняет только cleanup `spBaseObject`.

Аналитические операции `StartForAnalysis`, `StopForAnalysis`, `ResetForAnalysis`
соответствуют PC `6BE2D0`, `6BE2F0`, `6BE3C0` и PS2 `1E7830`, `1E7790`, `1E7860`.
Start получает один отсчёт, записывает его в `18` и ставит active `1`;
накопление сохраняется. Reset сначала обнуляет `14`, затем делает такой же запуск.

Stop не проверяет активность. При выключенном лимите он получает один отсчёт,
прибавляет `sample−startedAt` по modulo 2³² и очищает active. При включённом
лимите первый отсчёт сравнивается с limit строго по unsigned `>`: превышение
прибавляет limit; равенство и меньшие разности вызывают часы второй раз и
прибавляют разность второго отсчёта без повторного ограничения. Поэтому результат
может превысить limit, а повторный Stop повторно накапливает время от прежнего старта.

Байт лимита читается до первого вызова часов. Start и Reset записывают timestamp
после вызова; Stop читает timestamp и накопление после соответствующего вызова.
Эта последовательность сохраняется при изменении полей чужим callback.

Часы — явная внешняя служба: PC `WINMM.timeGetTime` через IAT `6D9454`,
PS2 оригинальный wrapper `1E7980`. Host предоставляет отдельный unsigned отсчёт
на каждый вызов. Реализация ОС, аппаратура и PS2 wrapper остаются открытыми.
Missing provider отклоняется до изменения состояния; это защита нашего API.
Native setter names, единицы wrapper PS2 и полная глобальная политика часов
не выводятся из этого компонента.
