# `wxGlyphState`

`wxGlyphState` (Class ID `1928C37D`) — потомок `wxCharacterState` с selector `37`. [Общая реализация](../../../Winx/Code/wxGlyphState.cpp) сохраняет собственные hooks PC/PS2. Исходный размер — `3C` на обеих платформах, собственных полей нет. Переносимый объект не является игровым ABI.

| Операция | PC | PS2 |
| --- | ---: | ---: |
| Фабрика | `5A7BA0` | `2CD9E0` |
| Vtable | `706A90` | `493600` |
| Обновление, PC slot `30` | `5A7C80` | `2CD6A0` |
| Проверка перехода, PC slot `34` | `523770` | `2CD850` |

Обновление сначала применяет `key &= FF87FF80`. Затем читает слово внешнего owner-объекта: PC `owner+124 -> word14C`, PS2 `owner+130 -> word158`. Полный enum и исходное имя этого поля остаются неизвестными. Четыре значения выбирают дополнительную маску и вариант:

| Значение | Дополнительная маска | Добавляемые биты |
| ---: | --- | --- |
| `15` | `F07FFFFF` | `0` |
| `34` | `F0FFFFFF` | `00800000` |
| `44` | `F17FFFFF` | `01000000` |
| `46` | `F1FFFFFF` | `01800000` |

Остальные значения оставляют результат первой маски. PC использует таблицу switch, PS2 — последовательность сравнений с теми же значениями. Lookup выполняется после выбора варианта. При отличии найденного handle от pending запускается playback с `mode=false`, `interrupt=true`, без освобождения старого handle; новый сохраняется после playback. Одинаковый handle пропускает запуск. Во всех случаях в конце обнуляется control word `4`.

Переход `34` всегда вызывает completion consumer с текущим handle и `consume=true`, включая пустой handle. Target не используется. Вход и выход, reset, прочие hooks используют [wxCharacterState](wx-character-state.md). Вход базы освобождает handle и вызывает виртуальное обновление, поэтому выполняет описанный выбор варианта. Copy пуст; clone сохраняет selector `37`, начальные flags и пустые привязки. Деструктор не останавливает анимацию.

[wxGlyphStateHost](../../../Winx/Analysis/Host/wxGlyphStateHost.h) предоставляет чтение внешнего слова и общие анимационные службы без успешной реализации по умолчанию. [C++ проверка](../../../Winx/Tests/wxGlyphSpiritStateTests.cpp) охватывает выбор варианта, одинаковый/новый handle, порядок callbacks, clone и completion. Полная игровая сцена остаётся внешней зависимостью.
