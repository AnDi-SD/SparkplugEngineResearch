# wxIcyAttackAIAction

`wxIcyAttackAIAction` имеет class ID `510661EC`; регистрационная и физическая
PC-база — [`wxAIAction`](wx-ai-action.md). PC allocation занимает `0x480` байт.
Фабрика находится по адресу `5C1C00`, primary table — `70A0C0`, getter
`5C1580` возвращает runtime record `7679D0`. Прямая передача того же receiver
конструктору `5C1370`, его вызов базового `58FF00` и установка своей таблицы
подтверждают физический префикс независимо от регистрационной связи.
[PC layout](../../../Winx/Analysis/PC/wxIcyAttackAIActionAbi.h) отделён от
портативного C++ объекта.

[Реализация](../../../Winx/Code/wxIcyAttackAIAction.h) предоставляет полную
PC Entry `5BE230` для явно переданного состояния уже существующего объекта
и существующего [`wxCharacterRegistry`](wx-character-registry.md). Это
ограниченный профиль состояния после конструирования; нативные конструирование,
клонирование, разрушение и владение вложенными полями остаются открытыми.

## Entry с существующим Registry

Entry читает существующий Registry из global `765AD8` и вызывает настоящий
selector `4E21D0` по адресу `5BE24B`, возвращаясь к `5BE250`. Она не читает
owner или command. Портативный код каждый раз читает поле `existing` общей
[storage binding](../../../Winx/Analysis/Host/wxCharacterRegistryBinding.h)
и напрямую вызывает общую реализацию Registry. Binding предоставляет объект
Registry; выбор цели выполняет сам selector.

После выбора Entry записывает полученный указатель в `3A8`, затем выполняет
следующие операции в нативном порядке:

1. Обнуляет words `3B0`, `3B8` и отдельно bytes `3AC`, `3AD`.
2. Обнуляет words `3C0`, `3B4`, `3C4`, `410`.
3. Обнуляет отдельно bytes `3E8`, `3E9`, `3EB`.
4. Записывает word `3BC = 1`, word `3C8 = 2` и byte `468 = 1`.

Другие поля, padding и родительское состояние сохраняются. В частности,
записи bytes не затрагивают `3AE..3AF`, `3EA` и `469..47F`. Имена и более
широкая семантика этих собственных полей не установлены. Аргумент Entry
не используется; её выходу не приписан Boolean-контракт.

Общий selector немедленно возвращает ненулевой cache. Иначе рассматривает
только первую группу и первый указатель её target vector. Пустые группы и
пустой первый vector дают null; первый payload непустого vector сохраняется
в cache даже при null. Последующие группы не просматриваются. Completed-null
допустим для Icy и всё равно приводит ко всем пятнадцати собственным записям.

## Состояние и границы профиля

Портативный конструктор принимает заимствованный target и полные raw bytes
`3AC..47F` длиной 212 байт. Закодированные там нативные указатели не приводятся
к host pointers, не разыменовываются и не принадлежат facade. Binding,
Registry и его заимствованные записи должны жить дольше операции. Внутри
синхронного вызова входы стабильны; замена binding, cache или первого target
между вызовами является явным входным управлением.

Профиль по умолчанию — Unqualified. Разрешённый профиль требует пустого
унаследованного action graph и admitted Registry с валидными borrowed views.
Отсутствующий Registry или отказ общего selector дают аналитический отказ
до собственных записей. Это не моделирует холодное создание Registry,
нативные faults, повреждённые vectors или rollback.

Generic factory и Clone выбрасывают `logic_error`, Copy возвращает
аналитический false; Notify и остальные неподтверждённые hooks сообщают
отказ. Уничтожение портативной facade сохраняет заимствованные binding,
Registry и targets. [Проверки](../../../Winx/Tests/wxIcyAttackAIActionTests.cpp)
покрывают общий selector, raw состояние, соседние bytes, повторные вызовы,
смену существующей привязки и границы отказов.

Нативный полный lifetime, global producer, физическое наследование Registry,
владение контейнерами и PathFinder, активные attack-state bodies, прочие
методы, PS2, connected gameplay и полнота класса остаются неподтверждёнными.

## Exit с общим Reset и существующей записью

PC Exit `5BE2C0` читает `own20 → owner144 → actor130` и вызывает virtual
slot `04` command record с таблицей `703090`. Настоящая общая процедура
[`5992E0`](../../game/ai/ai-command-reset.md) полностью завершается перед
возвратом к `5BE2D7`. Затем Exit читает существующий global `765AD4`,
записывает byte `510 = 1` его записи и только после этого обнуляет собственный
target `3A8`. Остальные command bytes, raw own tail, родительское состояние
и другие байты предоставленной внешней записи сохраняются. Метод не получает
выдуманного Boolean-контракта.

Переносимый код вызывает настоящую общую
[`wxAICommandRecordForAnalysis`](../../../Winx/Code/wxAICommandRecordForAnalysis.h)
и затем получает от отдельного
[Exit host](../../../Winx/Analysis/Host/wxIcyAttackAIActionExitHost.h)
живую ссылку на измеренный byte `510`. Host разрешает только структурные
заимствованные данные; он не выполняет Reset и не сообщает готовый результат
операции. Нативное имя класса внешней записи, её RTTI, конструктор, полный
размер и producer global остаются неизвестными. Предоставленный view задаёт
только доступное живое backing storage, не размер нативного allocation.

Exit имеет отдельный default-unbound, Unqualified профиль. Разрешение Entry
не разрешает Exit автоматически. Разрешённый Exit требует пустого inherited
action graph, admitted command record и стабильные живые borrowed views.
Внешние привязки могут явно меняться между вызовами. Уничтожение facade
сохраняет command, внешнюю запись и target живыми.

Отсутствующие owner, actor, command или неподходящий профиль/tag общей записи
дают аналитический отказ перед зависимыми эффектами. Доступность внешнего
byte проверяется после общего Reset: если backing storage отсутствует,
завершённый command Reset сохраняется, а старый own target ещё не очищается.
Это граница admission, а не нативный fault, rollback или реализация холодного
создания через `401290`. Aliasing, reentry, конкурентные изменения и владение
внешними данными не квалифицированы. Полный native Entry→Exit цикл не следует
из двух независимых профилей методов.
