# spNetworkPacket

PC-пакет с заголовком и собственным буфером данных. Общие исходники —
[spNetworkPacket](../../../Sparkplug/Code/Sparkplug/spNetworkPacket.h).
Class ID `0546DE34`, физическая база `spBaseObject`, native размер `28` hex.
PS2-регистрация в известных образах отсутствует. Разбиение на header и
translation unit аналитическое: исходный путь `spNetworkPacket.cpp` не найден.

## Поля и формат

| Смещение PC | Поле | Размер | Конструктор |
| --- | --- | --- | --- |
| `10` | Source | uint16 | `BAD0` |
| `12` | Destination | uint16 | `BAD0` |
| `14` | PacketType | uint16 | не инициализируется |
| `16` | UseTcp | uint8 | не инициализируется |
| `18` | PacketDataField1 | uint32 | `0` |
| `1C` | PacketDataField2 | uint32 | `0` |
| `20` | Size | uint16 | `0` |
| `24` | owned payload | pointer | отдельные 256 байт |

Payload и padding `17`, `22..23` не инициализируются. Portable representation
сохраняет неизвестные PacketType/UseTcp через optional и отдельно отмечает
известный префикс payload. Нулевые служебные байты portable allocation не
считаются исходными значениями и не доступны как известные данные пакета.

Wire format little endian без padding: семь полей в порядке таблицы,
затем Size байт payload. Заголовок занимает **17 байт**, формат `<HHHBIIH`.
UseTcp передаётся как raw byte, включая `255`; нулевой тип/байт также сохраняются.

## Чтение и запись

Read сначала получает размер и позицию stream, игнорируя статусы этих запросов.
Оба выходных слова перед запросами равны нулю. При unsigned `position >= size`
возвращается false без чтения и сообщения. Иначе семь полей читаются отдельно,
затем выполняется чтение payload. Отказ сообщает исходный текст конкретного
поля и возвращает false. Уже прочитанные поля и позиция остаются изменёнными;
сам packet Read не закрывает stream.

Write последовательно передаёт семь полей и payload отдельными вызовами.
Первый отказ сообщает исходный текст ошибки, вызывает `Close` stream,
игнорирует результат закрытия и возвращает false. У двух data fields текст
ошибки одинаков. Успешная запись сохраняет пакет и оставляет stream открытым.
Короткий вход не откатывается и не трактуется как целый пакет.

Внешняя диагностика передаётся через обязательный при ошибке
[host](../../../Sparkplug/Analysis/Host/spNetworkPacketHost.h).
Общие stream и memory stream подключаются напрямую.

## Копирование и границы

Clone создаёт новый packet и отдельный payload, регистрирует пару и вызывает
унаследованный Copy `spBaseObject`. Header и payload исходного пакета не
переносятся. Деструктор освобождает payload перед базой и памятью packet.
Проверка — `SparkplugNetworkPacketTests`.

В оригинале размер payload не проверяется относительно 256-byte allocation.
Portable версия сохраняет уже обработанный заголовок и явно отклоняет transfer
за этой границей. Она также отклоняет запись неизвестных native type/TCP/payload
байтов. Это наши защитные ограничения, а не восстановленные игровые проверки.
Соответствие ошибок stream установлено для отказов без изменения целевого
буфера. Собственная диагностика и ошибочные ветви packet восстановлены;
полный error subsystem внешнего stream и исходные правила ограничения
размера в сетевых callers остаются отдельной задачей.
