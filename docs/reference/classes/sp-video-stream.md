# spVideoStream

ClassID `0x27DE5AF5`, регистрационная база `spCrossPlatform`. Известны PC и PS2;
обе регистрации не содержат factory. Собственные начальные поля и освобождение
буфера восстановлены в [общем классе](../../../Sparkplug/Code/Sparkplug/spVideoStream.h).
Унаследованный clone возвращает null. Имена исходных методов неизвестны.

## Хранение

Размер PC-объекта — `0x24`. Primary interface расположен по `+0`, а объектная
Named/CrossPlatform view — по `+4`. Constructor обнуляет два байта `+0x18/0x19`,
указатель `+0x1C` и слово `+0x20`; padding `+0x1A/0x1B` не записывает. PS2
constructor отдельно подтверждает те же собственные операции.

Destructor освобождает ненулевой буфер `+0x1C` до разрушения Named-части.
Назначение двух байтов и слова остаётся неизвестным. Аналитический setter
состояния и передача owned-буфера нужны для подготовки входов; это не
восстановленные API создания видеопотока. Нативный layout описан в
[PC ABI](../../../Sparkplug/Analysis/PC/spVideoStreamAbi.h).

Primary interface PC-базы содержит abstract entries. Их работа не подменяется
успешными операциями; поведение конкретного PC-класса описано отдельно в
[spPCVideoStream](sp-pc-video-stream.md). Чтение файлов, декодирование и
воспроизведение видео здесь не установлены.
