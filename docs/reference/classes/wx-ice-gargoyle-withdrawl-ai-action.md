# wxIceGargoyleWithdrawlAIAction

`wxIceGargoyleWithdrawlAIAction` имеет идентификатор `0x239516B1` и физическую
базу `wxAIAction`. Написание `Withdrawl` сохранено из регистрации оригинала.
Размер — `0x3B8` на PC, `0x3BC` на PS2. PC factory находится по `0x5AE8F0`,
таблица из 20 слотов — по `0x709170`. PS2 factory — `0x2530F0`, таблица —
`0x4928D0`; перед 20 слотами стоят два нулевых слова.

Собственные четыре поля, начальные значения, заимствование Node, Entry, Exit,
Query, порядок Copy и общее наведение описаны в
[общем контракте пары](wx-ice-gargoyle-claw-ai-action.md#общие-pc-операции).
Оба класса сохраняют отдельное наследование от `wxAIAction`; общие операции
реализованы одной композицией в исходнике. Исходные имена файлов предполагаются.

## Фаза 1

Общий Update `0x5AE8C0` сначала завершает наведение `0x5AEB40`, затем читает
фазу. Фаза 0 использует общий `0x5AEDB0`; фаза 1 вызывает собственный слот `48`,
операцию `0x5AEA70`. Иные фазы сохраняют результат наведения без новой стадии.

Стадия получает LOCAL-позицию `20` узла владельца и cached WORLD-позицию `74`
сохранённого узла цели. Разности координат и сумма квадратов сохраняются в x87
без промежуточного float store. Сравнивается выражение `(z*z + y*y) + x*x`
с `22500.0f`.

При строго меньшем значении фаза, затем отметка времени становятся нулевыми.
Равенство оставляет их прежними. Во всех случаях стадия продолжает выполнение:
получает команду и записывает motion `04 = 1.0f`, повторно получает команду,
рассчитывает yaw по ранее снятым позициям через `0x5970B0` и записывает heading
`08`. Близость не вызывает ранний выход.
Для motion используется ранее сохранённый владелец. После записи motion
указатель владельца действия читается заново для получения команды heading.

Два остальных обычных bool update используют буквальное true. У Withdrawl нет
дополнительного слота проверки высоты Claw. Notify не пересылает уведомление;
Exit очищает только два командных байта и заимствованный указатель, сохраняя
фазу, отметку и слово неизвестной роли.

## Граница реализации

По умолчанию профиль `HooksOnly` отказывает в активном Update до наведения.
`PcFiniteGeometry` допускает конечные координаты в `[-1024, 1024]`, уже созданные
общие сервисы и валидные заимствованные узлы/команды. Строгое сравнение суммы
квадратов переиспользует общий nearest64 accumulator, а yaw — общий planar
helper с внешней границей `MSVCR71!_CIacos`/host `acos`. Малое отличие от порога
не должно исчезать из-за замены всей арифметики host `double`.

Entry непосредственно читает настоящий текущий `wxTargetManager`; host
связывает только слово `18` его текущей заимствованной записи с Node. Query
вызывает настоящий общий Perception и не обновляет сохранённый узел. Холодный
менеджер и неизвестная привязка имеют отдельные диагностические отказы.

PS2 ABI и полная таблица сохранены, её стадии и floating arithmetic отдельно
не квалифицированы. Тело селектора, холодные ресурсы, унаследованный pathfinding,
произвольные состояния базового класса и игровой цикл остаются открытыми.
Полнота класса и произвольная побитовая тождественность CRT не заявляются.
