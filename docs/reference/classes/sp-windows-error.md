# spWindowsError

`spWindowsError` (`0x1DE8113F`) — PC-класс, непосредственно производный
от [spError](sp-error.md). Его нативный размер `0x28`; дополнительных полей нет.
Общая реализация: [spWindowsError](../../../Sparkplug/Code/SparkBasePC/spWindowsError.h).
Размещение файлов и имена portable-методов аналитические.

Собственный formatter читает только diagnostic message в `+0x20`. При нулевом
указателе или пустой строке он возвращает пустой текст. Непустое сообщение
оборачивается в `(message)`, без ведущего пробела. Код причины и severity
на выбор текста не влияют. Собственное имя ошибки — `windows error`.
Унаследованные formatters отдельно добавляют severity и source/line.

В оригинале используется общий scratch buffer из 256 байт. Возвращаемый текст
ограничен 255 байтами; при длинном сообщении закрывающая скобка отсекается.
Собственный formatter не вызывает Win32 и не преобразует числовой OS error:
сообщение должно быть подготовлено вызывающей стороной.

Factory создаёт базовые пустые поля и устанавливает собственную vtable. Clone
регистрирует пару объектов, затем вызывает пустой copy slot исходного объекта.
Полезная нагрузка, severity, source и цепочка ошибки в clone не переносятся.
Нативный diagnostic message заимствован; destructor его не освобождает.

Portable-код использует общий `spError` и его RTTI/clone/manager-контракты.
Владение `std::string` и независимый возвращаемый текст являются адаптацией;
общий нативный scratch buffer и его побочные записи не воспроизводятся.
Получение системного сообщения вызывающей стороной остаётся отдельной границей.
