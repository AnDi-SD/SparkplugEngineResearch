# spNavigationGraph

Class ID — `0x188A161F`. Навигационный граф связан с render-node основой и хранит наборы навигации, порталы и таблицы переходов между ними.

Известное представление перехода содержит байтовый selector следующего портала и список альтернатив, каждая из двух байтов. Значение по умолчанию selector в общей реализации — `255`. Полная runtime-семантика выбора пути не установлена; успешный разбор структуры не означает готовности полного pathfinding.

Игровой `wxPathFinder` ищет в сцене `Navigation Graph`, затем `nv_group`. Отсутствие нужного графа оставляет навигационную ссылку пустой. Это правило игрового потребителя не следует смешивать с самим форматом графа.
