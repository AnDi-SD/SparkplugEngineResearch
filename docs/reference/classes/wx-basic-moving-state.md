# wxBasicMovingState

`wxBasicMovingState` имеет Class ID `1D533B89` и физически наследует
`wxCharacterState` на PC и PS2. Его собственный конструктор устанавливает
selector `+10` в ноль. Размер объекта на обеих платформах — `3C` байт.
Переносимый класс находится в [wxBasicMovingState.h](../../../Winx/Code/wxBasicMovingState.h)
и [wxBasicMovingState.cpp](../../../Winx/Code/wxBasicMovingState.cpp).

| Контракт | PC | PS2 |
| --- | ---: | ---: |
| Factory | `402B40` | `3F3EA0` |
| Constructor | — | `2C7C00` |
| Vtable | `6F8810` | `49A3F0` |
| Permission, slot 13 | `517790` | `2C7B40` |
| Movement request, slot 12 | `5177E0` | `2C77E0` |

При проверке разрешения перехода target `10` или `11`, текущий selector,
отличный от `9`, и нулевой pending handle немедленно дают true. В остальных
случаях вызывается общий потребитель `4FB330`/`2A6C30` с receiver из поля
`+18`, handle из `+24` и `consume=1`; возвращается его результат. Потребитель
может обнулить совпавшие pending записи receiver. Переносимый код вызывает
существующий [wxCharacterStateHost](../../../Winx/Analysis/Host/wxCharacterStateHost.h),
который предоставляет эту операцию; фактическая привязка receiver к игре ещё
не восстановлена.

В slot 12 при текущем selector, отличном от `9`, оригинал читает величину движения
из объекта владельца и меняет первый 32-битный ключ запроса. При величине меньше
`0,2` выбирается младшая группа битов; флаг движения дополнительно устанавливает
бит `00800000`. При `0,2 ≤ x < 0,5` получается средняя группа, а начиная с `0,5`
— старшая. Для входного `FFFFFFFF` итоговые значения соответственно
`F01F800F`, `F09F800F` с флагом, `F01F805F` и `F09F805F`. Сравнения с NaN
идут по старшей ветви. После поиска анимации совпавший pending handle
сохраняется без повторного запуска; при изменении старый освобождается и новый
запускается общими методами `wxCharacterState`. Величину и флаг движения даёт
[wxBasicMovingStateHost](../../../Winx/Analysis/Host/wxBasicMovingStateHost.h).

PC factory, пустой clone и удаление проверены исполнением оригинала. PS2
constructor, vtable и slot 13 проверены отдельно. Описанная ветвь slot 12
сопоставлена по инструкциям PC `5177E0` и PS2 `2C77E0`; пять пар оригинальных
префиксов также дошли до исходного поиска анимации с теми же ключами. Переносимый тест
проверяет пороги, маски, порядок вызовов и повторное использование handle.
Путь selector `9` с исходным генератором случайного числа и дополнительными
службами пока явно сигнализирует о невосстановленной части.
