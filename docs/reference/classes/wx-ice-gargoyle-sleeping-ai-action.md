# wxIceGargoyleSleepingAIAction

Registered ID `3C7B1A31`, base `wxAIAction`. The portable component implements its own Entry, Exit, Wake, Notify, Tick, both stage bodies and two-word Copy. Native layouts are `3B0` bytes on PC and `3B4` on PS2; the last two words are phase and stamp. Host configuration is separate from those layouts.

Entry clears both words. Wake changes any phase other than one to phase one and stamp zero; repeated Wake in phase one preserves the stamp. Notification `27B2` invokes Wake without forwarding to the current child. Other notifications use the shared AI base, including its `1C` virtual query and subsequent child forwarding. Exit clears command byte `1B` without resetting phase/stamp.

In phase zero, a zero stamp sets command byte `1B` and copies the current GameTimer time. In phase one, a zero stamp clears that command byte, stores current time plus100 with uint32 wrapping, then ensures TargetManager presence. A nonzero stamp instead tests the character state word and requests owner selector `(0,0)` when that word is zero. Other phases do nothing. The stamp is an initialization latch: neither stage compares it with time. Current time zero and wrapping plus100 back to zero deliberately repeat initialization on the next Tick.

Both stage bodies run directly in the common source. The host binds borrowed command/state records, returns the real GameTimer's shared `spTaskTimer` prefix and exposes the foreign selector entry. The source reads the actual timer state. PC `765AF0`/`59E090` and PS2 `49FC78`/`2A10F0` identify `wxTargetManager` (`3582501B`). The default `ExistingOnly` profile preserves the original bounded interface: a missing manager reports `UnqualifiedTargetManagerAcquisition` after the command/stamp prefix. The Boolean Tick wrapper's false on that analytical guard is ours, while ordinary native Tick returns true. The selector result describes only the caller boundary.

An explicit `BoundedPcAcquisition` profile instead uses the real TargetManager singleton and constructor. It admits the existing successful AssetManager path/plain-Node/null-Scene/stable canonical reference domain described by [TargetManager](../../game/wx-target-manager.md). A typed binding supplies borrowed services and application-owned `vector<unique_ptr<wxTargetManager>>` storage. Its configuration lookup is stable and has no side effects; validating its platform is an analytical preflight, not a newly inferred native callback. Sleeping directly constructs the real common TargetManager, republishes the captured factory result after construction, then retains it in the application store. Action destruction does not delete that manager.

PC composition evidence covers cold construction, wrapped stamp and repeated Tick, an external retained Node reference, loader mutation of command/stamp, reentrant Sleeping Tick against the constructor-published singleton, and a nested real TargetManager constructor that changes the singleton before the outer captured result is republished. Existing GameTimer is required. PS2, missing bindings, cold clock acquisition, allocator/resource failures and general startup remain unqualified; caught host exceptions report analytical refusal without a native rollback claim.

PC evidence uses actual action factories/RTTI and the real GameTimer. PS2 method evidence uses a construction-proven table, guarded borrowed layouts and the explicit scalar/SP stack-spill profile; it is separate from PC lifetime and full Copy. PS2 own Copy suffix is conditional on parent success. Native allocator failures, null/faulting gameplay graphs, startup outside the admitted PC resource domain and full AI/application execution remain unqualified.
