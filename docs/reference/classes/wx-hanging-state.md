# wxHangingState

Class ID `3AE37B41`, физическая и регистрационная база `wxCharacterState`.
Native размер PC/PS2 — `40`, selector — `17`. Поле `3C` — uint32 счётчик,
обнулённый конструктором; каждый update увеличивает его с переполнением.
Базовые Copy и Reset сохраняют `3C`, clone получает constructor defaults.
Исходники — `Winx/Code/wxHangingState`, проверка — `WinxHangingStateTests`.

Update `30` читает угол entity (`15C` PC / `168` PS2) и движение прямого
control владельца (`owner12C/138`, float word `4`). При движении `< 0.2f`
обнуляет направление. Иначе угол строго ниже `pi/4` задаёт направление `40`,
строго выше `3*pi/4` — `30`; обе ветви устанавливают consumer speed `1.3f`
перед записью нового key. Средняя область, включая обе границы, обнуляет
направление и прямой control word `4`. После этого применяет `F000007F` и
выполняет lookup; изменённый handle освобождает pending и запускает mode=true,
interrupt=true. Совпадение handle пропускает playback, но не увеличение `3C`
и не предшествующее изменение speed/control.

PC верхняя граница использует произведение float32 `3F490FDB` на `3` без
float32 spill; PS2 использует `4016CBE4`. PC сохраняет проверенные unordered
ветви; профиль PS2 ограничен конечными float32 и signed zero.

Первый вход `1C` обнуляет слово `504` внешнего игрового менеджера, затем `3C`.
Key получает `(key & FFA0000F) | 00200000`. При owner kind `1`, `17` или `18`
сравнивает два node word (`78` PC / `74` PS2), найденных через entity control:
второе значение строго больше первого выбирает `00800000`, иначе — `01000000`.
Нулевой первый node выбирает второй вариант; при ненулевом первом второй
указатель обязателен. Остальные kind поворачивают owner node на pi вокруг
оси `(0,1,0)` и применяют `F07FFFFF`. Kind читается из owner word `134` PC /
`140` PS2, не из регистрационного Class ID.

После lookup вход запускает mode=false, interrupt=true без освобождения
старого pending, сохраняет handle, очищает flag `1C` и возвращает false.
Повторный вход потребляет completion: при незавершении возвращает false;
при завершении ставит speed `1.25f` и вызывает базовый вход с виртуальным
update. Последний увеличивает `3C` после его первоначального обнуления.

Первый выход `20` обнуляет manager word `504`, освобождает pending, подготавливает
movement cache без очистки найденного node и выставляет entity-control flag
(`178` PC / `184` PS2). Key получает `(key & FFD8000F) | 00400000`, затем
выбирается вариант по owner packed word (`144` PC / `150` PS2):

| Условие | Вариант |
| --- | --- |
| Low nibble `5`, угол прямого control word `8` внутри обеих границ `pi/4..3*pi/4` | `01800000` |
| Low nibble `5`, угол вне интервала | `01000000` |
| Low nibble `0`, bits `180000` не равны `100000`, счётчик ненулевой, eligibility byte ненулевой, угол entity строго ниже `pi/4` | Вариант `0`, прямой control byte `1B` обнулён |
| Остальные случаи | `00800000`, прямой control byte `1B` равен `1` |

Eligibility byte расположен в entity control `184` PC / `190` PS2; угол —
entity float `158` PC / `164` PS2. Эта ветвь не читает их без выполнения
предыдущих условий. Nibble `5` сохраняет byte `1B`. Затем lookup, mode=false,
interrupt=true, запись handle, очистка flag `1E`, полное завершение движения
и false. Прямой control word `4` здесь не очищается.

Повторный выход при незавершённой animation только завершает движение и
возвращает false. При completion обнуляет entity flag, захватывает position
owner node и передаёт её actor control, подготавливает movement, обнуляет
прямой control word `4`, ставит speed `1.0f` и возвращает базовый выход.
PS2 записывает position в control `144/148/14C`; при наличии control pointer
`1F0` также суммирует её с node words `70/74/78` и сохраняет результат в
`15C/160/164`. PC делает это через внешнюю службу `4E41C0`; её полный body
не объявляется восстановленным по одному вызову.

`wxHangingStateHost` явно отделяет внешние owner/control/node/consumer/manager
объекты. Общий movement cache остаётся в базе состояния. Matrix rotation,
actor-control position setter и внешняя сцена остаются обязательными host
границами; PS2 matrix/accumulator math не заменяется PC-арифметикой.
Permission `34` наследует true. Собственные методы подтверждены в указанном
объёме; полное игровое соответствие класса ещё не закрыто.
