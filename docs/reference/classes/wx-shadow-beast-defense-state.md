# wxShadowBeastDefenseState

Class ID `43634D72`, физическая и регистрационная база `wxCharacterState`.
PC и PS2 выделяют `0x44` байт, selector `10` равен `8`. Конструктор обнуляет
byte `3C`, но не записывает padding `3D..3F` и pointer `40`. Базовый Reset
не меняет собственные поля. [Заголовок](../../../Winx/Code/wxShadowBeastDefenseState.h),
[реализация](../../../Winx/Code/wxShadowBeastDefenseState.cpp).

Вход `1C` двухфазный. При once-флаге базы `1C` освобождает pending,
задаёт `(key & F0200180) | 00200180`, ищет и запускает анимацию с mode=false,
interrupt=true. Сохраняет handle, очищает once-флаг и **после playback**
обнуляет byte `3C`. Затем обнуляет control word `4` и возвращает false.
Повторный вход потребляет completion-записи, в том числе при null pending.
При завершении уведомляет `owner24` сообщением `27D1`, вызывает контроллер
из pointer `40` с аргументами `(1,1)` и передаёт выполнение базовому входу.
База освобождает pending и вызывает виртуальное обновление. При ожидании
очищает control word и возвращает false.

Выход `20` при once-флаге `1E` отправляет `27D2` и вызывает контроллер `(0,1)`
**перед освобождением pending**. Задаёт `(key & F0400180) | 00400180`, запускает
mode=false, interrupt=true, сохраняет handle и очищает `1E`. Повторные вызовы
потребляют completion; при завершении вызывают базовый выход. До завершения
обнуляют control word и возвращают false.

Update `30` задаёт `(key & F0000180) | 00000180`. При новом handle освобождает
pending, запускает mode=true, interrupt=true и сохраняет результат. При
совпадении handle дальнейших действий нет. Byte `3C` update не меняет.

Пакет уведомления состоит из восьми 32-битных слов:
`[code,0,0,0,source,0,30,0]`. Получатель `owner24` может быть null: тогда
dispatch пропускается. Вызов контроллера остаётся обязательным. Его vslot
равен `34` на PC и `3C` на PS2; исходный тип неизвестен.

[Host](../../../Winx/Analysis/Host/wxShadowBeastDefenseStateHost.h) передаёт
заимствованные получателя и контроллер. Переносимый объект хранит pointer `40`
как optional: отсутствие значения обозначает неизвестную native-память,
а не null. Перед первой ветвью, использующей контроллер, вызывающий код
должен привязать его явно. Copy пуст; clone создаёт поля нового конструктора
без копирования контроллера или byte `3C`.

Проверка — `WinxShadowBeastDefenseStateTests`: обе фазы переходов, порядок
уведомлений и playback, completion, Reset, Copy, clone и обязательная привязка
контроллера. Внешние объекты, их обработчики и полная игровая интеграция
остаются открытыми.
