# `wxDispelState`

`wxDispelState` (Class ID `4600876A`) — потомок `wxCharacterState` с исходным selector `0`. [Общая реализация](../../../Winx/Code/wxDispelState.cpp) содержит собственные hooks PC/PS2. Исходный размер — `40` на обеих платформах. Собственный byte `3C` первоначально равен нулю; его семантика описана здесь как флаг отправки сообщения при выходе. Переносимый layout не является игровым ABI.

| Операция | PC | PS2 |
| --- | ---: | ---: |
| Фабрика | `5A6550` | `2CB600` |
| Vtable | `7067F8` | `4935B0` |
| Вход, PC slot `1C` | `5A6630` | `2CB320` |
| Выход, PC slot `20` | `5A66C0` | `2CB270` |
| Обновление, PC slot `30` | `523690` | `2CB310` |
| Проверка перехода, PC slot `34` | `5A6770` | `2CB460` |

Вход применяет `key &= FF807F80`, затем до lookup устанавливает byte `3C` в результат `(key & 0F800000) == 0`. Полученный handle запускается с `mode=false`, `interrupt=true` без освобождения прежнего pending handle и сохраняется после playback. Затем обнуляются control word `68` и word `4` в этом порядке. Результат — `true`.

Выход при установленном byte `3C` проверяет необязательный notification manager. При наличии менеджера отправляет восемь слов: `[2806, 0, 0, 0, this, 0, 22, 1]`. Затем, независимо от наличия менеджера, освобождает pending handle через общий stop/fade-протокол [wxCharacterState](wx-character-state.md) и возвращает `true`. Флаг не сбрасывается, поэтому повторный выход снова может отправить сообщение. Базовый reset также не меняет собственный byte `3C`.

Обновление только обнуляет control word `4`. Проверка перехода возвращает `true` при пустом handle; иначе запрашивает завершение с потреблением completion-записей. Target не используется. Copy унаследован от `spBaseObject` и пуст; clone имеет начальный byte `3C`, начальные флаги и пустые привязки. Деструктор не останавливает анимацию.

[wxDispelStateHost](../../../Winx/Analysis/Host/wxDispelStateHost.h) предоставляет control word `68` и optional manager. Структура сообщения описывает слова переносимо и не является native overlay. Адаптер не содержит успешной заглушки. [C++ проверка](../../../Winx/Tests/wxDispelStateTests.cpp) охватывает masks, lifecycle флага, сообщения, порядок callbacks и clone. Сцена, маршрутизация уведомлений и анимационные службы остаются внешними зависимостями.
