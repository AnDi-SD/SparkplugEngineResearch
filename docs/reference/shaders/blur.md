# Blur: четыре выборки и яркость

[Blur.hlsl](../../../Sparkplug/Shaders/PC/Blur.hlsl) объединяет восстановленные
стадии трёх внешних PC-ресурсов. Общая задача — подготовить четыре UV
и усреднить четыре texture samples; вариант pixel shader дополнительно
модулирует RGB яркостью.

| Entry point | Исходный ресурс | Стадия и профиль |
| --- | --- | --- |
| BlurVS | Blur.vsh | Vertex, vs_1_1 |
| BlurPS | Blur.psh | Pixel, ps_1_1 |
| BlurLuminancePS | BlurLuminance.psh | Pixel, ps_1_1 |

## Вершинная стадия

На вход приходят POSITION и UV из TEXCOORD. На выходе POSITION.xy
равен знаку входных x/y, POSITION.z=0 и POSITION.w=1. Нулевая входная
компонента остаётся нулевой; это не обычное умножение позиции на матрицу.

TextureSize в c0 и Distance в c1 задают смещения. Используются только
c0.x и c1.x: отдельный шаг по высоте текстуры не вычисляется.
Для S=TextureSize.x и D=Distance.x четыре выходных UV получают добавки:

| Выход | Добавка к входному UV |
| --- | --- |
| TEXCOORD0 | ((0.5−D)/S, 0.5/S) |
| TEXCOORD1 | ((0.5+D)/S, 0.5/S) |
| TEXCOORD2 | (0.5/S, (0.5+D)/S) |
| TEXCOORD3 | (0.5/S, (0.5−D)/S) |

Полутексельное смещение сохраняется во всех четырёх выборках.
Исходная программа не добавляет защиту от S=0.

## Pixel stages

Image0–Image3 соответствуют четырём текстурным входам s0–s3.
BlurPS усредняет все четыре RGBA с одинаковым весом 0.25;
alpha также усредняется. Из программы не следует, что вызывающий код
обязательно привязывает одну и ту же текстуру во все четыре входа.

BlurLuminancePS сначала получает средний RGB, затем его скалярную яркость
через dot с c1.xyz и умножает средний RGB на эту яркость.
Выходная alpha равна единице. Компонента c1.w и вклад исходной alpha
в яркость не используются; закомментированная инструкция не считается
частью алгоритма. Веса яркости задаются caller и не подменяются
фиксированным цветовым стандартом.

## Связь с runtime

[Контракт исходных программ](../../engine/materials/shader-contract.md)
отделяет формулы от ограничений старых GPU-регистров и последующих стадий.
Размер target, texture bindings, фильтрация, адресация и blending принадлежат
вызывающему проходу. Полная маршрутизация экранных эффектов в Remix
не выводится из наличия этих трёх ресурсов или их создания при старте.
