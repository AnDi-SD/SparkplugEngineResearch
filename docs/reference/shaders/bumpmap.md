# Bumpmap: tangent-space свет и normal map

[Bumpmap.hlsl](../../../Sparkplug/Shaders/PC/Bumpmap.hlsl) восстанавливает
две стадии внешнего PC-ресурса `Bumpmap.rfx`: `BumpmapVS` и `BumpmapPS`.
Vertex stage исходно задан HLSL с target `vs_1_1`, pixel stage — ASM
профиля `ps_1_1`. Наличие ASM внутри RFX не означает встроенную программу
в основном EXE.

## Vertex stage

| Данные | Назначение |
| --- | --- |
| POSITION, BLENDWEIGHT, BLENDINDICES | Позиция и необязательная деформация по палитре |
| NORMAL, TANGENT, BINORMAL | Базис для проекции световых векторов |
| TEXCOORD0 | Один UV для обоих texture inputs |
| view_proj_matrix, c0–c3 | Проекция ветви без деформации |
| BlendMatrices, VPTransform | Палитра и проекция взвешенной ветви |
| LightPos, inv_view_matrix | Положение света и преобразование в пространство объекта |
| Выходы POSITION, COLOR0/1, TEXCOORD0/1 | Проекция, закодированные light/half vectors и два одинаковых UV |

Исходник задаёт нулевое число весов до точки вставки специализации;
ветви одного–четырёх влияний преобразуют позицию и базис по тем же весам.
Их наличие в шаблоне отдельно от доказательства конкретного автоматического
выбора Bumpmap менеджером.

Программа переводит свет через inverse-view, получает направление света
и half vector, затем проектирует их на tangent/binormal/normal.
Вектор для построения half vector берётся из inverse-view образа
начала координат; это конкретное выражение ресурса, которое нельзя
молча заменить иной моделью направления к наблюдателю.
Компоненты проекций кодируются из знакового диапазона в COLOR0/1.
Эти цвета содержат направления, а не albedo или готовое освещение.
Оба UV-выхода получают исходный TEXCOORD0.

## Pixel stage и константы

Image0, s0 — базовая текстура; Image1, s1 — normal map.
Normal map и переданные через COLOR0/1 направления декодируются
преобразованием из [0,1] в знаковый диапазон.

| Pixel register | Значение в RFX |
| --- | --- |
| c0 | AmbientCol |
| c1 | LightMatDiff |
| c2 | LightMatSpec |

Diffuse использует скалярное произведение normal map и light vector.
Specular использует normal map и half vector, после чего три
последовательных возведения в квадрат дают степень восемь.
Комментарий о степени 32 в исходном ресурсе не соответствует инструкциям.
Специальный clamp dot до нуля не добавляется в восстановленное выражение.

Базовая текстура модулирует ambient/diffuse, а specular прибавляется
отдельно. Финальные операции исходного PS выполняются над RGBA;
отдельного принудительного сохранения alpha базовой текстуры или
установки alpha в единицу нет. Ограничения legacy registers и упаковка
интерполируемых COLOR — отдельные стадии.

[Shader contract](../../engine/materials/shader-contract.md)

[Effect template](../classes/sp-pc-effect-template.md) отделяет RFX records
от результата компилятора и фактически созданного shader object.
Наличие восстановленного normal-map выражения не квалифицирует все
игровые Bumpmap passes, способы подачи tangent basis или RT-материал Remix.
