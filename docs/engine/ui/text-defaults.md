# Начальное состояние текста на PC

У `spTextRenderable` начальные ссылки на текст и шрифт равны null. Цвет — `0xFFFFFFFF`, ширина переноса и выравнивание — 0.

| Смещение PC | Поле | Начальное значение |
| --- | --- | --- |
| `+0x5C` | Текст | null |
| `+0x60` | Шрифт | null |
| `+0x64` | Цвет | `0xFFFFFFFF` |
| `+0x68` | Ширина переноса | 0 |
| `+0x80` | Выравнивание | 0 |

Область `+0x8C…+0xA0` нельзя считать вычисленными bounds конструктора. Назначение непустого текста вызывает layout и требует пригодного шрифта; null font не даёт независимого безопасного пути для такого вызова.

Текст хранится байтовой строкой, включая завершающий ноль. Например, `AB\0` занимает три байта, а не чётное число байтов UTF-16. Полная кодировка отображения этим не определяется.

Чтение `spFont` допускает повторное присваивание одного поля: позднее значение заменяет предыдущее. Сырые битовые представления UV и числовых полей reader не обязательно нормализует. Дополнительные проверки конечности значений в нашем host-loader относятся к инструменту.
