# Узлы и мировые преобразования

`spNode` хранит локальные position, scale и orientation, ссылку на родителя, список детей и кэш мирового преобразования. Родительская ссылка не владеет объектом; дочерний список использует intrusive references.

## Представление

Во время работы ориентация хранится матрицей `3×3`. Serializer переводит её в quaternion XYZW; дисковое представление не совпадает с layout runtime-класса. Преобразования используют соглашение с векторами-строками.

При включённом наследовании позиция преобразуется ориентацией родителя и, при соответствующем флаге, его масштабом, затем прибавляется позиция родителя. Ориентации объединяются в порядке `localOrientation * parentWorldOrientation`.

## Обновление PC-узла

Billboard обрабатывается до проверки dirty-бита. Пересчёт мирового состояния зависит от `(flags | inheritedFlags) & 1`; обход детей выполняется и без этого пересчёта. Детям передаётся `(flags | inheritedFlags) & ~2`, после обхода собственные младшие три бита очищаются.

Флаги наследования независимы:

| Маска | Поведение |
| --- | --- |
| `0x10000` | Наследование позиции; при отключении у узла с родителем сохраняется прежняя world position |
| `0x20000` | Наследование ориентации; при отключении берётся локальная ориентация |
| `0x40000` | Умножение масштабов и участие масштаба родителя в наследуемой позиции |

Флаг enabled `0x200` не служит общей проверкой, отменяющей этот обход. Пересчитывать дерево только по видимым узлам поэтому недостаточно.

## PC и PS2

Размер PC-узла — `0xB4`, PS2 — `0xC0` с выравниванием 16. Локальные поля совпадают по смыслу, но размещение collision-контейнера и cached world fields различается. Нельзя копировать один runtime-layout между платформами.
