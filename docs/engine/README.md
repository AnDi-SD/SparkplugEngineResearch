# Движок Sparkplug

Sparkplug связывает объектную модель, загрузку ресурсов, сцену и подсистемы исполнения. Winx Club расширяет его собственными типами `wx…`; типы `sp…` относятся к движку, включая платформенные реализации.

| Подсистема | Что описано |
| --- | --- |
| [Архитектура](architecture/README.md) | Общие модули, ядро, порядок обновления и менеджеры |
| [Объекты](objects/README.md) | Идентичность, имена, владение и уведомления |
| [Ресурсы](resources/README.md) | Загрузка, сериализация, ссылки и время жизни |
| [Сцена](scene/README.md) | Узлы, иерархия, локальные и мировые преобразования |
| [Геометрия](geometry/README.md) | Меши, вершины, индексы и представления буферов |
| [Анимация](animation/README.md) | Кривые, контроллеры, привязка и skin |
| [Отрисовка](rendering/README.md) | Проекции, проходы, очередь и передача геометрии |
| [Материалы](materials/README.md) | Состояния, слои, шейдеры и константы |
| [Текстуры](textures/README.md) | Представления, источники, mip-уровни и загрузка |
| [Видимость](visibility/README.md) | BSP, octree, зоны, порталы и отсечение |
| [Физика и коллизии](physics/README.md) | Геометрия столкновений, объёмы и физические системы |
| [Свет и эффекты](effects/README.md) | Освещение, fog и частицы |
| [Интерфейс](ui/README.md) | Текст, GUI, фокус и сообщения |
| [PC и PS2](platforms/README.md) | Различия ABI, классов и платформенного поведения |

Начните с [общей архитектуры](architecture/overview.md). Данные на диске описаны в [форматах](../formats/README.md), конкретные типы — в [каталоге классов](../reference/classes.md).
