# Порядок обновления PC-кадра

`spPCApp` разделяет общее обновление и графическую часть. После предварительного обновления вызывается общее обновление `spEngineCore`. Потеря фокуса окна сама по себе не отменяет этот шаг.

## Общее обновление

Порядок менеджеров:

1. ErrorManager.
2. TaskTimer.
3. Input.
4. Network.
5. Physics.
6. Animation.
7. GUI.
8. Scene.
9. Audio.
10. ParticleSystemManager.
11. Очереди событий ядра, расположенные по смещениям `+0xCC`, затем `+0x110` в PC-представлении.
12. AsyncFileStreamManager.

Вложенная обработка событий анимационного actor не заменяет эти очереди ядра.

## Графическая часть

Графическое обновление выполняется, когда foreground window совпадает с окном приложения или его владельцем. Иначе вызывается `Sleep(1)`. Возвращаемое значение этой обвязки — `true`; результат вспомогательных вызовов не превращается автоматически в её результат.

Это порядок базового PC-приложения. Игровые переопределения и PS2-цикл требуют собственного описания; переносить на них весь порядок без уточнения нельзя.
