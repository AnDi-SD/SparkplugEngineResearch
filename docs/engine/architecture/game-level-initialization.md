# Инициализация сущностей уровня

Общая PC-операция обходит уже построенный
[`spGameLevel`](../../reference/classes/sp-game-level.md) и отправляет
инициализационное уведомление сущностям из его экземпляров шаблонов.
[Реализация](../../../Sparkplug/Code/Sparkplug/spGameLevelInitialization.h)
восстанавливает отдельную функцию; её исходный C++-владелец, имя и файл пока
не установлены. Наличие аргумента GameLevel не доказывает принадлежность
функции этому классу.

Сначала функция проходит экземпляры уровня в порядке списка. Для каждого
[`spTemplateInstance`](../../reference/classes/sp-template-instance.md) она
проходит список присоединённых объектов и вызывает их виртуальную проверку
`IsKindOf(spEntity / 0x22875AA1)`. Подходящие указатели добавляются в общий
список в том же порядке. Одинаковые указатели остаются отдельными элементами.
Корневой Node экземпляра и произвольные дочерние Nodes в этот обход
автоматически не включаются.

Отдельная PC-обёртка начинает такой же отбор непосредственно со списка одного
TemplateInstance. Она не читает список экземпляров содержащего уровня и не
включает соседние экземпляры. В общей реализации оба входа используют один
коллектор списка экземпляра и один протокол повторной рассылки; параметры
ограничений и аналитический результат общие.

Оригинал копирует найденные указатели из временного списка в массив и удаляет
временный список до первой рассылки. Он не увеличивает и не уменьшает счётчики
ссылок получателей. Общая переносимая реализация хранит те же заимствованные
указатели в одном векторе: это замена хранения, сохраняющая порядок обхода и
повторных вызовов, а не воспроизведение ABI контейнера или ошибок аллокатора.

Для каждого указателя функция создаёт отдельный синхронный кадр уведомления:

| Поле | Значение перед вызовом |
| --- | --- |
| Код | `0x1C` |
| Остальные известные служебные слова и отправитель | Ноль |
| Payload, native `+0x18` | Номер прохода, начиная с нуля |
| Младший байт Tail, native `+0x1C` | Ноль |

Получатель вызывается напрямую через виртуальный Notify. Он может изменить
заимствованный кадр до возврата. Если младший байт Tail стал ненулевым,
получатель сохраняется для следующего прохода. Старшие байты этого native
слова не инициализируются и не имеют установленной семантики. Они не влияют
на проверку повторения.

Список повторных вызовов сжимается на месте, сохраняя относительный порядок и
повторяющиеся указатели. После полного прохода номер увеличивается. Рассылка
заканчивается, когда ни один получатель не запросил повторения. Изменения
других полей кадра не переносятся в следующий кадр. Для пустого результата
отбора рассылка вообще не начинается.

Функция требует стабильного, заранее построенного графа и живых получателей
до завершения всех проходов. Доступ к спискам GameLevel и TemplateInstance
заимствует существующее состояние; специальный ввод списка для аналитических
fixtures не является восстановленным native Attach или загрузчиком.

Результат и пределы переносимой функции являются аналитическими. Отдельные
статусы показывают пустую ссылку в графе либо достижение предела обхода,
сущностей или проходов. Это явная остановка ограниченной реконструкции;
оригинал не имеет доказанного соответствующего успешного возврата. Политики
повторения отдельных игровых получателей, произвольные изменения графа во
время обхода, cold startup, ошибки выделения памяти и PS2-реализация остаются
отдельными границами.
