# Архитектура Sparkplug

Sparkplug — общий движок, Winx Club — его игровой клиент. Движок предоставляет типы `sp…`, игра расширяет их типами `wx…`. Например, `wxEngineCore` использует основу `spEngineCore`, а `wxEntity` — `spEntity`. Слово `Game` в имени `spGameLevel` не переносит этот тип в игровой слой.

## Модули

| Модуль | Назначение |
| --- | --- |
| SparkBase | Базовые объекты, память, ошибки и потоки |
| SparkBasePC | PC-реализации базовых операций |
| Sparkplug | Общие менеджеры, ресурсы, сериализация, сцена и поведение объектов |
| SparkplugDX | DirectX-реализация renderer, mesh, texture и render targets оригинальной PC-игры |
| SparkplugPC | PC-приложение, платформенные загрузчики и службы |

Для PS2 известны семейства `spPS2…` и `wxPS2…`; точные исходные имена всех PS2-модулей не установлены. Эти платформенные типы нельзя заменять PC-структурами только на основании похожих имён.

## От файла к кадру

1. Потоки и менеджеры ресурсов находят ресурс и открывают его содержимое.
2. Контейнер FFPS задаёт каталог и области сериализованных объектов.
3. Регистрация классов и serializers создают объекты, читают поля и восстанавливают ссылки.
4. Узлы и другие объекты образуют сцену. Анимация обновляет связанные значения, узлы пересчитывают мировые преобразования.
5. Видимость, материалы и renderer подготавливают и передают геометрию платформенному backend.

Файл SMO поэтому содержит объектный граф: модели, меши, материалы, текстуры, узлы, skin, коллизии и вспомогательные классы. Игровой уровень дополнительно использует шаблоны, размещение и объекты, созданные во время работы.

## Границы типов и платформ

В [каталоге](../../reference/classes.md) 784 различных имени: 373 класса движка и 411 игровых. В PC-регистрациях присутствуют 733 имени, в PS2 — 681, общих — 630. Присутствие только в одной известной версии не доказывает невозможность класса на другой платформе.

Class ID идентифицирует зарегистрированный тип. Поле базового ID описывает регистрационную связь; оно не гарантирует физический layout C++-наследования. Размеры, смещения полей и владение описываются отдельно.
