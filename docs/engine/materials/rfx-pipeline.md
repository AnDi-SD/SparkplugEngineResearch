# RFX: от файла к shader

Загрузчик RFX читает файловый XML-документ. XML parser и callbacks создают проходы и shader records, затем соответствующий shader передаётся функции компиляции.

Поддерживаются пути assembly и HLSL. В первом случае descriptors могут поступать из файла, во втором — из reflection внешнего SDK. Общая функция разрешает тип, register и число элементов константы. Готовые байты shader копируются в память движка и принадлежат shader до его уничтожения.

Этот путь не описывает полностью startup менеджера, повторную загрузку, все ошибки компиляции и интеграцию с конкретным устройством.
