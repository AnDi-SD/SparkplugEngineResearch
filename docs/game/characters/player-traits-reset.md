# PlayerTraits и сброс captured prefix

PC класс `wxPlayerTraits` зарегистрирован с ID `28C56217` и регистрационной базой `wxCharacterTraits`, ID `1BC6108E`. Его primary table `006F6990` содержит в slot `3C` операцию `004FD7E0`. RTTI getter `004FE040` возвращает адрес записи `0074E908`.

Конечный профиль `ResetCapturedPrefixForAnalysis` применяет целиком этот прямолинейный leaf к заданному prefix длиной `24D` байт. Оригинальный код содержит 27 инструкций, 20 DWORD-записей и три BYTE-записи, затем `RET0`. Он обращается к receiver только для записи. Полный размер native объекта, физическая C++ база и конструктор остаются неизвестными.

Операция записывает DWORD `6` по `124` и `128`, raw word `42C80000` по `1A8` и `1AC`, `42A00000` по `1BC`, `3F800000` по `238`. DWORD по `12C`, `130`, `134`, `1B0`, `1B4`, `1B8`, `1C8`, `1C4`, `1C0`, `230`, `234`, `240`, `23C`, `248` становятся нулевыми. BYTE по `1A0`, `1D0`, `24C` становятся нулевыми.

Остальные байты prefix сохраняются, включая `1A1`, `1D1`, `1CC`, `1D4`, `1D8`, `1DC`, `1E0`, `1E4`, `22C`, `244`. Значения raw words передаются без численного преобразования. Исходная последовательность native-записей фиксирует их порядок и ширину. API выдаёт итоговый prefix через присваивание staged value.

Профиль по умолчанию возвращает отказ. Явный профиль требует captured primary `006F6990` и сохраняет output при отказе. Успешный результат создаётся через staged prefix, допускающий before/output alias. Это аналитическое представление с явно заданным prefix. Native return type, другие методы, lifetime, полный объект, PS2 и gameplay остаются открытыми.
