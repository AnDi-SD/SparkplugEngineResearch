# CharacterStateMachine: создание и раскладка 36 классов

## База и различия раскладок

`wxCharacterStateMachine`: PC factory `004016A0`, vtable `006F6680`, getter
`004FAB90`; PS2 factory `003F75A0`, ctor `002B48D0`, vtable `0049B490`,
getter `003F9880`. PC constructor stores в `013DD6FB` и далее действительно
посещены original factory; это точный участок payload, не угаданный entry.

## Остановившиеся пути

Первичный учёт: PC34×20 и Goop15; PS236×15. Это scouted construction,
без закрытых классов. Активные переходы, input handling, нормальная привязка
персонажа и причины protected Bloom path исследуются следующими блоками.
Глобальные выделения, оставшиеся после удаления машины, не объявляются
утечками без отдельного установления их владельцев.
