# wxCharacterTraits: опубликованное значение Fairy Stars

На PC `wxCharacterTraits` регистрирует свойство `Value of Fairy Stars` с двумя
простыми callback. Setter переносит четыре байта аргумента в `this + 0x1A4`;
getter возвращает те же четыре байта в EAX. Здесь нет проверки диапазона,
арифметики, вызовов других методов или обращений к глобальному состоянию.
Это описывает raw DWORD свойства. Знаковость, ограничения редактора и влияние
значения на выдачу игровых наград по этим операциям не установлены.

Аналитический API принимает явно выбранный PC-профиль и захваченный префикс
длиной `0x1A8` с primary table `0x006F67F0`. Getter читает слово; setter создаёт
значение нового префикса, изменив только четыре байта `+0x1A4..+0x1A7`.
Остальные байты сохраняются. Input и output setter могут совпадать. Отказ
профиля или несовпадение primary table оставляет output без изменений.

Префикс представляет захваченные байты для анализа, а не объект оригинального
C++ ABI. Полный native sizeof, физическое наследование, конструктор и factory
не восстановлены этим API. Стадирование выходного значения не воспроизводит
native machine write trace или время жизни объекта. Методы damage, init,
сообщения, другие свойства, PS2 и игровой маршрут наград остаются вне этого
контракта. Регистрационная база `wxEntity` не доказывает физическое наследование.
