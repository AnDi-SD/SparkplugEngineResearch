# Вход и выход триггеров: настоящие HUD-зависимости

## Общий вход и выход

Generic enter `5903B0 / 3AC780` пропускает запрос, если слово130/13C равно0,
либо одновременно ненулевые bytes125/131 и127/133. Затем настоящий HUD getter
`559530 / 379470` читает window144/14C через HUD+60. Если он ненулевой или
собственный byte138/144 ненулевой, запрос также пропускается.

Generic leave `590420 / 3AC730` вызывает HUD hide `5594E0 / 3794D0`, который
передаёт основному окну state0. После возврата обнуляет свои bytes144/150
и138/144. На PC эта цепочка исполнилась полностью на настоящем обработчике.

## Производные триггеры

Pivot enter `539BC0 / 3B3C60` пропускает Generic enter, если собственный byte
188/1A0 ненулевой. Затем записывает active126/132=1 и profile504=8.
Push enter `53B130 / 3B5A50` всегда вызывает Generic enter, после возврата
ставит active=1 и profile504=16. PC shared leave53D360 сначала выполняет
Generic leave, затем обнуляет active и profile504. У PS2 отдельные оригинальные
адреса3B3C10/3B5A00 с теми же собственными stores.

Пилот1,710s, адресный повтор2 / 0,034s, пакет63 / 5,860s внутри процессов.
Всего80 основных попыток для78 квалифицированных случаев; отдельный PC scout
3 / 0,666s. Дальнейшие PS2 SQ/LQ, HUD enter body и parent bodies остаются
объявленными границами; полные PS2 цепочки не приписываются компонентам.

Шесть updates +5: GenericTrigger PC55→60/PS250→55;
PivotingDoor и PushButton PC30→35/PS225→30. Новых C++ и полностью закрытых
классов нет. Подтверждённые helpers HUD не получают выдуманного class credit.
