# Триггеры: 43 класса и общая управляющая логика

## Охват

| Родитель в регистрации | Число строк в этом семействе |
| --- | ---: |
| wxEntity → wxGenericTrigger | 1 |
| wxGenericTrigger → прямые потомки | 33 |
| wxPivotingDoor → wxAlfeaDoorTrigger | 1 |
| wxOneLinerTrigger → wxGenericSideQuest | 1 |
| wxGenericSideQuest → зарегистрированные потомки | 6 |
| wxDoubleSideQuest → wxPalladiumFairyQuest | 1 |

У GenericTrigger и GenericSideQuest нет зарегистрированных factory на обеих
платформах. Их промежуточные конструкторы и идентичность подтверждены отдельно;
абстрактность C++ по отсутствию factory не выводится. Остальные 41 класса
получили независимые PC и PS2 size/constructor/vtable/getter свидетельства.
Полный список, размеры и собственные PS2 stores находятся в контрактах.
Разница размеров между платформами принимает значения 24, 28, 32, 36, 40, 44,
48 байт; одной универсальной поправки нет.

## Конструкция и окружение

GenericTrigger: PC constructor `00590110`, vtable `007024B0`, getter
`005901D0 → 00752388`; PS2 constructor `003AD760`, vtable `00498030`, getter
`003F8E70 → 004C9170`. После PS2 ABI header в обоих интерфейсах 25 слотов.
Самостоятельный размер базового класса по отсутствующей factory не заявляется.

## Таймер, Notify и копирование

| PC offsets | PS2 offsets |
| --- | --- |
| 126, 125, 127, 12C | 132, 131, 133, 138 |
| 134, 140, 13C, 128, 130 | 140, 14C, 148, 134, 13C |

Все offsets шестнадцатеричные. Три payload случая включают нули, обычные значения,
ненормализованные байты и произвольные 32-битные шаблоны. Остальные собственные
поля и padding сохраняются. PC исполняет весь copy вместе с wxEntity copy;
PS2 префикс `3AD544 → 104F00` явно начинает после inherited success и доходит
до настоящего clone manager с hash `38F1ED51`. Его возврат не подставляется.

## Tick и вход пользователя

- При одновременных `125/131` и `127/133` пропускается основной Tick, но v17
  всё равно вызывается. Это ветвь однократного уже выполненного действия.
- После истечения интервала обновляется timestamp и вызывается v19.
  При первом false и установленном active `126/132` предикат вызывается снова;
  два false снимают active перед v22 выхода.
- True допускает вход через v21 только при неактивном HUD-флаге и совпадении
  сохранённого режима GameFlow с результатом оригинального поиска по стеку.
  Active выставляется до callback. Уже установленный active не предотвращает
  повторный v21 при следующем принятом проходе.
- Для активации через v20 нужны active, байт входа `inputRecord+1B`, разрешение
  текущего controller `+25`, защёлка `145/151` и совпадение режима GameFlow.
  Защёлка снимается до callback; при отпущенном входе устанавливается в 1.

## Ещё одно различие регистрации и конструкции

База получает PC45/PS240 вместо прежних 10/10, GenericSideQuest — первые 10/10,
41 callable потомок — PC20/PS215. Открыты геометрия, собственные реакции уровней
и квестов, наполненное клонирование, полный startup и полный PS2 lifecycle.
Ни один класс не объявлен полностью закрытым. Отдельное применение привязки
Node к прежним entity-остановкам учитывается своим последующим свидетельством.
