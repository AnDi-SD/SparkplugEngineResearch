Смещения и адреса шестнадцатеричные; числовые пороги десятичные. Не переименовываем
word128 в обычный линейный radius: эти потребители сравнивают именно square.
Перевод единиц координат здесь не устанавливался.

CT02OpenDoor/GiantBoulder получают два Node из собственных PC148/14C и
PS2160/164. Остальные используют сохранённый глобальный профиль
`765AD4 / 49FC7C`: profile2B4→record24→Node. Второй Node обычно берётся из
this18; GenericSideQuest использует this24→record24. В фикстуре альтернативный
источник содержит другие координаты, поэтому ошибочная привязка дала бы иной
результат. Глобальный cache miss и normal construction не исполняются.

PC GenericTrigger проходит исходный защищённый переход `590643`. Дополнительное
наблюдение чтения памяти для gate0 иFF зафиксировало оригинальную инструкцию
`40744C: mov al,byte ptr [esi+124]`. Gate0 возвращает false, gateFF допускает
геометрию. Размер чтения — ровно один байт; защищённая логика не заменена.

## Границы описания

171 разных исполнения прошли с первого раза:79 полных PC методов,12 полных
PS2 методов CT02OpenDoor/GiantBoulder и80 собственных PS2 компонентов остальных.
Пилот15 за1,259s,пакет156 за10,946s внутри процессов. Два дополнительных PC
наблюдения защищённого gate не считаются новыми входами основного пакета.

PC PhoneTrigger разделяет адрес и входы с CombinationLock:повторное выполнение
не делалось. PS2 PhoneTrigger имеет отдельное тело и13 собственных проверок.
Унаследованные aliases остальных потомков из разведочной таблицы не получают
дополнительных оценок за тот же общий метод.

## Учёт

15 updates на5:семь PC и восемь PS2 классов таблицы; PC PhoneTrigger без
повышения. Полностью закрытых классов и новых восстановленных C++ нет.
Исследовательские оценки описывают подтверждённое поведение, а не объём C++.
