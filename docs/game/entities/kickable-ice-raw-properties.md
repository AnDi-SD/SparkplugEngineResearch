# Сырые свойства `wxKickableIce` на PC

В составе собственного publisher `0x00543340` класса
`wxKickableIce` (`0x7F284E80`) есть три пары обработчиков, которые
переносят целое DWORD между полем экземпляра, стеком и `EAX`.

| Свойство | Поле | GET | SET |
| --- | --- | --- | --- |
| `Ice Id:` | `+0x1E4` | `0x00542790` | `0x0050A5B0` |
| `Collectible Type:` | `+0x1F4` | `0x0050BCD0` | `0x005427A0` |
| `Value of Fairy Stars` | `+0x16C` | `0x00510160` | `0x005427D0` |

Первые две метки содержат завершающий пробел. GET возвращает
полные четыре байта поля. SET записывает четыре байта со стека и
затем снимает аргумент.

Переносимый интерфейс принимает 508-байтовый префикс с primary
`0x006FCB38`. Составная операция GET/SET/GET выдаёт старое слово,
полный префикс после записи и новое слово. Остальные байты
сохраняются, включая соседние четыре байта по `+0x170`. Имена
исходных типов и применение этих значений в игре остаются открытыми.

## Stars impulse range

Свойство `Stars impulse range` в том же publisher использует поле
`+0x170`. GET по `0x005427B0` загружает `binary32` в x87 `ST(0)`.
SET по `0x005427C0` копирует четыре байта аргумента в поле и снимает
четыре байта со стека.

Отдельный переносимый профиль принимает положительные конечные
`binary32`, включая субнормальные числа. GET представляет результат
десятью байтами `ST(0)`. SET сохраняет исходное слово аргумента.
Составная операция GET/SET/GET сохраняет остальные байты префикса,
включая поля `Ice Id:`, `Collectible Type:` и `Value of Fairy Stars`.
Единицы диапазона и использование значения остаются открытыми.
