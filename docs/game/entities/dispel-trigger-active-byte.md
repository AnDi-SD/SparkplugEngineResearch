# Байт активации `wxDispelTrigger` на PC

Класс `wxDispelTrigger` (`0x446244FE`) зарегистрирован с базой
`wxGenericTrigger` (`0x38F1ED51`). Слоты таблицы `0x006FD630`
изменяют один байт экземпляра.

| Слот | Тело | Запись |
| --- | --- | --- |
| `+0x54` | `0x00549AF0` | `+0x1B0` получает `1` |
| `+0x58` | `0x00549B00` | `+0x1B0` получает `0` |

Обе операции записывают литерал и возвращаются без аргументов на
стеке. Переносимые методы принимают 452-байтовый префикс с primary
`0x006FD630`. Они меняют байт по `+0x1B0` и сохраняют остальные байты.
Возвращаемый `bool` показывает, прошёл ли захват проверку primary.
