# wxMovingPlatform: проверка близости на PC

Операция virtual slot `+0x2C` использует сохранённую world position узла,
связанного с receiver через `+0x18`, и координаты переданного record по
`+0x18`, `+0x1C`, `+0x20`. Она записывает байт receiver `+0x168`: единицу при
квадрате расстояния не больше `2 000 000`, иначе ноль. Последовательность
x87 сохраняет разности X, Y, Z и сумму `(X² + Z²) + Y²` в nearest/64,
без промежуточного binary32 spill. Константа сравнения имеет binary32 bits
`49F42400`. В AL возвращается единица; инструкция `RET 4` снимает аргумент.
Другие биты EAX и точный исходный тип возвращаемого значения не установлены.

В pristine mapped image DWORD `0x00765AB8` равен нулю: адрес принадлежит
нулевому virtual tail секции `.data`. Активный аналитический профиль требует
именно это значение, стабильные borrowed Node/point bindings и конечные
координаты с абсолютным значением не больше `16384`. В этой области DWORD
receiver `+0x80` не читается и сохраняется как неизвестное поле. Статически
видимая ветвь для ненулевого global и ненулевого `+0x80` сохраняет `+0x168`;
её original qualification требует отдельного опыта. API отказывает при
ненулевом captured global и не добавляет fixture в PE.

`UpdateNearStateForAnalysis` принимает captured receiver prefix `0x169`,
captured point record `0x24` и отдельно связанный reconstructed `spNode`.
Он использует общий nearest/64 math kernel и реальный getter world cache.
Исходные pointer words в captured prefix не разыменовываются на host.
При отказе output и аналитический bool остаются прежними. Input/output
prefix могут совпадать. При успехе меняется только `+0x168`; Node и point
остаются прежними. Стадирование output описывает итоговые значения и не
обещает воспроизвести native write-attempt trace или частичный эффект ошибки.

Историческая factory allocation измерена как `364` байта; минимум,
затронутый этой операцией, равен `0x169`. Это разные наблюдения и ни одно
не объявляет восстановленным весь native C++ layout. Физическое наследование,
производственный dispatcher, создание и lifetime графа, движение платформы,
другие virtual методы, PS2 и игровой сценарий остаются открытыми. Название
NearState обозначает геометрический смысл этой операции, а не полный игровой
контракт поля.
