# Сырые свойства `wxBreakableBarrel` на PC

Собственный publisher `0x00542620` класса `wxBreakableBarrel`
(`0x05FF35BE`) передаёт две пары обработчиков свойств.

| Свойство | Поле | GET | SET |
| --- | --- | --- | --- |
| `Barrel Id:` | `+0x180` | `0x00541C80` | `0x00541C90` |
| `Value of Fairy Stars` | `+0x184` | `0x00539560` | `0x00541CA0` |

Первая метка содержит завершающий пробел. GET возвращает четыре
байта поля в полном `EAX`. SET копирует четыре байта аргумента из
стека в своё поле и снимает четыре байта аргумента.

Переносимый интерфейс принимает 396-байтовый префикс с primary
`0x006FC930`. Составная операция GET/SET/GET выдаёт старое слово,
полный префикс после записи и новое слово. Все остальные байты,
включая хвост после `+0x187`, сохраняются. Имена исходных типов и
применение значений в игре остаются открытыми.
