# wxDamageProxy: raw-параметры

Восстановлены две пары property callbacks, опубликованные как `Damage period (ms)` и `Damage points`: копирование четырёх байт по смещениям `0x12C` и `0x124`. Getter читает полный DWORD; setter копирует полный DWORD аргумента. Указание `ms` сохранено как имя descriptor, без арифметики времени, signedness или вывода native C++ типов.

API работает с captured-префиксом 304 байта и явно выбранным PC-профилем primary `0x006F7F68`. Он сохраняет все байты вне выбранного DWORD, поддерживает alias и повторную запись; отказ профиля, primary или неизвестного property оставляет output неизменным. Составная value-операция воспроизводит восемь чтений/записей на одном сохраняемом префиксе и выдаёт шесть raw-результатов чтения и два полных префикса после записей.

304 байта — минимальный затронутый префикс. Сохранённый factory allocation 312 байт не доказывает текущий `sizeof`. Конструктор остаётся защищённым opaque entry; API не создаёт native объект. Native return signatures, полная структура, lifecycle, production callers, применение повреждений, PS2, gameplay и весь класс остаются открытыми.
