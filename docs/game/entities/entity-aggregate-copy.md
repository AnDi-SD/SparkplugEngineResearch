## Собственные поля `wxTargetRegion` на PC

В таблице `0x006F7ED0` класса `0x4307193A` запись по смещению `+0x0C` ведёт к
`0x00511160`. После успешного Copy базы выполнение переходит на
`0x00511177`. Участок читает источник через ESI и пишет назначение через
EDI. Граница участка находится по `0x005111E3`.

Первым переносится текст из `+0x124`, побайтно до первого нуля
включительно. Хвост назначения после нуля сохраняется. Затем переносятся
байты `+0x144` и `+0x147`, DWORD `+0x14C`, далее байты `+0x148`,
`+0x145`, `+0x146` и `+0x151` в этом порядке. Источник сохраняется.

[Аналитический интерфейс](../../../Winx/Code/wxTargetRegion.h)
принимает два разных 340-байтовых захвата с указанной таблицей.
Допустимый текст содержит ноль в первых 32 байтах захваченного
интервала. При отказе назначение сохраняется. Результат интерфейса
показывает, применён ли перенос к принятой паре захватов.

## Собственные поля `wxBush` на PC

В таблице `0x006FCEC8` класса `0x0598568B` запись по смещению `+0x0C`
ведёт к Copy `0x005441A0`. После успешного Copy базы выполняется участок
с `0x005441B7` до `0x005441EA`, где начинается следующий этап. Источник
передаётся через ESI, назначение через EDI.

Сначала переносится текст из `+0x14C`, затем из `+0x16A`. Каждый цикл
записывает первый ноль включительно и сохраняет хвост назначения после
него. Исходные байты сохраняются, значения выше `0x7F` переносятся без
преобразования.

[Аналитический интерфейс](../../../Winx/Code/wxBush.h) принимает две
раздельные 396-байтовые записи с таблицей `wxBush`. В каждом из двух
30-байтовых интервалов источника должен встретиться ноль. Интерфейс
проверяет оба интервала перед переносом и при отказе сохраняет назначение.
