| Контракт | PC | PS2 |
| --- | --- | --- |
| Число групп | 40 | 40 |
| Счётчики групп | 40 нулей с54 | То же |
| Ключи групп | сF4: slot0=0, slots1..39=FFFFFFFF | То же |

| Отдельный блок100 слов | 591C, original REP STOSD | 39DC, static memset(190 bytes) |

Hex offsets/strides в таблице; количества слов десятичные. 8000 байт разницы
размеров объектов объясняются первой матрицей. Не выдаём весь последующий
интервал до следующего поля за инициализированный массив и не обнуляем
не записанные конструктором слова. Полная разница размеров —8108 байт;
дальнейшие поля и платформенные лимиты сохраняются отдельно.
