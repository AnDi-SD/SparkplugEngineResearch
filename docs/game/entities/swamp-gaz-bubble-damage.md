# Swamp gaz bubble raw damage property

The PC own publisher of `wxSwampGazBubble` labels one complete raw DWORD callback pair `Damage Inflicted`. Its setter at `0x00540CE0` copies four argument bytes from the stack to `+0x14C`; its getter at `0x00540CF0` loads those four bytes into EAX. The descriptor supplies both callback addresses independently. The label does not establish native C++ types, signedness, units or how damage is applied.

The captured-value profile requires primary `0x006FE408` and a minimum336-byte selected prefix through that field. Historical factory allocation352bytes is separate evidence. The source facade does not declare the native object layout or physical inheritance. Factory/RTTI identity, current primary and RTTI, a clone reference to the registered factory, and six-argument registration bind this descriptor to the partial typed receiver. The current factory entry is opaque; no constructor body or current primary store is qualified.

Reads preserve all32 bits. Writes stage the complete prefix, support alias input/output, and retain every other byte. Compose records GET, SET, GET as the old raw value, one full post-store prefix and the new raw value. Unqualified or unknown profiles and wrong captured primary are rejected before changing output. The returned `bool` is this analysis value API's admission status and is not a native return signature.

Five FLD float property pairs and the differently shaped `Use Green bubbles` callbacks are excluded. Their bytes remain opaque and preserved. No float interpretation or conversion is applied. Full clone paths, constructor/factory execution, lifetime, native sizeof, explosion/radius/inflation logic, production dispatch, damage effects, PS2, gameplay and the whole class remain open.
