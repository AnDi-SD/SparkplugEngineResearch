# ParticleManager update with existing EngineCore and Game (PC)

`wxParticleManager` primary `0x00703ED0` binds virtual slot `+0x2C` to `0x005A1170`. The game method uses the particle manager's borrowed sentinel list. It captures the initial sentinel and reads the frame delta from the existing EngineCore and the state from the existing Game before testing whether the list is empty.

The method skips a zero particle pointer. A particle with no RenderNode takes the clock-only route. For a particle with a node, bit `0x200` of node `+0xB0` bypasses a virtual predicate. When the bit is clear, the original calls slot `+0x10` on the embedded node receiver at `+0xB4`. The admitted profile requires the bit to be set.

With a present node, nonnegative duration and `lifetime + duration <= clock` select the clock-only route. Otherwise the method reads all three node coordinates and subtracts them from the respective manager coordinates. It discards those differences and bypasses the distance comparison if the absolute values of all three manager coordinates are at most the binary32 constant with bits `0x3A83126F`. The original keeps the squared distance in extended precision as `(dz² + dx²) + dy²`. Distance at least `6,250,000` selects clock-only only if the node's scene equals the current EngineCore scene. State `0x21` changes that threshold to `42,400,000`. The current scene is fetched only for a distance at or above the selected threshold.

Clock-only adds the previously read delta to `ParticleSystem +0xA4`, with a single binary32 store. The other route passes the unchanged delta bits to the [particle update](../../engine/effects/particle-cpu-update.md). The analytical facade supplies each effect through its own synchronous callback. The existing base manager's borrowed link view is shared. The game method keeps the initial sentinel through the traversal.

The profile admits finite normal binary32 values and signed zeros for the operands read by the selected route and for the stored clock-only result. Arithmetic uses nearest rounding with a 64-bit x87 significand and the existing extended-precision primitives. A subnormal or non-finite clock-only result causes analytical refusal before the write callback. The borrowed ring and each member remain live during dispatch. Singleton creation, the node virtual predicate, native layout, mutation of the list during callbacks, PS2 and whole-frame behavior remain open.
