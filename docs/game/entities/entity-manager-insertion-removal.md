# wxEntityManager: добавление и удаление указателей

## Добавление после classifier

| Полученная группа | PC | PS2 |
| --- | ---: | ---: |
| Обычная0..39 | 130 указателей на группу | 80 |
| 41 / wxHUDPart | 100 | 100 |
| 42 / wxButton | 130 | 105 |
| Дополнительный список wxCharacterMoveCtrl | 130 | 80 |

Для обычной найденной группы:

Для нового типа classifier возвращаетFFFFFFFF. При наличии свободного
индекса1..39 метод пишет первый указатель группы, её class hash и count=1.
При отсутствии свободного индекса записи нет. Slot0 сохраняет особый статус.
HUD/Button дописываются в свои массивы до отдельных лимитов.

Оригинальные общие epilogues возвращают true, включая ветви без записи
из-за лимита или дубликата. Нельзя трактовать этот return как отдельное
подтверждение фактического добавления.

## Общий helper удаления из массива

PC **00573CE0**, PS2 **00289180..002892B4** получают искомый указатель,
адрес count, ёмкость и начало массива. Обе полные функции исполнены до
оригинального return; нет SQ/LQ frames, аппаратных вызовов или fake callbacks.

1. Сдвигает слова от следующего элемента **до конца ёмкости**, а не только
   живую часть до count.
2. Обнуляет последнюю ячейку всей ёмкости и уменьшает count.
3. Переходит к следующему индексу, не проверяя заново сдвинувшийся элемент.

Поэтому из `[A,A,B]` с count3 удаление A оставляет `[A,B]` с count2;
из `[A,B,A,C]` удаляет оба A и оставляет `[B,C]`. Три соседних A оставляют
один A. Возвращается признак того, что встретилось хотя бы одно удаление.
