# Игра Winx Club

Игровой слой расширяет Sparkplug типами `wx…`. Он выбирает ресурсы, управляет состояниями игры, персонажами, AI и взаимодействиями. Общая сериализация, узлы сцены и renderer принадлежат движку.

| Раздел | Содержание |
| --- | --- |
| [Ресурсы](assets/README.md) | Поиск файлов, модели, шаблоны и размещение |
| [Персонажи](characters/README.md) | Машины состояний, анимационные запросы, снаряды, волосы Bloom |
| [AI](ai/README.md) | Действия, команды, восприятие и навигация |
| [Триггеры](triggers/README.md) | Вход, выход, условия взаимодействия и связь с HUD |
| [Состояния игры и меню](flow/README.md) | Game flow, GUI, камеры и разрешение |
| [Игровые объекты](entities/README.md) | Entity, копирование, регистрация и связи с узлами |

Форматы [ANM, SPT и SPL](../formats/game-resources.md) связывают дисковые ресурсы с игровым поведением. Отдельный SMO не описывает весь уровень или полное состояние персонажа.
