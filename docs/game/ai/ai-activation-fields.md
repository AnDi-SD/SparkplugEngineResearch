# Активация IceWormHoles и начальные связи Kiko

Блок 43. 34 оригинальных опыта PC17/PS217, все с первого раза:
пилот6 /0,485622s, пакет28 /2,107546s. 22 завершённых метода IceWormHoles,
4 остановки KikoHole перед подпиской, 8 остановок KikoMoving перед
построением ориентации. В каждом опыте сверены все 24 KiB связанных
объектов. Продолжение за указанными остановками не исполнялось.

## IceWormHoles: весь слот9

PC `5226C0`, PS2 `254B40`. Action получает Node через
owner→entity→Node, сохраняет его по `+3C0` / PS2 `+3C4`, затем в
его parent `Node+2C` рекурсивно ищет точные имена `in` и `out`.
Настоящий NodeFind возвращает найденные узлы или null; они сохраняются
по action `+3BC/+3B8`, PS2 `+3C0/+3BC` соответственно.

## KikoHole: связи перед подпиской

PC `5221C0`, PS2 `2E9EF0`: собственный Node сохраняется по `+3A8`,
Node из `profile+2B4→entity+24` — по `+3AC`; PS2 смещения больше на 4.
Следующий вызов `410050` / `100860` получает subject персонажа
(`character+124` / PS2 `+130`) и action как слушателя.

## KikoMoving: позиция перед ориентацией

PC `5AD280`, PS2 `25B930` сохраняет собственный Node, Node игрока,
текущую структуру команд и копию мировой позиции игрока. Собственному
Node задаёт local `(-1954,225,1241)`, dirty bit1 и ту же позицию в
movement `+138` / PS2 `+144`.

Остановка перед `420470` / `1090E0` подтверждает аргументы направлений
`(-1,0,0)` и `(0,1,0)`. Ориентация и последующие записи конечной цели
не объявляются выполненными. Для продолжения нужно отдельно квалифицировать
этот helper и его PS2 арифметику; общая проблема EE SQRT остаётся открытой.
