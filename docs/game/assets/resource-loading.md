# Поиск игровых ресурсов на PC

Оригинальная PC-игра получает корневой путь данных из 32-битного представления реестра Windows:

```text
HKEY_LOCAL_MACHINE\Software\Konami\Winx Club
MediaPath
```

`MediaPath` — общий путь для установленной игры. Каталог EXE сам по себе не заменяет этот корень; несколько копий игры могут обращаться к одному значению реестра.

Ресурсная система разрешает имена файлов относительно выбранных источников данных. Затем общие загрузчики Sparkplug читают контейнеры, создают объекты и связывают ресурсы. Для модели нужны не только вершины: ссылки на материалы, текстуры, узлы и skin входят в общий объектный граф.

Наши инструменты принимают собственные пути к входным файлам. Например, конфигурация NativeValidator задаёт выбранную копию и условия запуска отдельно; её параметры нельзя выдавать за правила поиска файлов оригинальной игры.
