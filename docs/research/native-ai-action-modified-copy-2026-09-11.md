# AIAction: Copy изменённых полей

Проверены **36 классов**: 36 полных PC Copy и 36 независимо ограниченных PS2
components. Это 31 различный адрес Copy на каждой платформе: шесть классов
используют один base Copy. **147 переносов собственных полей** имеют одинаковые
ширины/порядок и смещения PS2=PC+4. Неизменность остальных байтов проверена.
Количество классов не выдаётся за количество уникальных методов.

## Направление и общая база

В original API `this` — **источник**, единственный аргумент — **получатель**.
PC base `58FDD0` сначала вызывает `58FD30(destination)`, затем original
BaseObject Copy. PS2 `223250` содержит аналогичную inline очистку получателя.
При пустом current и контейнере получателя остальные байты общей полезной
нагрузки сохраняются; база не копирует её целиком из источника.

PC объекты сначала созданы настоящими factories каждого класса. Контекст:
настоящий пустой Node, известные borrowed engine/scene links, настоящие static
clone-map startup и CloneManager. После создания source и destination payload
изменены разными, зависящими от смещения, конечными float32 bit patterns.
Byte-поля источника заданы A5, чтобы проверить перенос raw byte. Разные значения
позволяют заметить перестановку полей или неверное направление Copy.

Поля current/container оставлены пустыми и сохраняют подготовку factory.
Проверены весь source и весь destination до/после. Source не меняется.
У получателя меняются только перечисленные собственные поля. Это намеренно
изменённые входы Copy, не валидные активные персонажи. Destructors после порчи
неисследованных pointer fields не запускаются; новый lifetime не заявляется.

## Что переносится

Все offsets далее шестнадцатеричные. Полный список независимо извлечённых
PC/PS2 полей сохранён в машиночитаемом контракте.

| Группа | Собственные переносы |
|---|---|
| AIAction, DroidWander, GhoulScript, Help, Hurt, IceWormHoles, Idle, KikoHole, KikoMoving, MikaelWandring, WinxFly | Нет: изменённая полезная нагрузка destination сохраняется |
| Attack | Четыре word PC3A8/3AC/3B0/3B4 |
| DroidAttack, IceWormAttack, MosquitoAttack, ShadowBeastAttack, SpiderAttack | Три word PC3A8/3AC/3B0 |
| BacoAttack, GolemAttack | Пять word PC3A8..3B8 и byte3BC |
| DarcyAttack, IcyAttack | Word PC3A8/3B0/3B8/3BC; пропущенные промежутки сохраняются |
| IceGargoyleClaw/Withdrawl | Word PC3AC/3B0/3B4/3A8, в указанном порядке |
| IceGargoyleSleeping | Word PC3A8/3AC |
| FishWander, FlyingWander, Wander, IceGargoyleAttack | По12 переносов; наборы различаются |
| Frog, Knut, Minotaur, Stormy, Troll, Yeti | Отдельные подтверждённые наборы в контракте |

Например, Knut переносит byte PC3AC, а не весь word: соседние три байта
получателя сохраняются. Stormy переносит PC3C0 там, где Darcy/Icy переносят
PC3BC. FlyingWander использует PC3D4, а FishWander/Wander — PC400. Это причины
не заменять собственные Copy одним memcpy всего объекта или одинаковым набором
для внешне похожих классов. Pointer-shaped words здесь переносятся как raw32;
тест не превращает их в владеющие deep copies.

## Независимое PS2 подтверждение

PS2 собственные суффиксы начинаются после original base-call с V0=1. Регистры
source/destination/result восстановлены по конкретному прологу каждого Copy;
раскладка S0/S1/S2 различается между классами. Суффикс заканчивается до загрузки
сохранённого RA и LQ. Original completion `104F00` исполняется как настоящий
no-op; opaque ненулевой manager record — явный вход, не созданный PS2 manager.

Для классов, прямо использующих base `223250`, исполнен его пустой cleanup
prefix `223268..2233A4`, включая настоящий `100320` и completion, без SQ/LQ.
Полная вложенная транзакция derived→base→derived на PS2 этим не заявляется;
подтверждены отдельно база с пустым контейнером и собственный перенос при
успехе базы. На PC для каждого класса возвращается полный original Copy.

147 own transfers извлечены независимо из PC и PS2 bytes, затем проверены
исполнением. Первоначальный исследовательский фильтр пропустил PS2 LWC1/SWC1
при подсчёте Baco, считая только LW/LBU. Self-check остановил подготовку до
native тестов. После чтения raw окна добавлен этот вид переноса; исходная версия
фильтра сохранена. Различий реального набора полей после исправления не осталось.
NaN/особое FPU состояние не заявляются: word inputs в тесте конечные.

## Время и остающиеся границы

Два пилота (база и Attack):4 исполнения за0,794s. Один общий пакет остальных
34 классов:68 исполнений за12,504s. Все native проверки прошли с первого запуска.
Время относится к runner без внешнего Python startup; полный corpus и прежние
lifecycle тесты не повторялись.

Открыты очистка непустого destination graph, self-copy, aliasing владеющих полей,
полная PS2 транзакция и жизненный цикл намеренно изменённых pointer inputs.
Icy с ранее неизвестной подготовкой destructor не объявляется исправленным.
