  undo/redo, экспорт и сохранение с повторным чтением. Конечные операции
  Exporter, TextureTool и HairPatcher также прошли выбранные проверки.
- SanToVmd исправлен для вызова через Python API с Windows-1251 stdout:

## Ускорения и границы

Подбор Sky/Fog файлов переведён на индексы SQLite и точечный поиск объектов:
0,030/0,058 с в сохранённых измерениях. Native transfer удаляет ветви пачкой
и выдаёт ID без повторного сканирования каталога. При загрузке runtime mips
устранена лишняя копия массива; GPU получает уже готовую цепочку из общего
кода. Смежные проверки объединялись, неизменённые наборы не повторялись.
Для общего envelope writer устойчивого ускорения не измерено; его выигрыш —
одна реализация и устранение дублей, а не заявленная экономия времени.

Сбои native transfer и SAN устранены; исходные неудачные проверки сохранены
рядом с успешными. Остались пять предупреждений сборки TextureTool
(несовпадение analyzer/compiler и устаревший Bitmap.Save в тесте), без ошибок
сборки. Неподтверждённые операции имеют явные границы: weighted Fog,
default Font startup, полная симуляция/отрисовка частиц, полная игровая
видимость/кадр и отдельные редкие формы authoring. Полное совпадение кадра
с игрой и готовность PS2 runtime не заявляются.

Следующие пакеты для срока **14–15 сентября**: rigid lighting; контракт
материалов для внешнего экспорта и импорта; оставшиеся нужные операции LVL,
включая передачу свежей local pose SkyBox; затем компактная приёмка операций.
Полный реверс неиспользуемых методов не должен вытеснять эту очередь.
Это остаётся целевым сроком, а не подтверждённой оценкой завершения:
объём поддержки материалов в целевых форматах ещё требуется зафиксировать.

21 пакет нельзя перевести в процент готовности всех ядер. Последние
самостоятельные оценки исполняемых файлов остаются PC 36,032742% и
