# Вход и выход триггеров: настоящие HUD-зависимости

11 сентября 2026. Проверены GenericTrigger v21/v22, собственные entry/exit
PivotingDoor и PushButton и используемый ими обработчик состояния пустого
HUD-окна. Это исследование игровых классов, без изменения интерфейсов tools.
[Контракт и точные источники](../../research/trigger-entry-exit-contracts-2026-09-11.json).

## Общий вход и выход

Generic enter `5903B0 / 3AC780` пропускает запрос, если слово130/13C равно0,
либо одновременно ненулевые bytes125/131 и127/133. Затем настоящий HUD getter
`559530 / 379470` читает window144/14C через HUD+60. Если он ненулевой или
собственный byte138/144 ненулевой, запрос также пропускается.

Иначе вызывается HUD enter `55AED0 / 3794E0`. Только после его возврата
собственный byte144/150 записывается как1. Этот byte не доказывает показ окна:
HUD может штатно подавить показ, а триггер всё равно выставит свой флаг.
Такое оригинальное поведение сохранено, не исправлялось под ожидание стенда.

HUD enter сначала требует cached widget294: при его отсутствии ищет объект
через окно и виртуальную операцию его Node. Эта ветвь на PC остановлена до
неисследованного lookup; подставленного найденного объекта нет. Если cache
уже есть, GameFlow1B0 со значением70,71 или72 подавляет показ. Его также
подавляет ненулевой visible byte другого окна HUD+6C, если указатель есть.
При остальных входах настоящий обработчик55D1C0 устанавливает состояние
основного окна, затем идёт виртуальная операция cached widget. PC остановлен
у55AF40 до её dereference; lookup/widget callback не выдаётся за изученный.

Generic leave `590420 / 3AC730` вызывает HUD hide `5594E0 / 3794D0`, который
передаёт основному окну state0. После возврата обнуляет свои bytes144/150
и138/144. На PC эта цепочка исполнилась полностью на настоящем обработчике.

## Состояние пустого HUD-окна

`55D1C0 / 37E790` получает byte состояния. Для окна type18 и ненулевого
состояния сначала отправляет игроку код27D1, payload6/0. PC проверяет type
в13C защищённым оригинальным участком4066CE; PS2 использует word144.
Передача остановлена на435D30 PC / перед target vtable read37E818 PS2.
Проверены реальные аргументы/сформированный envelope, receiver callback открыт.

После этой ветви записывает window byte144/14C. Для пустого списка widgets
затем обнуляет Node localX/localY по20/24, помещает по28 значение window140/148
со знаком «плюс» для ненулевого byte и сменой знака для0. Отмечает dirty bit0
в NodeB0/B4. Внешний Node и вся запись окна проверены по полному буферу.
Проверены states0/1/255, height10/−10/0,5, начальные dirty40/2/FFFFFFFF.
Непустой список widgets, renderer и нормальная конструкция HUD не заявлены.

## Производные триггеры

Pivot enter `539BC0 / 3B3C60` пропускает Generic enter, если собственный byte
188/1A0 ненулевой. Затем записывает active126/132=1 и profile504=8.
Push enter `53B130 / 3B5A50` всегда вызывает Generic enter, после возврата
ставит active=1 и profile504=16. PC shared leave53D360 сначала выполняет
Generic leave, затем обнуляет active и profile504. У PS2 отдельные оригинальные
адреса3B3C10/3B5A00 с теми же собственными stores.

Одинаковый PC leave проверен один раз на Pivot receiver, повторного score
за второй адрес класса нет; у обоих классов дополнительно изучен собственный
entry. На PS2 post-parent tails запускаются отдельными свежими компонентами
с объявленным S0. Это не возврат успешной заглушки родителя и не полный Tick.

## Исполнения и исправление стенда

78 разных квалифицированных исполнений: PC42 (30 полных возвратов,9 границ
cached widget,2 lookup boundaries,1 сообщение); PS236 независимых компонентов.
В каждой основной пробе проверены40KiB borrowed records и исходные PS2 окна.
Дополнительно три предварительные PC window-пробы подтвердили защищённое
чтение type13C; это supporting evidence, не дополнительные классы.

Первый пилот15 дал14 совпавших результатов и1 остановку на LQ. В PS2 window
пробе отсутствовал вход V1=18: оригинал устанавливает его до исключённых SQ
stores. Исправлена только подготовка стенда, исходные bytes не менялись.
Обе затронутые PS2 window-пробы повторены: и исходно упавшая, и совпавшая
по конечной памяти на неверном пути. Первая версия сохранена и не засчитана
для этих двух случаев. Остальные13 квалифицированных результатов не повторялись.

Пилот1,710s, адресный повтор2 / 0,034s, пакет63 / 5,860s внутри процессов.
Всего80 основных попыток для78 квалифицированных случаев; отдельный PC scout
3 / 0,666s. Дальнейшие PS2 SQ/LQ, HUD enter body и parent bodies остаются
объявленными границами; полные PS2 цепочки не приписываются компонентам.

Шесть updates +5: GenericTrigger PC55→60/PS250→55;
PivotingDoor и PushButton PC30→35/PS225→30. Новых C++ и полностью закрытых
классов нет. Подтверждённые helpers HUD не получают выдуманного class credit.
