# Освобождение ресурсов Remix при заполнении кэша

13 сентября 2026. В закрытом запуске **Домино → Алфея → Домино** устранено ожидание
TTL перед приёмом геометрии нового уровня: Алфея получила **871 native instance
на первом полном кадре 1586**, обратный Домино — **446 на кадре 2975**. Лимиты не
увеличены. Это проверка собственного backend управления ресурсами, а не изменение
восстановленной логики игры. Исходная проблема описана в
[отчёте о native camera](winx-remix-native-camera-submit-2026-09-13.md).

Перед `CreateMesh` и обоими путями `CreateMaterial` общий
`EnsureSurfaceResourceRoom` проверяет прежние пределы: **512 meshes, 256 materials,
64 MiB mesh bytes**. Сначала удаляются материалы прошлых кадров без ссылок от
meshes; затем — самые старые meshes прошлых кадров и освободившиеся материалы.
Ресурсы текущего кадра и материал создаваемого mesh защищены. При ошибке Destroy
сохраняются ownership, зависимости и счётчики памяти; повторная pressure-попытка
для того же ресурса в этом кадре запрещена. Обход ограничен, возраст учитывает
переполнение unsigned frame. Если места нет, сохраняется D3D fallback.
Периодический TTL 300 кадров с проверкой раз в 30 кадров и принудительное
освобождение при смене политики сохранены.

Проверен именно adapter
`031456AB984230E19C1ECCF019AC10F322085683118819EC314FBABBAEB611B5`,
run `play-rtx-20260913-012849-680`, PID 10704; процесс завершён.
Исходники этого состояния заморожены в
`local-data/rtx-remix/material-channel-tests/pressure-v1/source`, включая вывод
pressure counters. Последующая работа над native materials в рабочем дереве
к этому результату не относится. Полные SHA-256, пути артефактов и границы
доказательств находятся в [JSON-манифесте](../../research/winx-remix-resource-pressure-2026-09-13.json).

| Момент | Native instances за кадр | Mesh cache | Удалено meshes / materials по pressure, накопительно | Отказы / ошибки ресурсов |
|---|---:|---:|---:|---:|
| Алфея, первый полный кадр 1586 | 871 | 512 | 51 / 0 | 0 / 0 |
| Домино, первый полный кадр 2975 | 446 | 512 | 102 / 3 | 0 / 0 |
| Последняя запись ресурсов, кадр 3900 | 446 | 228 | 102 / 3 | 0 / 0 |

В предшествующем загрузочном кадре 1584 захвачены 555 диапазонов, mesh calls ещё
не было. За два перехода зарегистрировано 102 pressure-запроса и 102 успешных
удаления meshes. К кадру 3900 суммарные удаления достигли 563 meshes и
53 materials: прежнее освобождение по TTL продолжало работать. За записанные
кадры подано **2 280 256 native instances**, сравнены **966 поколений буферов**,
расхождений байтов и layout нет. Это повторные подачи по кадрам, не число
уникальных объектов и не процент полноты всей сцены. Камера прошла **3815
SetupCamera** без API errors и повторных подач за кадр; внутреннее состояние
GPU camera этими счётчиками непосредственно не измеряется.

Проверки сохранены с исходниками и исполняемыми файлами:

- `Test-SurfaceResources.ps1 -Name pressure-v1`: **9379 проверок, 773 намеренно
  введённых отказа, PASS, остаток 0**. Без GPU. Проверены реальные пределы кэша
  и памяти, порядок освобождения, общие материалы, защита текущего кадра и
  входящего материала, frame wrap, слишком большой запрос, сохранение ownership
  при ошибках, ограничение повторов, отсутствие Destroy API, TTL и forced policy.
  Синтетический fixture проверяет наш backend; поведением игры он не объявляется.
- MaterialChannels на system D3D9 с recording API: **402 проверки, PASS** в
  `material-channel-tests/pressure-v1/elevated-run/result.json`. До этого были
  **две неудачные попытки**: создание D3D device в sandbox; затем elevated-запуск
  в прежнем cwd, отклонённый проверкой свежего каталога. Тот же EXE прошёл в новом
  подкаталоге. Отдельных stdout/stderr не сохранено: причины известны из tool
  outputs и наблюдения root; первый `result.json` пуст. Сообщённый второй
  `result-elevated.json` также был пуст, в сохранённом каталоге он не найден.
- x86 adapter собран и использован в игре; x64 compile-only завершён, SHA-256
  `E51AF394DF6CFAB3AF577E54ED04C779739BECFA1576EDD168A3154491798678`.
  x64 сборка не объявляется проверенной в этой x86 игре.

Охват запуска — только сцены **4 и 27**. Первая попытка возврата из Алфеи
сохранена как `test_interrupted`: выбор уровня не подтвердился при диалоге 70.
В Sweep добавлены ограниченные попытки с проверкой `debugOpen` после F1 и guard
диалога; повторный возврат успешен, в Домино подтверждено продвижение на 100
кадров в state 4. Алфейские `idle/moved` снимки первого прохода сделаны в
`[27,70]`: они подтверждают продолжение рендера, но не движение персонажа.
Snapshot скриптов сохранён при подготовке отчёта, без утверждения, что его hash
был записан при старте игры.

`user.conf` и `winx.ini` в папке игры побайтно совпали с `.before`. Реальный
bridge config — `local-data/Winx Club/.trex/bridge.conf`: `Start-Probe.ps1`
временно включает API, `Restore-LiveConfig.ps1` после завершения PID возвращает
копию только при совпадении временного hash. Автовосстановление записано в
`bridge-config-restored.json`; итоговый файл тоже совпал с `.before`. Проверка
была read-only. Предыдущий adapter и canonical DLL сохранены в
`surface-resource-tests/pressure-install-v1`.

Полный lifecycle остаётся открытым. В фактических логах
`<run>/workdir/rtx-remix/logs` renderer при выходе сообщил **41 common device
object not disposed**, хотя обе стороны bridge завершили cleanup успешно.
Также осталось сообщение уровня info об исчерпании бюджета Opacity Micromap
(110 300 686 bytes запрошено при 78 359 313 свободных). Startup warnings и
renderer fallback-сообщения сохранены. Live-проверка задействовала предел числа
meshes; предел bytes/materials и ошибки Destroy проверены fixture, а не
искусственно вызваны в игре. Если сам текущий кадр превышает лимит, fallback
остаётся ожидаемым результатом. Все уровни, длительные сессии и device recovery
этим этапом не закрыты.

Следующий блок подготовлен без изменения игровой логики: существующее тело
`spDXRenderer::ApplyTextureStateForAnalysis` (PC4BB1F0 / CP31) вынесено в общий
inline helper `Sparkplug/Code/SparkplugDX/spPCTextureStateMapping.h`, класс
делегирует ему. Тело совпало целиком после нормализации переводов строк
(1694 символа); публичный интерфейс класса сохранён. Существующий target
`SparkplugDXRenderStateTests` прошёл **1727/1727**, а **900 capture records в
9 группах, 34 970 bytes** совпали до и после. Frozen evidence:
`native-layout-tests/2026-09-13-texture-mapping-v1`. Новых эмуляций и GPU-запусков
для extraction не было. В pressure-only adapter материалы ещё получаются через
D3D; подключение общего mapping к ordinary native material — следующий шаг
[материального исследования](winx-remix-native-material-frontier-2026-09-13.md).
