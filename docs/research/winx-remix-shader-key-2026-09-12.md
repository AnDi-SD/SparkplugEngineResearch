12 сентября 2026. Собственный диагностический мост, не новый shader renderer.
Установлена DLL `shader-key-v2`, SHA256
`E76D956BAF0E10D2C2AEE46B72396E64C69F199C56B0CA771FD5B41D058806ED`.
Рендерная база остаётся `surface-combiner-v2`; её копия сохранена в
`local-data/rtx-remix/before-shader-key-2026-09-12.dll`.

## Сделанный шаг

Опция `-ShaderSemantics` подключает наблюдатель оригинального
`spPCShaderManager::4C8980(mask, lightTypes)`. Сама игра продолжает выбирать
и создавать шейдер, пользоваться кэшем и возвращать NULL для FFP.
Прослойка получает настоящий ключ и возвращённый игровой объект. При первом
выборе ключа и на контрольных draw она сравнивает сохранённый в игровом объекте
bytecode с `IDirect3DVertexShader9::GetFunction` и связывает его с shader audit.

Включение требует проверенного debug EXE; launcher автоматически включает
shader/material audit. Меняется один слот vtable, до начала рендеринга.
Переноса машинных инструкций в trampoline нет. Файлы EXE и оригинальные
shader-ресурсы не изменены. Для наблюдения используется исходный render thread.

`qualify_shader_key.py` проверил целевые участки pristine и debug EXE:
1424 байта manager selection, 408 байт renderer key, 80 байт device creation
и 40 байт manager vtable полностью совпадают. ABI thiscall с двумя аргументами,
возвращаемый объект и handle по +0x50 опираются на CP38/57/39. Это адресная
квалификация данной PC-сборки, не перенос адресов на произвольный EXE или PS2.

Новая опция `--native-keys` в общем `analyze_pc_shader_contract.py` передаёт
наблюдавшиеся ключи уже восстановленному C++ shader manager, составляет
исходник общим effect template и компилирует его Microsoft D3DX9_24, flags=0.
В shim/Python не добавлено второй реализации построения ключа, skinning
или освещения. Каждый ключ проверяется против именно связанной с ним программы,
с сохранением всех исполняемых инструкций и полной таблицы констант.

## Игровая проверка

Закрытый запуск:
`local-data/rtx-remix/runs/play-rtx-20260912-193022-699`.
Оконная Алфея → Домино → Алфея, запуск через StartLevel и штатное F1-меню.
Домино после движения продвинулось на 142 кадра, возврат Алфеи — на 75.
Это короткая проверка загрузки, движения и возврата кэша; не прохождение уровней.
Гардиния 2 не запускалась.

- 17 полученных программ, все 17 дошли до server bytecode и SPIR-V.
- 10 сгенерированных Fixed-вариантов реально использовались в draw.
  Их 10 настоящих ключей дали точное совпадение инструкций и CTAB.
- На frame 6900: 6 139 369 вызовов manager, из них 5 989 643 вернули NULL.
  Это штатный FFP-путь, а не потерянные shader-сборки.
- 20 424 контрольных draw: 19 918 без VS, 506 с подтверждённой связью ключа.
  Unlinked, ошибки и срабатывания лимитов — 0.
- Четыре редких варианта попали в запись первого выбора, но не в периодические
  draw-снимки. Полный shader audit отдельно подтверждает их 2/10/2/12 draw.
- D3D9 create/bind/constants/draw и материал-аудит: ошибок 0.
  Старое сообщение Remix `[41] common device objects were not disposed of`
  при выходе осталось; его устранение здесь не заявляется.
- EXE, NVIDIA DLL, winx.ini, user.conf, сохранения и bridge.conf проверены:
  сохранены; временная настройка bridge восстановлена, тестовая игра закрыта.

Повторного использования COM-адреса с другим shader object в этом прогоне
отдельно не воспроизводили. Мост не держит COM-ссылок: на sampled draw повторно
читает native object и bytecode, не принимает старую таблицу pointer → смысл.
Журнал ограничен 16 МиБ, ключи — 1024, отдельный shader — 16 КиБ.
Запись первых выборов ограничена первым встреченным ключом; полное покрытие
всех возможных вызовов и специальных shader managers не заявляется.

## Стало ли проще

Один и тот же закрытый запуск, тот же SDK и C++ source probe:

| Проверка | Прежний набор кандидатов | Настоящие ключи |
| --- | ---: | ---: |
| Компиляции/сборки всех ресурсов | 165 | 24 |
| Сопоставленные программы | 17/17 | 17/17 |
| Время внутри анализатора | 3,200 с | 0,525 с |

В этом измерении анализ ускорился в 6,10 раза, число компиляций уменьшилось
на 85,5%. Это одно парное измерение офлайн анализа, **не ускорение FPS**.
Старый набор кандидатов сохраняется для исследования ещё не исполнявшихся веток.

Смысловой выигрыш существеннее времени: у ColorMode 1 и 2 настоящий ключ
содержит один источник света, хотя оптимизатор выкидывает неиспользуемую ветку.
По одним инструкциям раньше находился эквивалентный ключ с нулём источников.
Теперь эти ситуации различаются, и порядок point/directional lights, UV flags
и выбранный ColorMode известны из игры, а не из единственного удачного кандидата.

Первая версия наблюдателя писала только периодические draw. Её запись
`play-rtx-20260912-192601-815` дала 9/13 совпадений и корректный отказ анализатора:
четыре кратких программы не имели записанного ключа. Результат сохранён в
`local-data/results/rtx-shader-key-v1-incomplete`; v2 добавляет первые выборы.

Основные результаты сравнения:
`local-data/results/rtx-shader-key-exact-20260912/report.json` и
`local-data/results/rtx-shader-key-search-20260912/report.json`.
Машинная опись: `research/winx-remix-shader-key-2026-09-12.json`.

## Граница и следующий перенос

Изображение этим наблюдателем не исправлялось. Алфея в проверенном кадре
остаётся тёмной. Общая готовность **≈45%**, материалы 25%, шейдеры 30%.
Связь key → bytecode → исходник теперь выполнена, но это ещё не разделение
albedo/ambient/additive color в GPU-пути.

Для следующего изменения доступны настоящие ColorMode и переменные регистры
каждой специализации. Mode 4 требует сохранить добавочный vertex color;
штатный API использует общий RGB combiner для albedo и emission. Независимые
составляющие ещё нужно представить и проверить на GPU. Кроме того, большую
часть этой выборки игра рисует через FFP: переделка одних программируемых
шейдеров не является полным решением материалов уровня. Здесь нет доказательства,
что именно шейдеры или именно FFP объясняют всё затемнение.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File research/rtx-remix/Run-WinxRemix.ps1 -Mode RTX -DebugMenu -ShaderSemantics -SceneLights -SceneGeometry -StartLevel 27 -Windowed
python research/analyze_pc_shader_contract.py --native-keys --run local-data/rtx-remix/runs/ИМЯ-ЗАПУСКА --output local-data/results/СВЕЖЕЕ-ИМЯ
```
