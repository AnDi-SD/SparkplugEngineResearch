# Измеритель готовности функций инструментов

Введён 8 сентября 2026, CP124. Начальный срез: **11 из 16 операций, 68,75%**.
Это переучёт ранее подтверждённых возможностей, не прирост нового цикла и не
конверсия старых 45,62% знания классов. Основной результат — число готовых
операций в явном списке; процент является только его удобным представлением.

## Правило

[Scope v1](../../research/tool-readiness-scope-v1.json) фиксирует 16 команд/сценариев,
их инструменты, критерии приёмки и ограничения. В него входят текущие
поддерживаемые операции и четыре конкретных пробела: запись и resize в GUI
TextureTool, совместная FBX alpha и редкие SAN-ключи в конвертере. Дробить или
удалять незавершённые операции ради роста процента нельзя: изменение состава
требует новой версии с объяснением. Сравнение разных scopes отклоняется.

Каждая операция имеет три независимых этапа:

1. **Контракт:** нужная часть реальных классов/формата подтверждена.
2. **Внедрение:** операция подключена и доступна в фактическом инструменте.
3. **Проверка:** результат прошёл относящиеся к операции проверки.

Готовность засчитывается только при трёх `passed`, evidence и отсутствии
блокирующих вопросов. Частичные этапы отображаются, но дробные проценты за
них не начисляются. Неоценённые операции остаются в знаменателе.
Одна команда, общая для Importer и редактора, учитывается один раз.

100% этого списка означает готовность названных операций в записанных вариантах,
не всех классов движка, всех файлов или всех возможных функций приложений.
Ограничения каждого сценария сохраняются в scope и в полном JSON-отчёте.

## Начальный срез

| Группа | Подтверждено |
|---|---|
| Viewer | Просмотр поддерживаемой сцены; SAN на модели |
| Exporter | Геометрия/размещения GLB/OBJ/FBX; поддерживаемый skin/SAN |
| Importer | Rigid и skinned импорт; fixed-size замена текстуры совместно с редактором |
| Редактор | Размещения; production collision-команды; проект/build/reopen |
| SAN-конвертер | Поддерживаемый SAN → VMD для описанных PMD-профилей |

Проверка извлечения текстур пока `partial`: GUI существует, но короткая актуальная
регрессия именно TextureTool ещё не выполнена. Это не означает, что пользователь
лишился возможности экспорта PNG. Четыре дополнительные операции остаются
блокированными по конкретным ограничениям. Этапы baseline: контракт 13/16,
внедрение 12/16, проверка 11/16.

[Baseline assessment](../../research/tool-readiness-assessment-2026-09-08-baseline.json)
содержит ссылки, SHA-256, наблюдения и происхождение оценок. Исторические
native/visual/target-format проверки учитываются только в описанной области;
новые game/GPU/MMD запуски на этом этапе не заявляются. Неизвестная семантика
и ограничения целевых форматов сохраняются.

## Повторение и изменение результата

```powershell
python research/tool_readiness.py report --details
python research/tool_readiness.py report --json
python research/tool_readiness.py record
python research/tool_readiness.py report --baseline local-data/results/tool-cycle-20260908-1900/baseline-readiness.json
```

`report` читает manifests и ограниченные исходники/документы evidence; EXE,
игровой корпус и SQLite не сканируются. Один файл хэшируется один раз за отчёт.
Изменённый или отсутствующий evidence переводит соответствующий этап в
`needs_review`; старый snapshot не переписывается. Новый reviewed assessment
сохраняется отдельным датированным файлом. Новый source hash без нужной проверки
не является основанием поставить `passed`.

`record` создаёт отдельный локальный snapshot. Сравнение с baseline сообщает
новые готовые операции и утратившие подтверждение. В отчёте цикла отдельно
указываются новые возможности, подтверждение уже существовавших и исправления;
повторное прохождение неизменённого теста не считается новой функцией.

Проверки измерителя: 7 тестов за 0,096 с — неизменный знаменатель, отсутствие
дробного кредита, изменённый evidence, обязательность доказательств, запрет
сравнения разных scopes, неизвестные/повторные ID и запрещённые пути.
[CP124](../../research/tool-cycle-checkpoint-2026-09-08-cp124.json).
