# PC Skin: кости и настоящая clone transaction (CP63)

2026-09-07. Pristine PC SHA-256
`3F022480BF55045DA4BF692E4BC8862ED38FC024E8A964A558FBDFDF646DFC4F`.
Лимиты прежние: 100000 инструкций / 2 секунды / 64 KiB arena на вызов;
новый процесс на сценарий. Статическая clone map создаётся исходным
`52FD90(this=755588)` и удаляется `6D7DB0`, без вызова CRT atexit.

## Исполненные функции и результат

`412BE0` запускает общую операцию, Skin virtual clone `46A1A0` создаёт
`46A120`, регистрирует пару настоящим `412F70`, вызывает copy `46A650`.
Copy освобождает прежние массивы назначения **до** base copy `479E60`,
копирует weights/count, выделяет сначала `count*64` для матриц, затем
`count*4` для костей, копирует все матрицы и вызывает **`412C40`** для
каждого узла. Эта функция использует уже найденную копию или создаёт новую
Node при отсутствии соответствия. Прежний source fallback к исходной кости
был ошибочным и устранён.

| Сценарий | Наблюдаемая семантика |
|---|---|
| Пустой Skin | Две нулевые allocation requests, weights/base group копируются |
| Одна кость | Новая Node с копией local state и фабричным world cache |
| Предварительно mapped | Тот же заданный Node, новая копия кости не создаётся |
| Повторная кость, root Clone | Один новый Node для обеих ссылок |
| Повторная кость, прямой Skin clone | Два новых Node: каждый miss завершает отдельную root transaction |
| Кость-родитель и её ребёнок | Сначала клонируется поддерево, второй слот использует уже созданного ребёнка |
| Copy в непустой Skin | Прежние массивы освобождены, заменены новыми |
| Матрица с NaN/Inf/-0 | Все 64 байта сохраняются без арифметики |

Все завершённые операции возвращают depth `manager+14=0`, число записей
статической map `755590=0`. Skin по-прежнему заимствует bone pointers;
Node parent отдельно владеет своими детьми. Стенд уничтожает Skin,
корневые Node и manager/map; все allocations освобождаются оригинальными
destructors. Подмена clone/register/lookup/copy bodies не используется.

## Перенос в C++

`spCloneManager::CloneReferenceForAnalysis` реализует lookup/miss с тем же
правилом глубины. `Clone` по-прежнему всегда создаёт новую копию и очищает
временные соответствия при выходе root. Хостовый registry слабых owners
связывает map hit с **его собственным** shared_ptr. `spNode` публикует owner
созданного ребёнка, чтобы последующий Skin мог безопасно сохранить ссылку.
Исходная raw map не владела объектами; этот registry — способ управления
памятью переносимой реконструкции, не восстановленный ABI.

Skin больше не использует aliasing shared_ptr от исходной кости к чужому
mapped адресу. При miss создаётся новая Node. Тест уничтожает исходные
owners и проверяет доступность всех костей результата. Raw mapping без
подтверждённого владельца, циклическая ссылка на unique root и self-copy
отклоняются безопасным source guard. Native self-copy освобождает свои
исходные массивы; его UAF не воспроизводится. Не утверждается полнота всех
циклических графов или ошибок аллокации.

`probe_pc_skin_clone.py` / `compare_pc_skin_clone.py`: **8 exact captures**,
сверяются weights/count/base group, полные биты матриц, aliases, parent index,
local/world position и flags каждого Node. Внешними входами остаются только
ограниченные allocator/CRT/stream/diagnostic contracts и известный RTTI.
Максимум наблюдаемого вызова 75460 инструкций, arena 1856 байт.

```powershell
python research/native_workbench.py run pc-skin-clone --deadline-utc 2026-09-07T16:00:00Z
```

Полный RenderNode/Skin/mesh/material frame, все copy errors и неизвестные
поля не закрыты этим срезом. Путь SMO read/write описан отдельно в
