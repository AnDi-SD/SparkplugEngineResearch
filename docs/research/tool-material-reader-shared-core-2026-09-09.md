# Общий reader материалов для tools — 9 сентября 2026

Второй блок дневного цикла до19:00 МСК. `SmoMaterialDataDecoder` больше не
разбирает игровую последовательность полей, состояния, цвета и UV в C#.
Мост вызывает общий `spMaterialSerializer` на настоящем `spDXMaterial` и
созданных им `spMaterialPassLayer`, `spStdLayer`, `spMaterialTexture`.
PC wire `MaterialData` выбирает DXMaterial оригинальной header factory42F4C0;
общий reader42F670→4774D0 уже восстановлен ранее.

## Что изменилось

Один цикл чтения обслуживает полную загрузку ресурсов и явную инспекцию.
При полной загрузке остаются настоящий `ReadFieldReference`, проверка типов и
канонические владельцы. Инспекция наблюдает позиции и ID ссылок через общий
`ReadReferencePrefixForAnalysis`; тела inline-ресурсов ограниченно пропускаются.
Она **не создаёт подставных текстур, контроллеров или загруженного графа**.
Такое частичное состояние обозначено `InspectionForAnalysis` и наружу выдаётся
только как DTO. Объекты материала/проходов/слоёв уничтожаются в мосте после
получения DTO; отдельный handle хранит лишь результат инспекции.

Повторные поля и неизвестные поля, произвольный ненулевой байт vertex alpha,
последний texture-state field8/17 и отключённое UV-поле обрабатывает исходный
reader. Нулевой UV flag потребляет матрицу, но сохраняет прежнее преобразование.
Null field10 очищает fallback texture; null6/11/12 сохраняют прежние контроллеры.
Эта политика общая для обоих путей. Поведение восстановленного алгоритма
не исправлялось: удалены противоречащие ему ограничения C# на порядок, повторы
и значение флагов. ARGB для инспектора наблюдается непосредственно при чтении,
без обратного округления RGBA. Ссылки связываются с каталогом через существующий
индекс документа, вместо полного прохода `Objects.Any` на каждую ссылку.

## Границы

- Native материал хранит до8 проходов по8 стандартных слоёв. Старый C# DTO
  потребителя пока представляет один стандартный слой на проход; иной состав
  явно отклоняется адаптером, не объявляется ограничением игры и не сплющивается.
- C# view требует authored color/power: у свежего DXMaterial power оригиналом
  не инициализирован. Нулевой power не подставляется. Отсутствующая controller
  relationship представлена отсутствием эффективного назначения.
- Сопоставление metadata-ссылок поддерживает используемые TextureData и
  конкретные controller wire classes. Native reader использует реальные семьи
  классов. Инспекция не доказывает возможность целиком загрузить уровень.
- Не восстановленные environment/camera/cubemap/movie ветки остаются явным
  отказом. Ограничение16МиБ, точных extent и количества элементов — защита host,
  не доказательство поведения оригинала на повреждённом файле.
- UI, упаковка релиза и отложенные пользователем три редакторских случая
  не входят в блок. Modern renderer пока отдельно потребляет этот DTO.
