# Цветовые операции на GPU и время жизни API-материалов — 12 сентября 2026

## Что изменилось

Общий контракт материалов расширен: RGB `MODULATE2X` передаётся через
специальный `Force_Modulate2x`; alpha `MODULATE2X`, `MODULATE4X` и `ADD`
передаются раздельно с соответствующими множителями и насыщением до 1.
Это собственный адаптер API, без правил для отдельных текстур, мешей и уровней.

API-материалы теперь освобождаются вместе с неиспользуемой геометрией.
Раньше меши удалялись, а материалы оставались до выхода и могли занять все
256 мест кэша. После 300 кадров без использования выполняется удаление;
обход идёт раз в 30 кадров. Сначала удаляются меши, затем материалы без
оставшихся ссылок. Ошибка удаления сохраняет объект для повторной попытки.
В лог добавлены размер кэша, байты, создания/удаления и ошибки ресурсов.

## Проверенный контракт

| Канал | D3D9 | Remix API | Результат |
| --- | --- | ---: | --- |
| RGB и alpha | SELECTARG1 / SELECTARG2 | 1 / 2 | Выбор соответствующего аргумента |
| RGB и alpha | MODULATE | 3 | Произведение |
| RGB | MODULATE2X | 7, Force_Modulate2x | min(1, 2ab) |
| Alpha | MODULATE2X | 4 | min(1, 2ab) |
| Alpha | MODULATE4X | 5 | min(1, 4ab) |
| Alpha | ADD | 6 | min(1, a+b) |

Обычные RGB операции Remix 4/5 намеренно убирают множитель; RGB ADD не
насыщает результат как D3D9. Поэтому RGB MODULATE4X и ADD остаются
неподдержанными данным контрактом. Модификаторы аргументов, SPECULAR/TEMP,
многостадийные материалы, projective UV и lit FFP также не объявлены
эквивалентными. Исходный путь игры сохраняется при отказе перевода.

Alpha-test использует [исправленный общий перевод](winx-remix-alpha-material-2026-09-12.md):
выключенный тест → ALWAYS, включённый сохраняет функцию и порог.

## Проверки

1. `Test-SurfaceMaterial.ps1`: **384 пары кадров, 3472 checks, PASS,
   maxChannelDelta=0**. System D3D9 FFP сравнивается с независимым pixel shader,
   исполняющим экспортированный descriptor. Это проверяет все RGBA-каналы,
   четыре набора аргументов и четыре UV-варианта; допускаемая погрешность 1,
   фактическое совпадение побитовое.
2. `Test-RemixMaterial.ps1 -Combiner`: собственная известная сцена исполняется
   непосредственно через штатные NVIDIA client/server DLL. Пара
   `material-fixtures/2026-09-12-combiner-native-v3` и
   `material-fixtures/2026-09-12-combiner-remix-v4`: **25 случаев / 50 кадров**.
   `combiner-validation-v4.json`: **72 проверки PASS**.
3. Native RGB сравнивается с Remix albedo после штатной степенной кривой 2,2;
   это именно функция pinned `color.slangh`, не точная кусочная sRGB-кривая.
   Максимальное расхождение — **0,589 значения 8-битного канала**, допуск 2
   учитывает независимое квантование обоих изображений. Проверено 19 видимых
   случаев; шесть отсечённых сравниваются по отсутствию полигона.
4. Alpha проверяется независимо от RGB по результату теста GREATER при
   заданных порогах, включая насыщение 2ab/4ab/a+b. Проверки не означают
   точного измерения всех промежуточных float alpha или всех функций сравнения.
5. `Test-SurfaceResources.ps1`: **44 проверки PASS**, 5 удалённых мешей,
   7 материалов, 2 искусственных отказа, 0 оставшихся объектов. Проверены
   общий материал нескольких мешей, порядок, повтор после отказа, orphan
   material, недоступный API, период обхода и переполнение счётчика кадров.

Первые 17 комбинаций отдельно прошли 51 проверку на штатном Remix до
расширения набора. В `combiner-remix-v1` сохранялся raw texture debug view 32
до combiner; его кадры подтвердили загрузку DDS, но не использованы как

до завершения процесса; нулевой кэш при продолжающемся рендере не требуется.

После Гардинии 1 → Алфея живой лог подтвердил удаление 129 API-мешей и одного
материала: meshCache=0, materialCache=0, resourceFailures=0. Это реальные вызовы
штатного runtime; искусственные отказы проверены отдельно recording API.
Счётчики относятся к собственному кэшу и успешной отправке API-операций через
bridge. Они не измеряют возврат VRAM операционной системе: renderer может
сохранять внутренние пулы; асинхронные серверные отказы не моделируются
синхронным возвратом client API.
В закрытых bridge32/bridge64 логах ошибок API нет. При завершении renderer
записал `[41] common device objects were not disposed of`; аналогичная запись
есть в раннем изолированном stock-стенде без игровой DLL-прослойки. Процесс
завершился штатно; причина этого внутреннего остатка не установлена и не
объявляется исправленной новым кэшем.
Прежние игровые шейдеры и освещение по-прежнему исполняются; разделение
ColorMode 4/5 на albedo/ambient/эмиссию этим блоком не завершается.
Темнота Алфеи, специальные supports, дополнительные камеры и USD capture
остаются открытыми. Гардиния 2 не запускалась.

x86 /W4 build без предупреждений. Контроль x64 компилируется, но не установлен;
единственное предупреждение — прежний неиспользуемый NVIDIA CPU helper
calculateIntensity. Native hooks и игровой профиль относятся к x86 debug EXE.

Готовность материалов **20% → 25%**: расширен работающий набор операций и
подтверждён конечный GPU-путь вместе с удалением ресурсов. Другие категории
без изменения. Общая оценка **43,25% → 44,25%, округлённо ≈45%**.
Рост связан с новыми поддержанными состояниями, а не количеством тестов.
