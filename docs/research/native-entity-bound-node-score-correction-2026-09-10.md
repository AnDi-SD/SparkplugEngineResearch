# Поправка к исходной оценке MoveCtrl

10 сентября 2026. В [досье привязки Node](native-entity-bound-node-copy-2026-09-10.md)
и описании PC assessment ошибочно написано `15→25` для CharacterMoveCtrl.
Предыдущий импортированный manifest `native-platform-entity-direct-family-2026-09-10.json`
содержит **PC10**, поэтому правильная запись — **PC10→25**. PS2 остаётся верной:
15→20. Для BreakableBarrel верна запись PC15→20.

Расчёт базы данных с самого начала использовал фактические оценки, поэтому
числовой итог блока не меняется: PC28,4747612551%, PS219,4273127753%,
544/733 и478/681 оценённых классов. Дополнительных процентов эта поправка не даёт.
Повторный manifest исправляет только актуальное описание PC MoveCtrl при том же
score25 и тех же границах; прежние импортированные файлы сохранены неизменными.
