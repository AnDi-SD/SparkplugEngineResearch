# CP125 — TextureTool: общий writer и рабочий GUI

Цикл 8 сентября 2026 до 19:00 МСК. Закрыты scoped операции просмотра/PNG,
замены RGBA и resize/repack в TextureTool. Проверки относятся к рабочей сборке
2.2; новый GitHub release этим checkpoint не публикуется.

## Что изменилось

TextureTool теперь выбирает `spTextureData` из реального каталога FFPS и читает
поля общим `SmoTextureDataDecoder`. Поиск сигнатур в пикселях, трактовка байтов
длины как texture format и фиктивный marker на `+0x3C` исключены из writer.
Поддержана запись одной встроенной PC Direct3D BGRA32-репрезентации с одним
явным mip. Другие варианты остаются ограничениями конкретного слота.

`SmoTextureDataWriter` и `SmoLeafObjectReplacer` — классы реализации инструментов,
а не приписанные оригинальному движку имена. Они обновляют реальные размеры
полей, FAT и inline ID/size prefixes, расширяют компактные headers, сохраняют
ID, порядок и нетронутые opaque bytes. `FixedSizeTextureWriter` Importer применяет
свою RGB/alpha-политику поверх того же writer. Лишнее PNG encode/decode при resize
и отдельное исправление каталога после старого repacker удалены.

В GUI включены выбор файла/папки замен и сохранение копии. Полный RGBA переносится
без изменения material blend states. Общий `SmoVerifiedOutputInstaller` перенесён
из Importer в `SmoViewer.Core`: исходники защищены, временный файл проверяется,
готовая копия устанавливается атомарно, предыдущая копия получает backup.
Вычисление выполняется в фоне; изображения замен декодируются по одному после
проверки размеров, до 128 МиБ пикселей на кадр.

## Проверки

Явная выборка из шести PC файлов: `gem`, `icebat`, `butterfly`, `Bloom_body`,
`loading`, `rock`. Она покрывает два serializer wrapper, menu/model/skin,
общий материал с двумя текстурами и разные размеры. Полный корпус не сканировался.

- 8 PNG проверены по всем BGRA/alpha bytes; roundtrip исходного PNG побайтно точен.
- 32 варианта записи: исходные размеры, 13×7, 128×64, 1×1, 64×128 и две
  одновременные замены. Каталог, соседние объекты/поля и skin palette сохранены.
- Синтетический контейнер проверяет рост UInt8 → UInt16 → UInt32, перемещение
  inline prefix и сохранность неизвестного extended field. Это структурный тест,
  отдельно от доказательств на оригинальном коде.
- Всего 4248 дешёвых assertions на шести файлах и компактных fixtures за 0,675 с.
- Importer: 192 assertions на двух файлах, точная RGB/alpha-политика и побайтно
  одинаковый с TextureTool вывод resize без округления размеров.
- Avalonia: 16 assertions, загрузка, пять preview-режимов, фиксированная замена,
  resize, binding кнопок, backup, защита исходника и повторное открытие. Проверен
  offscreen render интерфейса. Системные file picker диалоги не автоматизированы.

Оригинальный PC-код загрузил два фактических TextureData-среза 13×7 и шесть
целых SMO: три варианта `gem`, две GUI-копии и `loading` 13×7. Для целых файлов
восстановленный C++ и оригинал совпали по всем захваченным объектам, связям,
материалам, мешам и полным mip-цепочкам; 529 native assertions. Вывод GUI resize
в последней проверке побайтно совпадает с уже проверенным native input.

Это обнаружило лишний запрет NPOT в C++ native-data reader. Для BGRA он заменён
уже восстановленным общим wrapped resampler без dithering; исходные размеры
сохраняются, mip-размеры уменьшаются целочисленно. Новые mip-цепочки 13×7,
23×11 и 17×29 побайтно совпали с оригиналом. Сжатые NPOT остаются ограничением.
Два затронутых CTest (`TextureSerialization`, `SceneSerialization`) прошли за 1,20 с.

## Границы результата

Native проверки исполняют оригинальные инструкции с объявленной памятью COM,
предустановленными входами RTTI и лимитами 1 млн инструкций/8 с на вызов,
30 с на процесс, arena 128 КиБ. Это не отдельный запуск игры/GPU и не обещание
поддержки любого HD-размера. Чтение PS2/cross-platform, внешних источников,
двух платформенных копий и явно записанных mip-цепочек не превращено в запись.
Большие GPU/HD-сценарии требуют своей проверки при соответствующей задаче.

Манифест с hashes исходников, результатов и локальных inputs:
[`tool-texture-validation-2026-09-08.json`](../../research/tool-texture-validation-2026-09-08.json).
Новый измеритель отделяет две добавленные команды от актуальной проверки уже
существовавшего PNG workflow. Старый class ledger этим checkpoint не изменён.
