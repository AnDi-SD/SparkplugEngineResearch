# PS2 SQRT: уточнение проверки прежних результатов

11 сентября 2026. Уточнён открытый остаток
[предыдущего аудита](native-trigger-orientation-and-sqrt-guard-2026-09-11.md).
Его прямой CFG не нашёл SQRT, но оставил75 границ с косвенными переходами.
Новая проверка закрыла эти75 границ именно для достижимости оригинальной SQRT:
в разрешённых этим пробам участках такой инструкции нет.

## Метод и результат

Прежний CFG консервативно заходил за пределы code ranges конкретного guest,
например в холодные фабрики или другие виртуальные методы. Сохранённая
обвязка не допускает такого исполнения: перед инструкцией проверяет её
адрес относительно неизменяемого tuple ranges и при выходе выдаёт ошибку.

Для75 границ разобраны384 ссылки на исполнения из27 прежних result-файлов.
По SHA найдены18 точных версий probe. Literal ranges извлечены из AST;
динамические варианты раскрыты по явно проверенным SPECS либо originalEntry
той же сохранённой записи. Для6 base Copy записей дополнительно проверен
объявленный контекст actual empty-container base prefix. Условные варианты
объединены в консервативное множество допустимых участков.

Получилось63 уникальных окна. Каждое прочитано из pristine PS2 ELF;
все выровненные слова проверены на COP1/fmt16/funct4. Совпадений нет.
Разбор самих окон занял0,629s внутри процесса; повторного запуска guest нет.
Исходные результаты и class assessments не изменялись.

Дополнительно из Git сохранены четыре версии wrapper до введения запрета
SQRT:45a24fc, a9bb829, e2f5543, 2ddfe26. Во всех подтверждены pristine hash
check, tuple ranges и исключение при попытке исполнить слово вне разрешённого
участка. Поэтому косвенный переход за его пределы не мог незаметно превратить
проверяемую пробу в успешное исполнение оригинальной SQRT.

Все27 result hashes и18 probe hashes совпали. Точные версии источников
сохранены отдельно; sourceBindings связывают исходные пути в audit output
с архивными байтами. Самих старых результатов ради новых путей не переписывали.

## Ограничения и учёт

Проверка касается75 открытых границ прежнего аудита и оригинальных слов
в их разрешённых code ranges. Она не доказывает правильность всех инструкций
generic MIPS на EE, произвольного самомодифицирующегося кода или всех проб
за всю историю проекта. Исходный аудит охватывал882 result-файла двух циклов,
1805 записей/515 entry-stop-profile; этот объём не расширялся автоматически.

Новая PS2 normalization/dot по-прежнему открыта: известная SQRT несовместимость
остаётся под явным запретом. Преобразования/rounding, MOVZ и условный delay-slot
MADD из PivotingDoor этим аудитом также не реализованы и не проверены.

При первом чтении старого Python-файла AST parser остановился на UTF-8 BOM.
Исходная версия аудитора сохранена; чтение исправлено на utf-8-sig. Это ошибка
подготовки аудита, до формирования результата и без исполнения игрового кода.
Повторный адресный аудит прошёл, прежние evidence остались неизменными.

Class credit не добавлен: это проверка достоверности уже полученных знаний.
Практическое ускорение — использовать реальные пределы стенда для сужения
аудита, сохраняя его предмет и не переигрывая тысячи незатронутых случаев.
