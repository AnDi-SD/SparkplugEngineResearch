1. Первый проход правильно сверил hashes imported manifests и replay,но
   не обошёл их вложенные ссылки из-за абсолютных Windows paths в базе.
   Его `passed` не является итогом полной проверки. Исходная версия и
   частичный run1 сохранены;добавлена нормализация и обязательное условие,
   что каждый imported manifest действительно разобран.
2. Следующий проход остановился на историческом словаре `sourceBindings`
   вместо списка. Result file run2 не создавался;сохранены исходник и
   диагностика. Именованные runs теперь разрешаются только в один точный
   source внутри соответствующего sealed contract.

   `research/ps2_scalar_prefix.py`. Их sealed contracts уже содержат
   явные архивные привязки того же результата. Run4 сверяет идентичный SHA
   именно по этим привязкам. Глобальный поиск похожего файла или замена
   исторического hash текущим не используются. Все5 разрешены,0 остаются.

Ни один проход не менял ledger,исторические результаты или restored game
code. Guest calls не выполнялись. Это проверка по состоянию после блока37;
