## Документация и сборка

У каждого изменённого приложения есть короткая инструкция для распакованного
пакета и актуальные release notes с пометкой о локальном кандидате.
Manifest schema 2 позволяет копировать `PACKAGE_README.md` как `docs/README.md`;
полные исследовательские README остаются в исходниках. Удалены устаревшие
ссылки на прежние release notes и описание отключённой записи TextureTool.
Благодарность Butermix сохранена в release notes Viewer.

Версия LVLcreator поднята до 0.1.1; footer и окно «О программе» получают её
из assembly. Изменений поведения редактора в этом checkpoint нет.

Упаковщик публикует каждый отдельный проект один раз за вызов. Suite и
отдельные Exporter/Importer/Hair используют один hash-проверенный payload:
три повторных restore/clean/publish исключены. Кэш существует только до конца
вызова. MSBuild ограничен двумя workers, shared compilation отключена,
добавлен явный локальный NuGet source. Native FBX нужен только соответствующим
выбранным продуктам; неизвестное имя отклоняется до сборки.

Повторная C++-сборка остановилась на FileTracker/GetOutOfDateItems с
E_ACCESSDENIED в ограниченной среде. Bridge и исходники не менялись после
[проверки CP128](tool-shared-san-2026-09-08.md). Добавлено явное повторное
использование только при совпадении SHA всех build/source файлов и трёх
runtime-файлов. SHA bridge:
`F38747313113E971D9C7640F0500DB2C40E2BAA554198958F6EDBD605EB99257`.
Это прежняя native-проверка, а не новая успешная C++-сборка.

Сборка шести пакетов завершилась успешно с SDK 8.0.420. TextureTool выдал
два CS9057: Avalonia 12.1.0 analyzer/generator ожидают compiler 4.14, доступен
4.11. Предупреждения не подавлялись; запуск фактического Avalonia-приложения
прошёл. Для полной исходной сборки рекомендуемый SDK уже указан в корневом
README. Установка SDK/runtime в этом checkpoint не выполнялась.

## Адресные проверки

- `release/audit_packages.py`: шесть пакетов, 65 файлов, 29 Markdown,
  18 относительных ссылок; версии launcher/payload, точные копии документов,
  native hashes, отсутствие лишних файлов и внутренних дублей проверены.
- Exporter, Importer и Hair имеют точные одинаковые payload SHA в suite и
  отдельных пакетах. Каждый ZIP member потоково сравнен с исходным пакетом;
  шесть ZIP имеют отдельные SHA-256.
- `research/smoke_release_packages.py`: шесть корневых launcher и три suite
  приложения дали ожидаемое отзывчивое главное окно. Все девять закрылись
  штатно, суммарное время 54,83 с, максимальный job commit 499 417 088 байт.
  Последняя пересборка LVLcreator после нормализации исходников проверена
  отдельно: 8,08 с, 291 491 840 байт, штатное закрытие.
- Smoke работает на приватном desktop, с копиями пакетов, последовательно;
  Job Object ограничивает commit 512 МиБ и число процессов четырьмя. Только
  собственные процессы могут быть завершены по тайм-ауту. Игровые ресурсы и
  команды редактирования не передавались; portable Importer logs без ошибок.
- Пять отказов упаковщика подтверждены до создания output: неверный hash,
  неполный native manifest, выход native path за корень, неизвестный продукт,
  выход output за `artifacts/release`.

Первый smoke-v1 неверно трактовал пустой список окон Windows как ошибку с
кодом 0. Стенд исправлен, результаты v1 сохранены как невалидная диагностика;
вывод о запуске опирается на v2 и отдельный финальный LVLcreator probe.
Проверка запуска не заменяет прежние проверки содержимого SMO/SAN,
редактирования, экспорта, визуального результата и поведения в игре.

Манифест с точными hashes и локальными путями:
[tool-release-packages-validation](../../research/tool-release-packages-validation-2026-09-08.json).
Предыдущие evidence CP125–133 не переписаны. В новой assessment обновлена
ссылка на проверенное описание версии LVLcreator; это не новая функция.
