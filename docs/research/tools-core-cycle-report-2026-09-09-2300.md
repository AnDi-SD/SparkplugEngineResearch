## Незавершённые и нестандартные случаи

| Случай | Состояние и следующий шаг |
| --- | --- |
| Три FAT/envelope writer | Перенос приостановлен: найденный общий producer является host-кодом и меняет lossless-контракт. Рекомендуется согласовать [один общий host encoder](tool-container-writer-boundary-2026-09-10.md), сохраняющий ID/raw names/opaque bytes и потоковую запись. Новая реализация не добавлена. |
| Полная загрузка и память | Source-less TextureData, cached TextureData1848 Alfea01 и файлы>64MiB остаются ограничениями. Skip не выдаётся за прочитанный payload; нужны адресный контракт/чтение конкретной копии и отдельный измеренный memory profile. Palette authoring теперь требует успешного whole graph load. |
| Материалы и неоднозначные поля | Неизвестный DX power мешает полному Material writer; scalar writer его не подставляет. Multipass donor DTO, legacy/orphan/repeated LTS и repeated/missing authoring scalar/palette assignments требуют отдельного выбора операции. Reader сохраняет подтверждённое поведение; редактирование явно отказывает. |
| PC/PS2 Corpus | 8 старых combined rerun-профилей остановлены guard до записи БД. Нужны раздельные PC/PS2 operations/evidence; исторические результаты сохранены. |
| Отложено пользователем для LVLcreator | Cached120/physical84, редкие lossless headers и inverse-world при nonuniform parent. Повторные support slots сохраняются в Workspace, но команды требуют явной адресации. Отсрочки не отменены. |
| Прежние runtime границы | Полный Occlusion Init, защищённый PC MaterialColor constructor, looping particles и повторная непустая NavigationGraph table остаются открытыми/явно ограниченными. Material clock и специальный SkyBox pass требуют подключения backend. Отдельный аудит Text уточнил необходимый следующий объём, полного font renderer не требуется. |
| Проверенная точность | Ошибка округления общего Box/OBB исправлена по оригиналу. Для Light исправлена ошибочная ожидаемая величина теста; игровой код не подгонялся. Raw Skin matrices, включая NaN/-0, сохраняются; алиасы разных ID одного Node и непрочитанные Node extents явно отвергаются, их специальные ABI fixtures пока не построены. |
| Font initialized state | Одна fresh factory/destructor проба подтвердила нулевые height/image/glyphs и неинициализированный baseline. Общий Font должен явно хранить неизвестность baseline до reader assignment; default0 не вводится. |

Exporter/TextureTool/SanToVmd используют общий Core, но этот цикл не объявляет
новый полный acceptance каждого приложения. WinxHairPatcher не менялся и
остаётся отдельной задачей аудита. Общие native bridges не считаются
дополнительными самостоятельными приложениями.
