# SAN-конвертер: общий sampler и spNode, 8 сентября 2026

Проверенный этап цикла до 07:30 МСК. `SanToVmd` теперь вызывает те же C++
`spAnimationSerializer/spAnimation/spAnimTrack`, `spNodeController` и `spNode`,
что Viewer. Самостоятельные Python `Curve`, SAN key decoder, Slerp/Squad,
Euler-to-quaternion и расчёт мировой игровой позы удалены.

## Граница реализации

`sparkplug_native.py` — собственная тонкая ctypes-обвязка: загрузка DLL,
размеры структур, владение handles и копирование массивов. Вычислений движка
в ней нет. C ABI версии 2 дополнен получением числа тегов, подготовленных
осевых данных и мировой PRS. Старые entry points и их структуры сохранены.
`Scene.sample` общий для выдачи матриц Viewer и PRS конвертера.

На кадр конвертер получает всю мировую позу одним native-вызовом. `spNode`
и привязки к animation создаются один раз на скелет/клип; повторное чтение SAN
на каждом кадре отсутствует. Клип закрывается после записи VMD, сцена — после
пакета, включая ошибку записи отчёта. C++-сцена держит собственную ссылку на
animation, поэтому закрытие Python handle не оставляет висячих samplers.

Python сохраняет прикладной выбор имён/ролей, подготовку скелета MMD,
retargeting и запись VMD. Совпадающие имена дорожек выбираются по первой
непустой PRS-роли; разные роли могут прийти из разных дорожек. Это политика
инструмента, не утверждение о полном actor binding игры.

Масштаб, не представимый в VMD, отклоняется на основании подготовленных
массивов настоящего `spAnimTrack`. Копии интерполятора ради этой проверки нет.
SMO-reader скелета пока прежний Python: его удаление зависит от общего native
resource graph. **Всё ядро SanToVmd по новым правилам ещё не готово.**

- 32 коротких теста, включая packed/scalar, cubic/quaternion, двухключевой
  endpoint, повторное время, смену клипа, обратную перемотку, сохранение старого
  VMD при ошибке и время жизни межъязыковых объектов.

  Miku Ver2/Luka/MEIKO. Запуск из изолированной копии с DLL и произвольным cwd.
- Независимый сохранённый MMD Tools reader прочёл весь VMD, включая IK и хвост.
  Все 732 позы редких анимаций сверены с сохранённым original-PC PRS.
  Максимальная ошибка направления сегмента: `1.744849e-6`.
- Шесть C++ suites прошли. C# interop: 2 273 checks, 3.749 секунды,
  peak working set 51 761 152 байта; проверочная сборка без warnings/errors.

Оригинальный эталон не вычислялся повторно: executable и каждый synthetic SAN
проверены по SHA256 из успешного предыдущего отчёта. Новый consumer не меняет
значения, уже полученные оригинальным кодом. Старый Python-конвертер при сравнении
обычных клипов используется только для описания различий, не как источник истины.
Игровые алгоритмы C++ в этом этапе не менялись; изменены мост и приложение.

## Явные отличия и отложенное

Общий host-loader проверяет весь SAN, включая неиспользуемые дорожки. Поэтому
representation 99 в ненужном треке и NaN в исходных коэффициентах теперь дают
явную ошибку. Старый Python-reader мог пропустить такие данные. Оригинальный
reader способен перезаписать часть коэффициентов, но общая host-защита пока
требует конечные входные числа. Эти синтетические случаи отдельно проверены
как отказ; поддержка их через второй parser не добавлена. Если реальные нужные
ресурсы потребуют более точного приёма, следующий шаг — адресно сверить
конкретный reader/prepare path и предложить изменение общей host-границы.

Полная матрица 240 VMD и визуальное проигрывание MMD не повторялись.
Интерфейс не перерабатывался, релиз не упаковывался. Переносимая папка теперь
содержит Python-модуль и DLL; вариант одного автономного Python-файла завершён.
