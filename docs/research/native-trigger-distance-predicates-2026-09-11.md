# Триггеры: реальные потребители геометрического helper

11 сентября 2026. Продолжение [общего семейства триггеров](native-generic-trigger-family-2026-09-10.md).
Из таблиц 43 классов сопоставлены slots10–24:171 уникальный PC адрес и206 PS2.
377 ограниченных линейных окон служат разведкой, не доказательством полного
изучения этих методов. Этот блок проверяет семь разных PC и восемь PS2 v19.

## Проверенное поведение

Все выбранные методы сравнивают квадрат расстояния, без извлечения корня.
Результат true требует строгого «меньше»; равенство возвращает false.
Исполнен настоящий helper `597660→597600 / 293210`, изученный в
[CollectibleGem](native-collectible-proximity-2026-09-11.md). При force0 он
исключает вертикальную составляющую только если `abs(dy)<tolerance`;
на границе высоты она включается. GiantBoulder передаёт force1, исключая Y.

| Класс / PC v19 / PS2 v19 | Порог высоты | Сравнение square |
|---|---:|---|
| CT02OpenDoor / 546D30 / 3A3960 | 100 | float `<20000` |
| GiantBoulderTrigger / 545E50 / 3AD970 | force1 | float `<160000` |
| CTCombinationLock / 548C80 / 3A48B0 | 500 | uint32 square `<word128/134` |
| PhoneTrigger / 548C80 / 3B35B0 | 500 | тот же PC код, отдельное PS2 тело |
| ChangeCharacterPlacement / 541040 / 39BD00 | 300 | uint32 square `<word128/134` |
| GenericSideQuest / 591110 / 3D5DF0 | 100 | uint32 square `<word128/134` |
| DragonFlowerTrigger / 53BF20 / 3AA4C0 | 100 | float square `<converted unsigned word128/134` |
| GenericTrigger / 590640 / 3AC890 | 100 | gate byte124/130, затем uint32 square `<word128/134` |

Смещения и адреса шестнадцатеричные; числовые пороги десятичные. Не переименовываем
word128 в обычный линейный radius: эти потребители сравнивают именно square.
Перевод единиц координат здесь не устанавливался.

CT02OpenDoor/GiantBoulder получают два Node из собственных PC148/14C и
PS2160/164. Остальные используют сохранённый глобальный профиль
`765AD4 / 49FC7C`: profile2B4→record24→Node. Второй Node обычно берётся из
this18; GenericSideQuest использует this24→record24. В фикстуре альтернативный
источник содержит другие координаты, поэтому ошибочная привязка дала бы иной
результат. Глобальный cache miss и normal construction не исполняются.

PC GenericTrigger проходит исходный защищённый переход `590643`. Дополнительное
наблюдение чтения памяти для gate0 иFF зафиксировало оригинальную инструкцию
`40744C: mov al,byte ptr [esi+124]`. Gate0 возвращает false, gateFF допускает
геометрию. Размер чтения — ровно один байт; защищённая логика не заменена.

## Числовые границы

PC `60DB90` является runtime float→integer conversion; здесь не было sqrt.
Его исходные FISTP/FILD и коррекция результата сохранены отдельным capture.
PS2 соответствующие методы используют CVT.W.S и unsigned comparison, с ветвью
для square≥2³¹. Проверенные geometry inputs дают точные небольшие целые square;
ветвь ≥2³¹ не исполнялась. Дробные и исключительные значения не квалифицированы.

DragonFlower преобразует unsigned threshold в float другим путём. Проверены
обычные пороги и high-bit words80000000/FFFFFFFF с маленьким square. Эти
диагностические случаи устанавливают результат сравнения; общую побитовую
точность преобразования произвольных uint32 между PC x87 и EE они не доказывают.

## Общий пакет и границы исполнения

171 разных исполнения прошли с первого раза:79 полных PC методов,12 полных
PS2 методов CT02OpenDoor/GiantBoulder и80 собственных PS2 компонентов остальных.
Пилот15 за1,259s,пакет156 за10,946s внутри процессов. Два дополнительных PC
наблюдения защищённого gate не считаются новыми входами основного пакета.

PS2 использует явный [integer-squares CPU-профиль](native-ps2-integer-square-accumulator-2026-09-11.md).
В компонентах исходный SQ-пролог и LQ-restore исключены, геометрический helper
вызывается и возвращается целиком; его результат не подставляется. Записаны
интерпретированные accumulator/B инструкции и проверена неизменность code bytes.
Во всех случаях проверены целиком36KiB receiver/profile/player/Node records:
исследованные predicates их не изменяют. Scene, действия триггера и lifecycle
этим блоком не закрыты.

PC PhoneTrigger разделяет адрес и входы с CombinationLock:повторное выполнение
не делалось. PS2 PhoneTrigger имеет отдельное тело и13 собственных проверок.
Унаследованные aliases остальных потомков из разведочной таблицы не получают
дополнительных оценок за тот же общий метод.
