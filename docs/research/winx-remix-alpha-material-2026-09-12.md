## Причина и доказательство

В D3D9 `ALPHATESTENABLE=False` отключает сравнение. В pinned NVIDIA source
`InstanceManager::calculateAlphaState` определяет наличие теста по
`alphaTestCompareOp != kAlways`; поле `alphaTestEnabled` не отменяет эту
функцию. Поэтому нулевое поле сравнения в заполненном нулями API descriptor
означает NEVER и скрывает полигон. Обычная D3D9 ветка самого Remix заранее
канонизирует выключенное сравнение в ALWAYS; наш прямой API-путь обязан
делать то же самое.

Это подтверждено на поставленном runtime `remix-main+68edea01`, а не только
чтением более нового reference checkout `b81a7b566b1eeb9edb4dc2b3c9d3972e0f253ad4`.
Новый `Test-RemixMaterial.ps1` создаёт отдельную копию штатного runtime,
окно 960×540, известную геометрию и материалы. Не загружает игру или её ассеты.
Сохраняет кадры, исходник стенда, журнал операций и hashes; имеет лимит времени.

Контрольная пара: `material-fixtures/2026-09-12-native-alpha-v5` и
`material-fixtures/2026-09-12-remix-alpha-v5`, по 16 кадров. Системный D3D9
исполняет оригинальные состояния; Remix получает перевод общей функции
`surface_material::AlphaTest`. `alpha-validation-v5.json`: **21 проверка PASS**.

Проверка относится к видимости в этих состояниях, не к равенству моделей

albedo Remix и обычный native framebuffer имеют разные шкалы RGB.

## Что установлено для следующего блока материалов

- `D3DMATERIAL9.Emissive` не стал независимой поверхностной эмиссией на
  проверенном legacy FFP пути. Материал с этим полем даёт нулевой emissive
  debug buffer; явный API material — ненулевой.
- API opaque material способен одновременно нести albedo и эмиссию.
  Его эмиссия сохраняется при выключении legacy emissive-blend override.
- Совпадающие base/additive draw не воспроизвели исходную сумму на стенде;
  порядок проходов меняет результат. Это пока не годится для общего разделения
  игрового lighting. Нулевой emissive GBuffer у отдельного additive draw не
  доказывает отсутствие его вклада во всех путях частиц и освещения Remix.
- В оригинальном `Shaders/Fixed.rfx` ColorMode 4 **прибавляет** In.Color0 к
  накопленному освещению, ColorMode 5 **умножает** его. В наблюдавшихся lit VS
  присутствует аддитивный вариант. Замена всех oD0 на белый или MatDiffuse
  уничтожила бы известный член игрового результата; такая замена не внесена.
- Shared RGB combiner API применяется и к albedo, и к emissive. Полный перенос
  произвольного независимого vertex albedo/vertex emission ещё не реализован.

Ранние `remix-v1` кадры оказались одинаковыми из-за устаревшего DWM window DC.
Они сохранены как неудачный эксперимент. Стенд теперь захватывает только client
rectangle собственного foreground-окна через desktop DC; анализатор отвергает
набор одинаковых кадров. Варианты v2/v3 использовались для локализации alpha
контракта; итоговая воспроизводимая пара — v5.

Готовность остаётся **≈45% (43,25% по весам)**, материалы 20%. Этот узкий
перевод закрывает ошибочное API-состояние, но не перенос ambient/vertex lighting
игры. Темнота Алфеи и полное разделение материалов остаются открытыми.
