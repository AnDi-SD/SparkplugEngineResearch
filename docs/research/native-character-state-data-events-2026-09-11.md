# CharacterState: управляющие записи и события анимации

19 классов,8 различных PC методов и19 PS2 методов. **244 исполнения, все
прошли:**122 полных PC возврата,38 полных PS2 scalar возвратов и84 PS2
post-SQ event components. Пилот0,257s, общий пакет21,930s; внешние startups
не включены. Базовый input graph и результаты предыдущих проверок разрешений
повторно не объявляются новым исследованием.

Короткие кандидаты выбраны обходом достижимых инструкций внутри ограниченных
PC windows: call,indirect jump и выход из окна исключали метод из этой
выборки. Это ускорение отбора; исключённые методы не признаются изученными
или ошибочными. Полученные кандидаты разобраны и сопоставлены с PS2, затем
выполнены оригинальные методы. Отбор ничего не изменяет в бинарнике.

## Управляющие записи v12

Offsets hex. На обеих платформах state14 указывает на character; от него
move находится PC12C/PS2138. Имена полей аналитические, не original symbols.

| Классы | PC | Поведение |
|---|---|---|
| Blast,Dispel,FrogAttack,FrogHurt,GolemAttack,Hurt,OpenSecretPassage,PhysicalAttack,ShadowBeastHurt,SpiderAttack,Try2Hoist,WayToGo | 523690 | Обнуляет move word4; аргумент не используется |
| FrogJumping | 520E50 | Обнуляет move word4 только при state byte3C=0; значения1/255 сохраняют move |
| MinotaurStunned | 521B60 | Обнуляет move byte60 иword4 в этом порядке |
| ShadowBeastJumping | 523790 | Записывает в word0 аргумента `(old & FFFFFFF2) | 2`; state и связанное move не меняются |

Это void методы. Неопределённые остатки return register не превращаются в
результат bool. Проверены два ненулевых заполнения записей, Frog flag0/1/255,
а для packed word — отдельные изменяемые bits,FFFFFFFF,80000000,12345678.
Весь объём семи borrowed записей сравнивается, а не только ожидаемая запись.

## Имена событий v15

Входная цепочка одинакова: argument1C→event10→указатель на строку.

| Класс | PC / PS2 | Точное событие и запись |
|---|---|---|
| BirdFlyingState | 517C40 / 2E5480 | `event_takeoff`: character byte PC26C/PS2278=0 |
| GhoulJumpingState | 51AD60 / 2E5010 | `air`: в move три word PC1C8/1CC/1D0, PS21D4/1D8/1DC получают0/43BB8000/0; следующий byte PC1D4/PS21E0=1 |
| TrollMovingState | 51A680 / 2F8D40 | `event_air_begin` →state byte3D=1; `event_air_end` →0 |
| YetiMovingState | 51A0C0 / 2F00D0 | Те же два события меняют state byte3C |

Ghoul получает move через character→machine→move:
PC character124,machine12C; PS2 character130,machine138. Значение43BB8000
представляет float375.0. Название «скорость» или «импульс» полю по одной
записи не присваивается. У Troll/Yeti здесь меняются **другие байты**, чем
проверяемые их v13 в [предыдущем блоке](native-character-state-permissions-2026-09-11.md).

PC сравнивает с literal через `repe cmpsb`, включая завершающий NUL:
14 bytes дляtakeoff/end,16 дляbegin,4 дляair. PS2 вызывает исходный strcmp
40A8A8. Проверены точные имена,пустая строка,неизвестное имя,первый byteFF,
добавленный символ,обрезанное имя,верхний регистр и NUL с последующим tail.
Только точные строки доNUL вызывают запись. Остальные данные сохраняются.

## Граница PS2 strcmp

Обработчики исполнены после SQ-пролога до LQ-эпилога с заданными borrowed
входами. Настоящий strcmp вызывается с entry40A8A8,без замены результата.
Для string address сalignment1 он сам выбирает байтовую ветвь40A9D8;
сalignment8 — 64-битную ветвь40A96C. Обе ветви исполнены и записаны в trace.
Исходные литералы загружены по своим реальным адресам и сверены с PC.

Когда оба адреса16-byte aligned, original strcmp выбирает LQ/MMI-путь.
Эта ветвь не поддержана используемым scalar стендом, не исполнялась и
не засчитана. Выбор допустимых alignment1/8 — явные входы эксперимента,
не переписывание strcmp и не утверждение о всех игровых размещениях строк.
Полный PS2 event call с SQ/LQ также остаётся за границей проверки.

Native отказов нет. Exact executable SHA,windows,selected CFG,входы и
контроль всех записей: `local-data/results/native-cycle-20260911-0730/character-state-data/`.
Для каждого из19 уже оценённых классов добавлен один проверенный рабочий
метод, +5 отдельноPC/PS2. Полностью закрытых классов и новых C++ реализаций
этот блок не добавляет.
