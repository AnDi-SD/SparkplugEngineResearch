# PS2 SAN companion — ограниченный interval leaf

Часть CP128, 8 сентября 2026. PC остаётся основной платформой инструментов;
PS2 используется для узких сопоставлений. Полные serializer/Squad/playback PS2
не запускались. ELF stripped, class strings и registration records сохранились.

Pristine `SLES_532.19`, 3 799 600 bytes, SHA-256
`198313352DBF4FA26FF8C5D509F6783FC32F9B504A627E416323C5FFBBFFE8FE`.

| Класс | ID / base ID | Initializer | Factory / allocation |
|---|---|---|---|
| `spAnimTrack` | `33B61869` / `60C839C5` | `0x480060`, 56 bytes | `0x120AD0`, `0x44` bytes |
| `spAnimationSerializer` | `C0ACBFA6` / `42429877` | `0x4830D0`, 56 bytes | `0x184E70`, `0x4C` bytes |

Registry catalog `0x480090` / `0x483100` указывает на завершающие jumps
initializer, не начало функций. Track: name `0x444978`, registration object
`0x4A6F50`, vtable `0x48CF10`. Serializer: name `0x44A670`, registration object
`0x4A9EB0`, table pointers `0x48F050` и `0x48F074`. Имена всем slots не присваиваются.

Оригинальный leaf `0x0011F980`, 268 bytes, SHA-256
`6A95B36A0F19AAE6CD27B75689A240FFDA9CE47C0AAF6AED876A2A79B53ACCF2`
вычисляет индекс интервала и долю времени.
Harness: [`probe_ps2_san_interval.py`](../../research/probe_ps2_san_interval.py).

Guest: Unicorn MIPS64 R4000 little endian, включённый FPU, только scalar leaf;
code/return RX, data 4 КиБ RW. Лимиты: 1 000 instructions / 100 мс на вызов,
30 с на отдельный процесс. Нет callees/imports, OS forwarding, game execution,
MMI/VU. Остановка по лимиту не возобновляется. Модель R4000 не доказывает полную
совместимость с EE и всеми float-особенностями PS2.

Аргументы из тела leaf: `F12=time`, `A1=times`, `A2=count`, `A3=&fraction`,
`T0=cachedIndex`; результат индекса — `V0`. Шесть callsites в окне
`0x11FA90..0x120910` дополнительно показывают `A1=descriptor+8`,
`A2=descriptor+0`, cache в `T0`, fraction на stack. Полный caller не исполнен.

**65 cases / 2 141 instructions / 0,719 с, passed**: 1–4 возрастающих ключа,
неравномерная шкала, прямой/обратный cache. При двух ключах последнее время и
после него дают `(0,0)`; при трёх и более — `(count-2,1)`. Это независимо
согласуется с PC endpoint, перенесённым в инструменты. Допуск fraction `1e-6`;
bit-exact EE FPU не заявляется. Empty/negative cache/NaN/Inf вне проверенных входов.

Первоначальный MIPS32 guest останавливался на PS2 `DADDU` как reserved
instruction; MIPS64 устранил причину без отключения guards. Generic Capstone
может ошибочно назвать EE SQ/LQ/MMI как другие extensions, поэтому такие
mnemonics не используются как доказательство.
