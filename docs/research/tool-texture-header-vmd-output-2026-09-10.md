# TextureTool header и SanToVmd output — 10 сентября 2026

## TextureTool

Удалён второй C# разборщик data-block headers из `SMOTextureTool.Core/SmoDocument`.
Два существующих потребителя (material path и vertex-color preview) теперь
вызывают общий `SmoDataBlockReader` → native `spDataBlockSerializer`.
Игровые алгоритмы и FAT/envelope writer не менялись.

Адресный тест воспроизвёл ошибку старого helper: заголовок `EAFFFFFFFF`
вызывал `OverflowException` при переводе UInt32 payload size в Int32.
До замены прошли 18/19 случаев, после — 19/19; повреждённый размер даёт отказ.
Формы заголовков, extended ID и усечённые данные проверены той же выборкой.

На исходных `SFX/book.smo` и `Characters/Bloom/Bloom_body.smo` прошла 71 проверка;
все три PNG до/после совпали побайтно. Новые material DTO snapshots относятся
только к итоговому запуску: прежний запуск не сохранял DTO. Итоговая сборка
без предупреждений и ошибок. Один неиспользуемый тестовый helper удалён.

Первоначальная новая проверка ошибочно требовала полные 11+9 state arrays.
У book actual Material ID11 содержит legacy field8, а старый material path
наблюдает только field17: DTO хранит 11+0. Исправлено предположение теста,
отсутствующие состояния не заменены нулями. Перенос этого material path
остаётся отдельной задачей. Snapshot сохраняет raw DTO fields, поскольку
старые convenience getters индексируют отсутствующий массив.

Unhandled test assertion оставила наш процесс в Windows crash reporting.
Только этот процесс завершён; focused CLI теперь печатает ошибку и возвращает
exit1. Остальные процессы пользователя не останавливались.

## SanToVmd

`write_vmd` использовал фиксированный соседний `motion.vmd.tmp`: запись
уничтожала ранее существовавший файл с этим именем, а две перекрывающиеся
операции сталкивались. Теперь `NamedTemporaryFile` создаёт собственный файл
каждой операции в каталоге назначения. Замена готового VMD происходит после
закрытия успешно записанного файла; cleanup удаляет только принадлежащий
операции временный файл. Формат VMD, retargeting и игровой sampler не менялись.

До исправления два теста дали три ошибки: success/failure с чужим sibling
и детерминированные перекрывающиеся записи. После оба теста прошли, включая
сохранность прежнего результата при ошибке и отсутствие своих временных
остатков. Также прошли 18 существующих converter tests. Это проверка файловой
операции, не новый полный acceptance всех SAN/PMD.
