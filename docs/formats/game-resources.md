# Игровые ресурсы помимо SMO

SMO задаёт сериализованные объекты движка. Выбор анимаций, игровые компоненты и размещение уровня используют дополнительные файлы.

| Формат | Известное назначение | Граница описания |
| --- | --- | --- |
| ANM | Текстовая таблица из восьми колонок; последняя ссылается на SAN, завершение `end` | Семантика первых семи колонок полностью не установлена |
| SPT | Бинарные игровые компоненты, свойства и ссылки на ресурсы, включая SMO | Полное поведение компонентов и всех зависимостей неизвестно |
| SPL | Размещение и ссылки на SPT/игровые шаблоны | Полный контракт размещения неизвестен |
| SFT | Шрифтовый ресурс FFPS | Общий контейнер и отдельные поля шрифтов |
| SNC | Текстовые правила звуковых событий со ссылками на WAV | Частичное описание |
| CCC | Таблица RGB-коррекции Bloom по моделям и уровням | Частичное описание |
| WXT | Таблица смещений и строк с нулевым завершением | Известны варианты со счётчиком и самозавершающейся таблицей смещений |
| WXD | Определения строковых сущностей | Подробная семантика не установлена |
| WXS | Сохранения или пользовательские настройки | Подробная семантика не установлена |
| SPS | Интервалы, локализованные строки и индексы субтитров | Частичное описание |

Именованная привязка анимации описана в [SAN](san.md). Имя файла модели не заменяет связь между игровым состоянием, ANM и выбранной SAN-анимацией. Просмотр одного SMO не восстанавливает все созданные игрой объекты уровня.
