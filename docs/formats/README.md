# Форматы ресурсов

| Формат | Назначение | Описание |
| --- | --- | --- |
| SMO / FFPS | Сериализованный объектный граф движка | [Контейнер, каталог и поля](smo.md), [типы объектов](smo-objects.md) |
| SAN | Анимация `spAnimation` в FFPS | [Кривые, время и привязка](san.md) |
| STX | Отдельная текстура | [PC-варианты и границы PS2](stx.md) |
| PCK | Контейнер ресурсов PS2 | [Каталог и секторные смещения](pck.md) |
| ANM | Таблица состояний со ссылками на SAN | [Игровые ресурсы](game-resources.md) |
| SPT / SPL | Компоненты, шаблоны и размещение | [Игровые ресурсы](game-resources.md) |
| SFT, SNC, CCC, WXT и другие | Шрифты, звук, цвета и локализация | [Игровые ресурсы](game-resources.md) |

Class ID находится в [каталоге классов](../reference/classes.md). Поля конкретного объекта описаны в его карточке. Ограничения записи конкретной программы приведены в [инструкциях инструментов](../../tools/README.md); наличие описания формата не означает, что все варианты доступны для редактирования.
