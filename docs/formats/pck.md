# Контейнер PCK

PCK используется PS2-версией для хранения ресурсов. Его каталог связывает строки имён, секторные смещения и размеры записей.

Физическое смещение записи вычисляется как `sectorOffset * 0x800`. При чтении нужны проверка строковой таблицы, принадлежности имени каталогу и границ каждой записи относительно размера контейнера. Простая подстановка секторного числа как байтового смещения неверна.

Вложенный ресурс интерпретируется своим reader: наличие записи SMO или SAN в PCK не меняет внутренний формат этого ресурса. Извлечение контейнера также не означает полной поддержки runtime-семантики всех PS2-объектов.

Репозиторий содержит чтение и инвентаризацию PCK в общих инструментах. Универсальный writer PCK здесь не заявлен.
