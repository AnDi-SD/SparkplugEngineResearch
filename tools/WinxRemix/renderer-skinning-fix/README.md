# Шаги массивов skinning в Remix renderer

Наш [патч skin-strides-v1.patch](skin-strides-v1.patch) для `rtx_remix_api.cpp` изменяет шаг чтения двух массивов:

- Веса: `sizeof(float) * bonesPerVertex`.
- Индексы: `sizeof(uint32_t) * ceil(bonesPerVertex / 4)`, поскольку в word упакованы четыре индекса.

Исходная версия и patch hash заданы в [manifest.json](manifest.json). Это изменение внешнего renderer, а не восстановленная игровая логика. Полный renderer с этим патчем ещё не собран и не проверен на GPU; установленный прототип не следует считать автоматически обновлённым.

## Ограничения

`skinning.h` читает B−1 весов и вычисляет последний как `1−sum`; при B1 эффективный вес равен 1. Произвольные ненормированные веса этим патчем не поддержаны. Вклады `weight <= 0` пропускаются, позиция затем не нормализуется; нормаль нормализуется отдельно.

Индексы упакованы в bytes. До вызова API необходимы корректные указатели, размеры массивов, `B > 0` и индексы `< actualPaletteCount <= 256`. Геометрические индексы — отдельный uint32 triangle-list массив.

[test_skin_strides.cpp](test_skin_strides.cpp) проверяет CPU-арифметику и упаковку с выбранными upstream-заголовками. Он не создаёт Vulkan backend и не доказывает результат GPU-отрисовки.
