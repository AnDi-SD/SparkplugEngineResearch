# WinxCoop

[English](README.en.md)

[Релиз 0.1.0 на GitHub](https://github.com/AnDi-SD/SparkplugEngineResearch/releases/tag/winxcoop-v0.1.0) ·
[Заметки к выпуску](RELEASE_NOTES_0.1.0.md)

Пассивный спутник для оригинальной PC-версии Winx Club. Сервер играет обычное
одиночное прохождение, а клиент управляет второй Блум в той же локации.
Положение, направление и основные анимации передаются между играми;
клиент автоматически следует за загрузками серверных локаций.

Спутник пока не участвует в бою, подборе предметов и сюжетных действиях.
Общий мир, HP, инвентарь, квесты и сохранение не синхронизируются.

## Быстрый запуск

1. Откройте `WinxCoopLauncher.exe` из комплекта своей системы: `Win7-x86`
   или `Windows-x64`. Нужна полная установленная оригинальная Winx Club;
   игровые файлы не входят в комплект.
2. В общих настройках сверху выберите установленный `WinxClub.exe`.
   Для игры в окне заранее задайте `fullScreen=false` в её `winx.ini`.
3. Слева, в блоке сервера, нажмите **Создать лобби** и **Запустить игру**.
   Новая игра или сохранение выбираются обычным игровым меню.
4. На другом компьютере справа, в блоке клиента, найдите сервер в LAN либо
   введите `IPv4:порт` и нажмите **Подключиться**. Клиентская игра сама
   загрузит готовую серверную локацию.

Для двух игр на одном ПК используйте разные комплекты программы и адрес
`127.0.0.1:27025`. Подробности подключения, выхода и ограничений — в
[руководстве пассивного спутника](docs/passive-companion.md).
Для готовой папки программы предназначена отдельная
[инструкция комплекта](PACKAGE_README.md).

Язык выбирается справа вверху. **Язык системы** включает русский при русском
языке интерфейса Windows и английский в остальных случаях. Ручной выбор
**Русский** или **English** сохраняется локально и применяется к открытому окну.

## Состав и разработка

`src/Launcher` содержит окно запуска, поиск лобби и координатор пассивного
спутника. `src/Adapter` связывает отображение персонажа с оригинальной игрой.
`src/Networking` содержит собственную сессию и транспорт поверх общего
восстановленного Packet/MemoryStream codec. Это наша интеграция, а не
доказательство готового многопользовательского режима оригинального движка.

Сборка требует Windows, Visual Studio C++ Build Tools, Windows SDK и CMake.
Зависимости и правила исходников описаны в [CONTRIBUTING](../../CONTRIBUTING.md).
Контрактные проверки запускаются из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/WinxCoop/Build-NetworkChecks.ps1
```

Проверки протокола без игры не заменяют проверку двух настоящих игр.
Текущий игровой объём ограничен localhost, Гарденией 1/2 и указанными в
руководстве сценариями. Все уровни, физическая LAN и новая версия внутри
Win7 требуют отдельных проверок.
