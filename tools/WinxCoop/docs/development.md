# Разработка интерфейса WinxCoop

[English](development.en.md)

Окно пассивного спутника — нативное приложение Win32. Общие настройки
расположены сверху, функции сервера слева, клиента справа. Одна программа
выполняет одну сетевую роль за раз; разделение элементов не создаёт второй
сетевой сеанс. Игровую логику и сетевой контракт изменение языка не меняет.

## Строки интерфейса

Все записи интерфейса и сообщения состояния собраны в отдельном
[`LaunchText.h`](../src/Launcher/LaunchText.h). Таблица хранит стабильный ключ
и две строки рядом: английскую и русскую. `TextId` выбирает запись,
`UiLanguage` — язык, а `Text` возвращает перевод. `UiStatus` хранит ключ и
подробность сообщения; `Render` подставляет её вместо `{0}`. Состояние
перерисовывается при смене языка без повторного выполнения операции.

Исходные подробности ошибок, имена файлов, адреса и пути остаются данными;
их не нужно переводить как ключи. В локальном журнале сообщения состояния
записываются на английском независимо от выбранного языка окна.

[`LaunchMain.cpp`](../src/Launcher/LaunchMain.cpp) выбирает язык по
`GetUserDefaultUILanguage`: русский для Windows с русским языком интерфейса,
английский во всех остальных случаях. Ручной выбор сохраняется в локальном
`launcher-settings.ini`, секция `[Interface]`, ключ `language`:

| Значение | Поведение |
| --- | --- |
| `system` | Выбор по языку интерфейса Windows |
| `ru` | Русский |
| `en` | Английский |

Отсутствующее или неизвестное значение использует `system`. Переключатель
не меняет игровую локаль, числовые сетевые поля или формат сохранений.

## Изменение переводов

Добавляйте ключ и оба перевода одной строкой таблицы. Сохраняйте маркер
`{0}` в обоих переводах сообщений с подробностью; порядок слов может
различаться. Не переводите имена файлов и программные идентификаторы.

После правки проверьте обе локализации, системный выбор, сохранение ручного
выбора после перезапуска, обновление уже показанного состояния и читаемость
длинных строк при изменении размера окна. Обновляйте русское и английское
руководства вместе. Готовый комплект получает `PACKAGE_README.md` как
`README.md`, `PACKAGE_README.en.md` как `README.en.md` и оба руководства
`passive-companion` в своём каталоге `docs`.
