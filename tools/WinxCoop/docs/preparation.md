# Подготовка отдельной игры

`Prepare-PrototypeGame.ps1` создаёт новую изолированную копию для сцены Alfea 28
этапа P. Нужна своя оригинальная PC-игра: EXE и ресурсы в комплект WinxCoop не
входят. Подготовка файлов не подтверждает работоспособность кооператива или VM.

Запускайте скрипт в Windows PowerShell 5.1 или PowerShell 7 на Windows. Укажите
каталог, содержащий `WinxClub.exe`, `Media` и корневой `Shaders`, и
**несуществующий** каталог назначения:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/WinxCoop/Prepare-PrototypeGame.ps1 `
  -SourceGameRoot 'D:\Games\Winx Club' -Destination 'D:\WinxCoop\PreparedGame' -WhatIf

powershell -NoProfile -ExecutionPolicy Bypass -File tools/WinxCoop/Prepare-PrototypeGame.ps1 `
  -SourceGameRoot 'D:\Games\Winx Club' -Destination 'D:\WinxCoop\PreparedGame'
```

Родитель назначения должен существовать. Первый вызов проверяет входы и
показывает действие без создания игры. Обычный второй вызов выполняет подготовку
без дополнительного запроса подтверждения. `-Source` — сокращение параметра
`-SourceGameRoot`, `-GameRoot` — альтернативное имя `-Destination`.

Также обязательны проверенные `msvcr71.dll` и `msvcp71.dll`. По умолчанию они
читаются из исходного корня. Если они находятся в другом имеющемся каталоге
вашей игры, задайте `-RuntimeDirectory`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/WinxCoop/Prepare-PrototypeGame.ps1 `
  -SourceGameRoot 'D:\Games\Winx Club' -RuntimeDirectory 'D:\Games\Runtime71' `
  -Destination 'D:\WinxCoop\PreparedGame'
```

Принимаются только две версии, закреплённые SHA256 в скрипте: `msvcr71.dll`
размером 344064 байта и `msvcp71.dll` размером 503808 байт. Игра, CRT и шейдеры
не поставляются этим скриптом. При отсутствии Shaders/Fixed.rfx или любой из
этих DLL, несовпадении размера или хеша подготовка останавливается **до**
создания назначения. Для обоих источников сохраняется режим только чтения.

Исходный путь может содержать Unicode. Назначение и все будущие имена внутри
него должны быть ASCII: корень до 180 символов, любой полный путь до 239.
Скрипт отклоняет reparse points, пересечение исходника с назначением, в том числе
через псевдоним диска, и существующее назначение, даже пустое. Это также относится
к каталогу, оставшемуся после неудачной попытки. Скрипт ничего не удаляет и не
перезаписывает; при ошибке новый частичный каталог остаётся для проверки.

Копируются проверенный `WinxClub.exe`, две закреплённые CRT71 DLL и деревья
`Media` и `Shaders`, включая `Media\Saved`.
Файлы создаются обычными потоками с `CreateNew`, без ссылок на исходник. Корневые
proxy DLL, другие EXE, плагины и прочие DLL установленной игры не копируются.
Всё внутри Media и Shaders сохраняется как данные, включая штатные вспомогательные скрипты;
подготовка их не выполняет. Состав самих игровых
ресурсов должен быть исходным: наличие правильного EXE не доказывает отсутствие
модификаций в пользовательском Media.

Допускается исходный EXE с SHA256
`3F022480BF55045DA4BF692E4BC8862ED38FC024E8A964A558FBDFDF646DFC4F`.
Каждая физическая копия проверяется по размеру и SHA256 прочитанного исходного
потока и повторно открытого файла назначения. Буфер потока — 64 КиБ; целые игровые
файлы в память не загружаются. Исходные файлы открываются только для чтения.

В новом корне создаётся ASCII `winx.ini` с фиксированными параметрами:

```ini
showCinematics=false
useGamePad=false
fullScreen=false
enableSound=false
enableShadows=false
language=en
startLevel=28
testCinematic=false
cinematicToTest=0
```

`config.ini` копируется побайтно только при совпадении с известной исходной
конфигурацией SHA256
`8528B4231A5D3FC302D90C19ABFCA87FE355011A221F13F3F723097FD1C41068`.
В остальных случаях создаётся отдельная минимальная конфигурация:

```ini
[Input]
mouse_exclusive=false
```

Готовый каталог имеет вид:

```text
PreparedGame\
  WinxClub.exe
  msvcr71.dll
  msvcp71.dll
  Shaders\
    Fixed.rfx
    ...
  Media\
    Saved\
    ...
  winx.ini
  config.ini
  WinxCoop-preparation.json
```

Новый отчёт имеет версию 2 и содержит исходный EXE SHA256, закреплённые версии
CRT, проверенные размеры и хеши файлов обоих деревьев,
применённые настройки, способ создания отдельного Saved и итог подготовки.
При ошибке после создания назначения записывается
`WinxCoop-preparation.failed.json`, если запись ещё возможна. Незавершённую копию
запускать не следует.

Скрипт не дополняет уже подготовленные каталоги и не меняет их прежние
манифесты. Для повторной подготовки с полным новым составом выберите новый путь.

Укажите полученный путь как `gameRoot` в `WinxCoopLauncher.ini` или через
`--game-root`. Библиотека адаптера и helper-программы остаются рядом с лаунчером;
скрипт их не копирует и не запускает. Отдельный Saved принадлежит только этой
проверочной копии. Для независимого опыта создавайте новое назначение: сохранения
из временной копии не переносятся обратно в исходную игру.

Параметры лаунчера, одинаковый набор программ на обоих ПК и последовательность
подключения описаны в [руководстве прототипа](prototype-runtime.md).

Этап P ограничен Alfea 28 и отображением движения двух локально управляемых Блум.
Переходы между уровнями и синхронизация квестов, боя, инвентаря и мира требуют
отдельной реализации и проверки.
