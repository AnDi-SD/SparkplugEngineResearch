# WinxCoop: запуск установленной оригинальной игры

**Win7-x86** предназначена для Windows 7, **Windows-x64** — для 64-разрядной
Windows. Каждая папка содержит собственный .NET runtime. Открывайте
`WinxCoop.SessionHost.exe`, сохраняя рядом остальные файлы поставки и
`WinxCoop.SessionBundle.json`. Программа может находиться в доступной только
для чтения сетевой папке. Игровые файлы в поставку не входят.

## Обычный запуск

1. Установите оригинальную игру обычным способом на локальный диск компьютера.
2. В программе выберите папку с `WinxClub.exe` или вставьте полный путь к нему.
3. Нажмите **«Запустить игру»**.

Эта кнопка напрямую открывает выбранный `WinxClub.exe` из его собственной
папки, без аргументов и без подключения мода. Сохраняется штатный запуск
установки, включая обычное главное меню. Лаунчер не выбирает уровень, не меняет
`winx.ini`, настройки, переменные окружения или реестр. Маркер подготовленной
копии, выбор профиля и создание лобби не требуются. Неизвестная версия EXE
также может запускаться: её контрольная сумма записывается только для
диагностики и не служит разрешением на обычный запуск.

Используется стандартный запуск Windows, как при двойном щелчке по EXE,
включая настройки совместимости и обычные запросы прав самой Windows.

Меню и дальнейшее поведение определяет сама игра с текущими настройками
установки. Лаунчер не исправляет и не восстанавливает INI, ранее изменённый
другой программой или вручную.

У обычного запуска нет таймера завершения. Закрытие лаунчера или завершение
сетевого сеанса не закрывает запущенную этой кнопкой игру. Выходите из неё
обычным игровым меню. Успешно выбранная папка запоминается локально.

Обычный запуск **не означает подключения кооператива**. Уже открытая игра
автоматически к сетевому сеансу не присоединяется.

## Необязательный сетевой прототип

Кнопки **«Создать лобби мода»**, **«Подключиться к лобби»** и
**«Запустить с модом»** относятся к отдельному экспериментальному пути.
Он запускает свою игру с адаптером и требует поддерживаемую версию EXE,
совпадение ресурсов и готовность обоих компьютеров. Ошибка этого пути не
запрещает обычный запуск кнопкой выше.

На сервере создайте лобби; на клиенте укажите IPv4 сервера и подключитесь.
`127.0.0.1` подходит только для двух программ на одном компьютере. Запуском
с модом управляет сервер. Если появляются запросы сетевого доступа, разрешите
мосты WinxCoop для используемой локальной сети и продолжите той же кнопкой.
Дождитесь отдельного подтверждения готовности игр; одно подключение к лобби
ещё не означает готовность совместной игры.

Поддержка сцен и действий в сетевом прототипе ограничена. Полное прохождение,
все игровые механики и подключение к произвольно уже запущенной игре не
заявляются. Для native-пути пока нужны короткие локальные пути без кириллицы
и кавычек. Эти ограничения не применяются к проверке версии обычного запуска.

Лимит на экране относится только к сетевому сеансу: по умолчанию 2 часа,
максимум 4 часа. Для его завершения нажмите **«Завершить сеанс»** на сервере
или **«Отключиться»** на клиенте и дождитесь освобождения принадлежащих этому
сеансу процессов. Самостоятельно открытая обычная игра остаётся работать.

## Журналы и настройки

Данные записываются локально, отдельно для каждой программы:

| Программа | Локальная папка |
| --- | --- |
| Win7-x86 | `%LOCALAPPDATA%\WinxCoop\Win7-x86` |
| Windows-x64 | `%LOCALAPPDATA%\WinxCoop\Windows-x64` |

Кнопка **«Папка журналов»** открывает эту папку. `launcher.log` содержит пути,
запуск, диагностическую контрольную сумму EXE, PID и наблюдённый код завершения
обычной игры, а также ошибки и действия сетевого сеанса. Если лаунчер закрыт
раньше игры, записывается окончание наблюдения без кода завершения; неизвестный
результат не выдаётся за успешный выход. Заполненный журнал сохраняется под
отдельным именем, новые записи продолжаются в `launcher.log`.

`launcher-settings.json` хранит выбранную папку игры и параметры соединения.
Журналы сетевых сеансов находятся по умолчанию в `Sessions\Session-…`;
для них можно выбрать другую локальную папку. Кнопка **«Открыть папку сеанса»**
открывает последнюю попытку, включая завершившуюся ошибкой. Для диагностики
сохраняйте `launcher.log` и целую папку соответствующего сеанса.

В сетевую папку программы журналы, настройки и состояние сеанса не записываются.
