# WinxCoop 0.1.0

[English](RELEASE_NOTES_0.1.0.en.md) · [Быстрый запуск](README.md) · [Руководство](docs/passive-companion.md)

Первый публичный выпуск WinxCoop от 23 ноября 2026 года. В оригинальной PC-версии Winx Club второй игрок может управлять своей Блум рядом с Блум ведущего. Оба игрока управляют своим персонажем и камерой, а прохождение ведёт сервер.

## Загрузка

- [Windows x64](https://github.com/AnDi-SD/SparkplugEngineResearch/releases/download/winxcoop-v0.1.0/WinxCoop-0.1.0-Windows-x64.zip)
- [Windows 7 x86](https://github.com/AnDi-SD/SparkplugEngineResearch/releases/download/winxcoop-v0.1.0/WinxCoop-0.1.0-Win7-x86.zip)

Распакуйте подходящий архив целиком и откройте `WinxCoopLauncher.exe`. Для запуска нужна полная установленная Winx Club. В общих настройках лаунчера выберите её `WinxClub.exe`. Инструкции внутри каждого архива доступны на русском и английском.

## Возможности

- Сервер создаёт лобби и запускает игру через обычное меню. Клиент находит лобби в локальной сети или подключается по введённому адресу и порту.
- Когда сервер загружает локацию, клиент входит в неё автоматически. При следующем переходе клиент следует за сервером в уже открытой игре. Между играми передаются положение, направление и основные анимации Блум.
- Общие настройки находятся сверху, серверные действия слева, клиентские справа. Язык выбирается в правом верхнем углу. В режиме «Язык системы» используется русский для русского интерфейса Windows и английский для остальных языков. Ручной выбор сохраняется и применяется сразу.
- У каждого комплекта есть локальные журналы. Кнопка **Папка журналов** открывает `launcher.log` и каталог `Sessions`.

## Объём выпуска

Клиентская Блум — пассивный спутник. Бой, подбор предметов и сюжетные действия выполняет ведущий. У каждой игры собственные HP, инвентарь, квесты и состояние мира. Клиент загружает стандартный вход локации. Удалённая Блум использует фиксированный костюм и основные анимации.

Игровая проверка разработчика охватывает два экземпляра на одном ПК через localhost, повторную загрузку Гардении 1 и переход в Гардению 2. Проверки обновлённого лаунчера охватывают обе архитектуры, смену языка с сохранением выбора, поиск лобби, подключение и отключение на одном ПК. Проверка совместимости на других уровнях, между отдельными компьютерами и внутри Windows 7 остаётся открытой.
