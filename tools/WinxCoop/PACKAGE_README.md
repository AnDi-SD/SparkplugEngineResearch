# WinxCoop — пассивный спутник

[English](README.en.md)

Второй игрок управляет своей Блум рядом с серверной. Сервер проходит обычную
одиночную игру, клиент следует за его загрузками локаций. Бой, предметы,
HP, задания и сохранения между играми пока не синхронизируются.

## Запуск

1. Сохраните всю папку комплекта вместе. Рядом с `WinxCoopLauncher.exe`
   должны находиться `WinxCoopGameHost.exe` и `WinxCoop.NativeAdapter.dll`.
   Используйте `Win7-x86` для Windows 7 или `Windows-x64` для Windows x64.
   GameHost и адаптер в обоих комплектах остаются 32-битными.
2. Откройте `WinxCoopLauncher.exe`. В общих настройках сверху нажмите
   **Выбрать…** и укажите `WinxClub.exe` полной установленной оригинальной игры.
   Игровые файлы в комплект не входят; отдельная подготовленная копия не нужна.
3. Перед запуском проверьте `fullScreen=false` в игровом `winx.ini`, если
   нужен оконный режим. Лаунчер настройки игры не переписывает.
4. На сервере используйте левую часть окна: **Создать лобби** →
   **Запустить игру** → обычное игровое меню и выбор новой игры или сохранения.
5. На клиенте используйте правую часть: **Найти в LAN** либо адрес
   `IPv4:порт` → **Подключиться**. Отдельно запускать клиентскую игру не нужно:
   она загрузится после готовности серверной локации.

По умолчанию порт — `27025`. Для двух игр на одном ПК откройте разные
комплекты и подключитесь к `127.0.0.1:27025`. Если обе игры используют одну
установку, их каталог сохранений общий; не сохраняйтесь одновременно в один слот.
При запуске из общей сетевой папки используйте подключённый сетевой диск.

## Окно и язык

Общие настройки и кнопка журналов находятся сверху; серверные функции —
слева, клиентские — справа. Один экземпляр программы выполняет одну сетевую
роль за раз. Недоступные в текущем состоянии действия отключены.

Переключатель языка расположен справа вверху. **Язык системы** выбирает
русский при русском языке интерфейса Windows, иначе английский.
**Русский** и **English** задают язык вручную. Выбор сохраняется локально;
смена языка не перезапускает игру и не меняет её язык.

## Выход и журналы

Игра завершается обычным игровым меню и Quit. Чтобы разорвать соединение без
закрытия игры, используйте **Закрыть лобби** на сервере или **Отключиться**
на клиенте. При закрытии лаунчера он ожидает завершения принадлежащих ему
процессов. Общего таймера закрытия игры нет.

**Папка журналов** открывает локальные `launcher.log` и `Sessions`:

- `%LOCALAPPDATA%\WinxCoop\Win7-x86` — комплект x86;
- `%LOCALAPPDATA%\WinxCoop\Windows-x64` — комплект x64.

При ошибке сохраните `launcher.log` и папку нужного запуска из `Sessions`.
Программе не требуется записывать журналы в сетевую папку комплекта.

## Ограничения

Клиент загружает стандартный вход локации; точное место появления, профиль
и мир сервера не передаются. Удалённая Блум использует фиксированный костюм
и основные анимации. Игровые проверки ограничены двумя играми через localhost,
Гарденией 1/2 и описанными сценариями. Все уровни и физическая LAN этой версией
не объявлены проверенными.
