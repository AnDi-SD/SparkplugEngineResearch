Положите сюда:

1. Один SMO — игровую модель, которой принадлежат анимации.
2. Одну PMD — целевую модель MMD.
3. Один или несколько SAN — анимации выбранной игровой модели.

Например: Icy.smo, Miku_Hatsune_Ver2.pmd, xiwa.san, xiru.san.
Переименовывать файлы не нужно. Кладите их прямо сюда, без вложенных папок.
Текстуры для конвертации не нужны.

После этого запустите run.bat в папке уровнем выше.
Готовые VMD будут в соседней папке output.

Не смешивайте в одном запуске несколько SMO или PMD.
Для другого персонажа замените комплект входных файлов.
