# Текстуры SMO: используемый контракт

Актуальный writer 2.2 использует каталог FFPS и `SmoTextureDataDecoder` общего
`SmoViewer.Core`. Он не ищет объекты по последовательностям байтов внутри пикселей.

## Встроенное PC Direct3D BGRA32

После `[class ID][SBOO]` находится поток полей `spDataBlockSerializer`.
Поддерживаемый путь записи: поле 3 (встроенный источник), поле 1 производной
секции (Direct3D), поле 0 (первый mip). В его payload последовательно лежат:

| Смещение в payload mip | Данные |
| --- | --- |
| 0 | UInt8: присутствие native данных |
| 1 | UInt32: ширина |
| 5 | UInt32: высота |
| 9 | UInt32: native format flags, для этого writer 0/BGRA32 |
| 13 | UInt8: присутствие пикселей |
| 14 | UInt32: ширина mip |
| 18 | UInt32: размер строки, width × 4 |
| 22 | UInt32: высота mip |
| 26 | BGRA bytes, width × height × 4 |

Размер заголовка каждого поля определяется его кодом размера. Поэтому абсолютные
смещения внутри объекта зависят от обёртки. Исторические `0x32E3`/`0x43E3` —
заголовок поля и младший байт длины, а не форматы текстуры. `+0x3C` у одной частой
обёртки — последний байт `mipHeight`, не отдельный marker. Имя экспортированного
PNG пока сохраняет исторический суффикс `fmtXXXX` для совместимости папок замен;
интерфейс показывает реальное представление.

При замене обновляются настоящие поля размеров и пиксели. При изменении длины
пересчитываются enclosing field headers, inline `[object ID][size]`, смещения
и размеры FAT, file/data size. Компактный заголовок расширяется при необходимости.
Нетронутые opaque fields и ID сохраняются. Неоднозначный контейнер отклоняется.

Запись ограничена одной встроенной PC BGRA32-репрезентацией с одним записанным
mip. Недостающие mip-уровни создаёт оригинальный загрузчик. Измеренные NPOT-примеры
13×7, 23×11 и 17×29 сохраняют свои базовые размеры в native-data пути; это отличается
от нормализации размеров в отдельном cross-platform upload пути.

## Чтение других представлений

Общий decoder также различает legacy cross-platform BGRA, дополнительные
Direct3D mip-уровни и структурные PS2 palette/32-bit формы. Их наличие не означает,
что TextureTool умеет их записывать или превращать PS2 swizzle в PC preview.
