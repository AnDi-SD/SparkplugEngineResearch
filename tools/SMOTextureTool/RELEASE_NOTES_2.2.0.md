# SMOTextureTool 2.2.0

Кандидат от 2026-09-08, подготовлен локально. Публикация не выполнена.

- В GUI включены замена RGBA, resize и сохранение проверенной копии SMO
  для поддерживаемых embedded PC BGRA-текстур с одним mip level.
- Writer использует структуру FFPS и обновляет размеры/offsets контейнера.
  Точные NPOT-размеры поддерживаются; прежние marker/fixed-offset эвристики
  не определяют возможность записи.
- Сохраняются просмотр и PNG export. Проверены разные варианты PNG и точные
  выходные пиксели, а также приём поддержанных записей оригинальным PC-кодом.
- Неподдерживаемые representations и несколько mip levels остаются read-only.

Версия 2.1 использовала неверную терминологию marker signatures; текущий
структурный writer её заменяет. Существующий output получает backup,
а новая копия устанавливается после проверки. Инструкция: [README](README.md).
