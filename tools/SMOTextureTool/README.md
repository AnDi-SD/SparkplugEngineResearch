# SMOTextureTool

Просмотр и извлечение встроенных текстур SMO, замена полного RGBA и сохранение проверенной копии ресурса. Рабочее дерево — **2.2.0**; [последний перенесённый релиз — 2.1.0](https://github.com/AnDi-SD/SparkplugEngineResearch/releases/tag/smotexturetool-v2.1.0).

## Работа с текстурами

1. Откройте SMO и выберите текстуру.
2. При необходимости экспортируйте одну текстуру или набор в PNG.
3. Выберите замену для слота либо папку PNG с сохранёнными экспортными именами.
4. Нажмите **Сохранить копию SMO** и повторно откройте результат.

Исходный SMO и изображения замен защищены от перезаписи. Существующая выходная копия получает backup. Запись сохраняет точные размеры, включая прямоугольные и NPOT, и полный RGBA; состояния материала не изменяются. Alpha в PNG сама по себе не включает blending.

## Поддержка

Записывается встроенное PC Direct3D BGRA32-представление с одним записанным mip и без второй платформенной копии. PS2, палитры, внешние источники, смешанные представления и явно записанные mip-цепочки остаются вне этого writer. Ограничение конкретного слота видно в интерфейсе.

Обычный предел — 4096 пикселей на сторону. Расширенный — 16384 и не более 128 МиБ несжатых пикселей на изображение. Это пределы инструмента; поддержка конкретного GPU проверяется отдельно.

```powershell
dotnet run --project tools/SMOTextureTool/SMOTextureTool/SMOTextureTool.csproj
```
