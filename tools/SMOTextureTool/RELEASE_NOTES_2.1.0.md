# SMOTextureTool 2.1.0

Версия 2.1.0 исправляет точную причину повреждения обычных текстурных блоков
`0x32E3`/`0x43E3`. Байт `+0x3C` теперь проверяется и сохраняется как обязательный
нулевой marker `spDataBlockSerializer`, а BGRA payload читается и записывается с
`+0x3D`.

Также исправлено поле `+0x38`: для прямоугольных текстур оно хранит
`height << 8`, а не повтор ширины. Набор форматных тестов теперь проверяет
первый и последний BGRA-пиксель, отказ на повреждённом marker-е, побайтный
round-trip, изменение размера до `128x64` и корректность всех связанных полей
заголовка.

Исправленный fixed-size full-BGRA/Alpha контрольный файл прошёл нативную загрузку
игрой. Resize/repack этим тестом не проверялся, поэтому writer и элементы замены
в GUI по-прежнему отключены; релиз предназначен для просмотра и извлечения
текстур.

Windows x64 пакет использует общую чистую схему релизов: стабильный корневой
загрузчик, framework-dependent single-file приложение в `app/`, документацию в
`docs/` и автоматическую установку подписанного Microsoft .NET 8 Desktop Runtime
при его отсутствии.
