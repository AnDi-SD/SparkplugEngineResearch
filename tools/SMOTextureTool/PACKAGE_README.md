# SMOTextureTool

Просматривает текстуры PC SMO, экспортирует PNG и сохраняет поддерживаемые
замены текстур в новый SMO.

1. Запустите корневой `SMOTextureTool.exe` и откройте SMO.
2. Выберите текстуру. Сохраните PNG или загрузите изображение для замены.
3. При необходимости задайте новый размер и сохраните отдельную копию SMO.

Замена и resize доступны для поддерживаемых embedded PC BGRA-текстур с одним
mip level. Для остальных форм программа сохраняет режим чтения и диагностику.

Распаковывайте архив целиком. Launcher использует .NET 8 Desktop Runtime x64
и предлагает его установку при отсутствии.
