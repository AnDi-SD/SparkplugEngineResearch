# SmoLVLcreator 0.1.1

[Русский](RELEASE_NOTES_0.1.1.md) · [Changelog](CHANGELOG.en.md)

Test candidate dated 2026-09-08. At that point the build was local.

The working tree included shared fixes for PC textures and imported resources,
together with updated shared decoder and renderer dependencies. The version
number distinguished this build from the published 0.1.0 release. Placement
workflows, project save and build, undo/redo and collisions retained their
previously verified scope.

Support remained bounded to the verified game objects, scenarios and effects.
Check the result of a level build before using it. The editor provides raw
inspection of unknown fields.
