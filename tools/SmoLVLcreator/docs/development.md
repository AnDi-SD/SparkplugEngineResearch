# Устройство SmoLVLcreator

[English](development.en.md)

Интерфейс обращается к редакторскому документу. Документ использует общие средства чтения SMO, построения сцены, импорта, экспорта и редактирования.

| Каталог | Ответственность |
| --- | --- |
| [SmoLVLcreator.Core](../SmoLVLcreator.Core/) | Объекты, размещения, команды, отмена и повтор |
| [SmoLVLcreator.Gui](../SmoLVLcreator.Gui/) | Окно и взаимодействие |
| [SmoLVLcreator.Viewport.Wpf](../SmoLVLcreator.Viewport.Wpf/) | Слои отображения и гизмо в 3D-вьюпорте |
| [SmoLVLcreator.ProjectTool](../SmoLVLcreator.ProjectTool/) | Команды формата проекта |

Архитектура [общего ядра](../../shared-core.md) описывает общие исходники, нативный ABI и границы управляемого слоя. Чтение форматов и реализация игрового поведения принадлежат общим компонентам.

## Проект и фоновые операции

`SmoProjectArchive` читает и записывает `.smolvlproj`. `SmoProjectSerializer` собирает игровой SMO по каталогу объектов, исходным данным и журналу операций. Транзакции отмены и повтора принадлежат `SmoProjectSession`. Структура архива и команды для работы с ним описаны в [документации ProjectTool](../SmoLVLcreator.ProjectTool/README.md).

При добавлении внешней модели фоновый процесс читает снимок подготовленной модели с выбранными материалами и текстурами. Он возвращает план добавления ветвей объектов и связанные данные для установки в проект. Изолированные операции сохранения SMO и сборки проекта записывают и проверяют результат. Проверка в игре запускает оригинальную игру отдельно и отслеживает прохождение этапов загрузки.

## Языковые ресурсы

| Каталоги UTF-8 | Назначение |
| --- | --- |
| [`Strings.ru.json`](../SmoLVLcreator.Core/Localization/Strings.ru.json) и [`Strings.en.json`](../SmoLVLcreator.Core/Localization/Strings.en.json) | Интерфейс редактора, ProjectTool и сообщения фоновых процессов |
| [`Strings.ru.json`](../../../release/bootstrapper/Strings.ru.json) и [`Strings.en.json`](../../../release/bootstrapper/Strings.en.json) в `release/bootstrapper` | Сообщения программы запуска, в том числе при проверке наличия .NET Desktop Runtime |

[`LevelText`](../SmoLVLcreator.Core/Localization/LevelText.cs) читает ресурсы из `SmoLVLcreator.Core`. Английский каталог задаёт набор ключей для WPF и даёт запасной текст при пропуске перевода. В XAML используйте `DynamicResource Loc.<ключ>`, в C# — `LevelText.Get(ключ, параметры)`. Для подписи в истории команд сохраняйте ключ и аргументы через `LevelText.Label`, а при выводе используйте `LevelText.Display`. Тогда подписи уже выполненных команд отображаются на выбранном языке.

Редактор сохраняет `Auto`, `Russian` или `English` в поле `Language` файла `%LOCALAPPDATA%\SparkplugEngineResearch\SmoLVLcreator\settings.json`. В режиме `Auto` русский язык интерфейса Windows выбирает русский каталог, остальные языки выбирают английский. Программа запуска SmoLVLcreator читает то же предпочтение. ProjectTool определяет язык справки и локализованных сообщений по системному языку интерфейса при запуске. Изолированные процессы редактора получают активный язык через `SMOLVLCREATOR_WORKER_LANGUAGE`. Числовые аргументы ProjectTool читаются в инвариантной культуре. При форматировании параметров локализованных сообщений используется текущая числовая локаль.

## Обновление перевода

1. Обновите оба каталога одновременно. Сохраните ключи и индексы параметров, например `{0}` и `{1:N0}`. При изменении порядка слов можно переставить параметры в строке. Команды CLI, пути, идентификаторы и расширения оставляйте в исходном написании.
2. Чтобы добавить язык, создайте полный `Strings.<код>.json` в UTF-8 без BOM и зарегистрируйте его как встроенный ресурс в [проекте Core](../SmoLVLcreator.Core/SmoLVLcreator.Core.csproj) по схеме `SmoLVLcreator.Strings.<код>.json`. В [`LevelText`](../SmoLVLcreator.Core/Localization/LevelText.cs) зарегистрируйте стабильный идентификатор предпочтения, выбор каталога и правило для системного языка. Добавьте пункт с этим идентификатором в `LanguageSelector` окна редактора.
3. Для нового языка программы запуска подготовьте полный каталог ключей в `release/bootstrapper`, зарегистрируйте его в [сборке пакета](../../../release/Build-Releases.ps1) и добавьте выбор языка SmoLVLcreator в [`RuntimeBootstrap.cs`](../../../release/bootstrapper/RuntimeBootstrap.cs).
4. Проверьте совпадение наборов ключей и параметров, запуск с системным языком, явное переключение, подписи старых команд Undo/Redo, сообщения фоновых процессов и ширину длинных подписей. Обновляйте русскую и английскую документацию вместе.
