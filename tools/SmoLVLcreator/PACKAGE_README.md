# SmoLVLcreator

Редактор поддерживаемых сцен уровней PC SMO.

1. Запустите корневой `SmoLVLcreator.exe` и откройте сцену или проект.
2. Выберите объект и измените размещение либо используйте доступные операции
   импорта и коллизий. Undo/Redo сохраняет историю правок проекта.
3. Сохраните проект; для SMO выполните build в отдельный файл и проверьте результат.

Проект и построенный SMO — разные файлы. Сохраняйте исходную сцену и материалы
проекта вместе с рабочими копиями. Поддерживаются подтверждённые варианты
объектов и полей; неизвестные данные сохраняются в пределах доступных операций.

Сохраняйте структуру архива, включая `native/`. Launcher использует .NET 8
Desktop Runtime x64 и предлагает установку при его отсутствии.
Изменения и границы поддержки: [0.1.1](RELEASE_NOTES_0.1.1.md).
