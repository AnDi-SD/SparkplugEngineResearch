# SmoLVLcreator

[English](README.en.md)

Редактор поддерживаемых сцен PC SMO.

## Запуск

1. Распакуйте весь архив в одну папку. Мост чтения SMO `SparkplugViewerNative.dll` находится в `app/`, а файлы для FBX — в `native/`.
2. Запустите корневой `SmoLVLcreator.exe`. Если в Windows отсутствует Microsoft .NET 8 Desktop Runtime (x64), программа запуска предложит установить его.
3. В меню **Файл** выберите **Открыть уровень или проект…** и укажите `.smo` или `.smolvlproj`. Язык меняется справа вверху. **Язык системы** выбирает русский при русской локали интерфейса Windows и английский во всех остальных случаях. Ручной выбор сохраняется.

## Работа со сценой

- Выделите объект левой кнопкой мыши. `Ctrl+ЛКМ` меняет состав выделения, `Esc` снимает его, `F` кадрирует активный экземпляр. В свободной перспективе `WASD` и `Q/E` перемещают камеру, а ПКМ с колесом регулирует скорость полёта.
- Чтобы добавить модель без скелета, нажмите **+ Модель…** в каталоге. Чтобы заменить существующую модель, выберите её карточку и команду замены. Доступны OBJ/MTL, GLB и FBX.
- В диалоге подготовки назначайте изображения по строкам материалов или подбирайте их по имени. Ручное назначение имеет приоритет. Для OBJ можно выбрать MTL. После подготовки модели проверьте предупреждения и, при замене, положение и масштаб в окне подгонки.
- Выберите **Сохранить проект**, чтобы записать правки в `.smolvlproj`. Во время работы используйте `Ctrl+Z` и `Ctrl+Y` для отмены и повтора. Команда **Собрать SMO…** создаёт отдельный файл для игры. Храните исходный SMO и открывайте собранный файл для проверки.

Редактирование доступно для поддерживаемых объектов, полей и схем коллизий. Уровневые сценарии SPT/SPL редактируются другими средствами.

## Ограничения

объектах уровня. Поддержка анимированных текстур находится в работе.
