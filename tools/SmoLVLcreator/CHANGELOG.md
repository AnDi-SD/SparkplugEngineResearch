# Changelog

## 0.1.0 — 2026-08-27

- Создан модульный редактор SMO-уровней на общих parser, scene, renderer,
  importer и exporter ядрах проекта.
- Добавлены GPU-просмотр уровня, свободная/фокусная камера, picking,
  мультивыделение и WORLD/LOCAL gizmo для Move/Rotate/Scale.
- Реализованы инспектор, дерево уровня и каталоги моделей, размещений, текстур и
  неизвестных объектов с ленивыми GPU-превью.
- Составные модели восстанавливаются по структуре и подтверждённым ссылкам SMO,
  а не по именам или близости индексов.
- Реализованы добавление, клонирование, перемещение и удаление размещений без
  дублирования общих mesh/material/texture-ресурсов.
- Добавлены просмотр, перемещение, создание, регенерация и удаление коллизий с
  независимым либо связанным редактированием визуального объекта.
- Реализованы экспорт выделения в GLB/FBX/OBJ, импорт rigid-моделей, поиск
  внешних MTL/текстур и полная замена составных моделей вместе с материалами,
  текстурами и alpha.
- Основным форматом редактирования стал `.smolvlproj` версии 1. Исходный
  `data.bin` остаётся неизменным, а правки и новые объектные леса хранятся как
  журнал операций и отдельные immutable assets.
- Убран промежуточный полный SMO из проектного импорта: изолированный worker
  возвращает сразу планы объектных лесов и asset blobs.
- Замена RGB/RGBA-текстуры переведена в проектный журнал и поддерживает
  Undo/Redo, повторное открытие проекта и финальную сборку.
- Добавлена единая schema-backed подсистема правок полей. Редактор использует
  только подтверждённые transform/collision/resource операции; неизвестные
  поля сохраняются побайтно и доступны общему RAW API.
- Сборка SMO выполняется потоково и только по запросу: пересчитываются размеры,
  inline-границы и каталог, результат повторно строго разбирается до установки.
- История ограничена 256 транзакциями; неиспользуемые asset blobs истории
  удаляются при вытеснении и `CompactHistory`, чтобы длительная сессия не росла
  без ограничения.
- Изолированные import workers получили отдельный memory ceiling и режим
  экономии GC; GUI показывает стадии и не запускает сохранение только по
  оценке доступной памяти.
- Исправлен выбор сохранённого пользователем `WinxClub.exe` в окне проверки и
  передача настроенного contextual start level.
- Убраны старые `Experimental`-названия из основной архитектуры и CLI; формат,
  Core и вспомогательный инструмент теперь называются `SmoProject` и
  `SmoLVLcreator.ProjectTool`.
- Автоматический Core-набор проходит 1 676 проверок, включая 1 500 случайных
  изменений журнала, archive/reopen/build, RGBA-текстуры и ограничение истории.
- Реальный gate `Alfea02_old.smo` + двухчастная `shrek.glb` проходит 25
  структурных проверок проектного импорта, замены, Undo/Redo и финальной сборки.
- В проектный путь перенесены copy/paste/duplicate, трансформации и удаление
  исходных/добавленных размещений, редактирование/создание/удаление коллизий,
  ручные связи visual-collision и передача владения внешним ресурсом при
  удалении его первого размещения.
- Финальная сборка `.smolvlproj -> .smo` снова выполняется в отдельном процессе
  под Windows Job Object с верхним пределом 1536 МиБ. Вернулись прогресс,
  отмена, соседний `.SmoLVLcreator.log`, строгая проверка временного файла,
  проверка SHA-256 после установки и timestamped `.bak` при перезаписи.
- Preview после структурной правки теперь строится прямо из проектных блоков в
  памяти и не создаёт промежуточный SMO на диске.
- Прямой legacy full-repack импорт оставлен только внутренним compatibility
  oracle; GUI и стресс-конвейер используют один production batched worker.
- Полный случайный project stress прошёл 1 000 операций, а 80-МиБ уровень —
  под жёстким лимитом 1024 МиБ. Повторные build и re-import дали идентичные
  SHA-256. Отдельно пройдены OBJ+MTL и OBJ без MTL с поиском текстур рядом.
- Ссылочные размещения теперь всегда сериализуются после определения mesh-
  ресурса и внутри того же подтверждённого owner/partition. Для встроенного
  меша лёгкая копия строится из собственной ветки модели: inline-геометрия
  заменяется ссылкой, а размеры оболочки пересчитываются снизу вверх.
- Запечённая геометрия `spPartitionRenderable` без static placement больше не
  получает произвольную оболочку предмета. Такие ресурсы не считаются
  размещаемыми, пока для них не будет реализовано копирование и rebasing вершин.
- Нативный stress-кандидат с 250 смешанными правками принят загрузчиком игры и
  пережил полный 70-секундный contextual-интервал без EOF и `0x004BC4B9`.
- Исправлена передача владения физическим mesh-ресурсом: если исходное
  размещение удалено, первое уцелевшее ссылочное размещение становится
  владельцем определения, а остальные остаются ссылками. Дублирующиеся поля
  ссылок различаются по точному типу и номеру вхождения.
- Ручные связи визуальных объектов с коллизиями перенесены из временного
  состояния окна в `.smolvlproj`: они переживают повторное открытие, участвуют
  в Undo/Redo и не добавляют неподтверждённых полей в игровой SMO.
- Финальный stress с seed `82744` прошёл 1 000 операций, два промежуточных
  archive/build/reopen checkpoint и детерминированные build/re-import. Итоговый
  SHA-256 — `5F0966193AB44DC39B890EDAD2C8EA2CC73E60E586857EAF5725C6CA9853EB6D`,
  пик worker working set — 363,9 МиБ. Этот же SMO принят настоящим загрузчиком
  игры и пережил контрольное окно без падения.
