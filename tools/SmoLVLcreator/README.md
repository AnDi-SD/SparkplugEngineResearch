# SmoLVLcreator

Редактор SMO-сцен Sparkplug: объекты уровня, размещения, поддерживаемые свойства, импорт и экспорт. Текущая проверочная версия — **0.1.1**, опубликованная — **0.1.0**.

## Начало работы

Откройте SMO: появятся каталог ресурсов, список объектов, инспектор и сцена. Левый щелчок выбирает объект, `Ctrl` добавляет его к выбору, `Esc` снимает выбор, `F` кадрирует размещение. Правая кнопка вращает камеру; `Shift` с правой кнопкой перемещает её. Без выбранного размещения доступны свободный обзор, `WASD` и `Q/E`.

Редактор хранит изменяемые transforms и ветвящуюся историю Undo/Redo поверх прочитанного workspace. Он использует общие операции Importer, Exporter и Editing.

```powershell
dotnet run --project tools/SmoLVLcreator/SmoLVLcreator.Gui/SmoLVLcreator.Gui.csproj -- path/to/level.smo
```

Нужны полный репозиторий и [общие зависимости сборки](../../CONTRIBUTING.md).

## Ограничения

Редактирование доступно для поддерживаемых схем transforms и collision. Повторные размещения одного Model показываются в каталоге, но текущая модель команд не адресует каждый reference slot независимо: создание редактируемого документа сообщает `REPEATED_RENDERABLE_AUTHORING`.

Редактор отдельного SMO не заменяет полностью восстановленную систему игровых уровней SPT/SPL. Ядро продолжает развиваться.
