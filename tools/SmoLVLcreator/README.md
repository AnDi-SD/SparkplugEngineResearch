# SmoLVLcreator

[English](README.en.md)

Редактор PC SMO-сцен Sparkplug. В нём можно изменять размещение объектов, добавлять и заменять модели, работать с коллизиями и экспортировать сцену или выделение. Изменения в **0.2.0** описаны в [заметках к выпуску](RELEASE_NOTES_0.2.0.md).

## Начало работы

1. Выберите **Файл → Открыть уровень или проект…** и укажите файл `.smo` или `.smolvlproj`. Каталог ресурсов, структура уровня и инспектор заполнятся данными сцены.
2. Выделяйте объекты левой кнопкой мыши. `Ctrl+ЛКМ` меняет состав выделения, `Esc` снимает его, `F` кадрирует активный экземпляр. ПКМ вращает камеру, `Shift+ПКМ` перемещает её параллельно плоскости экрана. В свободной перспективе `WASD` и `Q/E` перемещают камеру, а ПКМ с колесом регулирует скорость полёта.
3. Выберите **+ Модель…** в каталоге, чтобы добавить модель без скелета из OBJ/MTL, GLB или FBX. Для замены выберите существующую модель и выполните команду замены. В диалоге подготовки доступны ручное назначение изображений, подбор по имени и выбор другого MTL для OBJ.
4. Сохраните проект через **Сохранить проект**. Команда **Собрать SMO…** создаёт игровой файл отдельно от проекта. История отмены и повтора позволяет сверить правки в текущем сеансе.

Переключатель языка находится справа вверху. **Язык системы** выбирает русский для русской локали интерфейса Windows и английский для любой другой. Язык можно задать вручную, выбор сохраняется и применяется к открытому окну.

## Запуск из исходников

```powershell
dotnet run --project tools/SmoLVLcreator/SmoLVLcreator.Gui/SmoLVLcreator.Gui.csproj -- path/to/level.smo
```

Нужны полный репозиторий и [общие зависимости сборки](../../CONTRIBUTING.md). Редактор использует общие компоненты SmoImporter, SmoExporter и SmoViewer.Editing. Готовый архив запускается по [инструкции из комплекта](PACKAGE_README.md).

## Ограничения

Редактор обрабатывает поддерживаемые схемы трансформаций и коллизий внутри SMO. Один ресурс модели может использоваться несколькими экземплярами. Возможность редактирования конкретного экземпляра зависит от того, как он связан с ресурсом в сцене. Игровые сценарии SPT/SPL требуют отдельной работы.

При экспорте выделения счётчик может включать предупреждения со всего уровня. Системы частиц пропускаются при экспорте геометрии. Поддержка анимированных текстур находится в работе. См. [известные ограничения](docs/guide.md#known-limitations).
