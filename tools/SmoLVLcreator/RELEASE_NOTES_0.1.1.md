# SmoLVLcreator 0.1.1

Тестовый кандидат от 2026-09-08, подготовлен локально. Публикация не выполнена.

Рабочее дерево включает общие исправления PC-текстур и импортируемых ресурсов,
а также обновлённые shared decoder/renderer dependencies. Номер версии отличает
эту сборку от опубликованной 0.1.0. Сценарии размещений, project save/build,
Undo/Redo и коллизий сохраняют свои ранее проверенные границы поддержки.

Этот выпуск не означает поддержки всех игровых объектов, сценариев или
эффектов. Перед использованием изменённой сцены проверяйте результат build;
неизвестные payloads не следует редактировать как угаданные поля.
Инструкция: [README](README.md).
