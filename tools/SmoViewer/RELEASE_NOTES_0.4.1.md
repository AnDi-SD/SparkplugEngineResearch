# SmoViewer 0.4.1

Релиз добавляет Winx Hair Patcher в общий комплект и делает его доступным прямо
из вкладки **Игра**.

## Главное

- вкладка **Игра** разделена на секции **1. Патчи** и
  **2. Проверка модели в игре**; настройки запуска изначально свёрнуты, а ход
  нативной загрузки входит в общую прокручиваемую страницу;
- кнопка **Отключить волосы Блум** расположена в секции **Патчи** и запускает
  отдельный патчер без необходимости искать его файл вручную;
- если Viewer уже нашёл `WinxClub.exe`, его полный путь передаётся отдельным
  аргументом и автоматически подставляется в патчере; пользователь может выбрать
  другой EXE;
- suite содержит `tools/WinxHairPatcher/WinxHairPatcher.Gui.exe` версии 0.2.0;
- Viewer находит патчер как в опубликованном комплекте, так и в локальной
  Release/Debug-сборке разработчика;
- отсутствие файла или ошибка запуска показываются пользователю и не завершают
  Viewer;
- окно **О программе** показывает версию включённого Winx Hair Patcher.

## Материалы и прозрачность

- `FinalBlendOp` больше не интерпретируется как общий набор флагов: операции
  `0x4`, `0x5` и `0x6` различаются;
- Viewer читает полный companion-массив `MaterialRenderStates` и состояние
  владеющего `spSkin`. Для обычной skinned alpha-поверхности подтверждён точный
  tuple `[0,0,1,2,1,1,3,0,4,0,6]` вместе с `AlphaSortEnable = 1`; rigid- и
  skinned-effect consumers имеют отдельные подтверждённые tuple. Проверки одного
  state 8 недостаточно;
- effect-операции получают отдельное явно обозначенное WPF-приближение. Оно не
  выдаётся за нативный игровой рендер;
- pristine Minautor подтверждает отдельный skinned `FinalBlendOp=0x2` профиль
  `[0,0,1,0,1,1,3,0,4,0,6]` + `A1/P1` + black diffuse + UV partial alpha.
  Viewer показывает его как source-alpha surface без emissive; гибрид
  `RS[5]=0` + `A1` помечается как неподтверждённый, но не скрывается как opaque;
- большие `RS[5]=0` alpha surfaces и смешение white retained body с black
  generated `imp_o_x` face runs получают отдельные баннеры. Они предупреждают
  о рисках level ordering и native fixed-function lighting, не заявляя точное
  воспроизведение в WPF;
- в «Слои просмотра» есть turntable **«Нативный свет: вращать модель»**. Он
  вращает модель относительно фиксированного света Viewer только для визуальной
  диагностики angle-dependent normals/diffuse;
- успешный native loader test подтверждает создание и выживание ресурса, но не
  правильность blend/shading итогового кадра. Для импортированной модели всё ещё
  обязательна визуальная проверка в игре.

## Комплект

Пользовательский пакет `SmoViewer-0.4.1-suite-win-x64` содержит:

- `SmoViewer.exe` — загрузчик Microsoft .NET 8 Desktop Runtime x64;
- `app/SmoViewer.exe` — SmoViewer 0.4.1;
- `tools/SmoExporter/SmoExporter.Gui.exe` — SmoExporter 0.3.0;
- `tools/SmoImporter/SmoImporter.Gui.exe` — SmoImporter 0.4.0;
- `tools/WinxHairPatcher/WinxHairPatcher.Gui.exe` — Winx Hair Patcher 0.2.0;
- документацию каждого приложения в соответствующей папке `docs`.

## Безопасность

Кнопка Viewer только открывает отдельный патчер. Изменение `WinxClub.exe`
происходит после проверки выбранного либо автоматически подставленного файла и
подтверждения уже в Winx Hair Patcher; перед атомарной заменой он создаёт
резервную копию рядом с EXE.
