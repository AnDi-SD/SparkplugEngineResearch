# Sparkplug SMO Tools — Windows x64

## Запуск

Запустите `SmoViewer.exe`. Если Microsoft .NET 8 Desktop Runtime (x64) ещё не
установлен, загрузчик предложит скачать официальный подписанный установщик
Microsoft и выполнит тихую установку. Windows может показать подтверждение UAC.

После открытия SMO используйте верхние кнопки:

- **Экспорт…** — запускает `tools/SmoExporter/SmoExporter.Gui.exe` 0.2.1 и передаёт модель вместе со списком SAN;
- **Импорт…** — запускает `tools/SmoImporter/SmoImporter.Gui.exe` 0.3.0 с текущей моделью как шаблоном.
- **Игра** — использует встроенный `SmoNativeValidator.Core`: находит `WinxClub.exe` и его внутренние loader-вызовы независимо от патчей,
  временно перенаправляет запрос выбранного SMO внутри дочернего процесса и записывает native checkpoints,
  exception/timeout и полный JSONL-журнал. Исходники Core, CLI и тестов находятся в репозитории,
  но отдельный Validator EXE или самостоятельный релиз в комплект не входят.

Инструменты можно также запускать напрямую из их папок. Документация каждого
приложения находится в соответствующей подпапке `docs`.

## Зависимости

Viewer, GLB/OBJ exporter и Importer используют общий установленный Microsoft
.NET 8 Desktop Runtime (x64), который проверяет корневой загрузчик. Для создания
бинарного FBX требуется Blender 4.x.
При его отсутствии SmoExporter явно отключает FBX, но оставляет GLB и OBJ
доступными.

## Безопасность данных

Viewer и Exporter читают исходные ресурсы. Importer никогда не перезаписывает исходный SMO: результат сохраняется новой копией и проверяется strict parser.

Игровые файлы в комплект не входят.
