# SmoViewer 0.7.0 — ядро анимации Sparkplug

Локальный кандидат. Воспроизведение SAN переведено на восстановленные C++-классы
из SparkplugEngineResearch. Viewer вызывает их через `SparkplugViewerNative.dll`:
загрузка анимации, интерполяция каналов, обновление узлов и skin-матрицы выполняются
общим кодом Sparkplug. Повторная C#-реализация этих вычислений в окне удалена.

Сохранены выбор анимации, перемотка, слои, выбор костей и вывод через OpenGL/WPF.
Каждая перемотка начинается с сохранённых параметров узлов SMO. Ошибка загрузки
SAN останавливает воспроизведение; DLL является обязательной частью пакета.

SMO-парсер, подготовка материалов/геометрии и графический backend пока остаются
адаптерами Viewer. Полный перенос renderer, игровых эффектов и событий этой
версией не заявляется. Имена C++-классов подтверждены исследованием; их portable
реализации восстановлены из исполняемых файлов, а не получены как исходный SDK.

Требования пакета: Windows x64 и .NET 8 Desktop Runtime. Распаковывайте архив
целиком: DLL ядра размещается рядом с приложением внутри `app/`.

Для сборки исходников нужны workspace SparkplugEngineResearch и Visual Studio
с C++/CMake. Проект `SmoViewer.Sparkplug` собирает DLL автоматически; отдельная
сборка с готовой DLL допускает параметры `SparkplugNativePath` и
`SkipSparkplugNativeBuild=true`. Переработка интерфейса отложена отдельно.
