# SmoViewer

Просмотрщик ресурсов Sparkplug: объектный граф SMO, геометрия, материалы, текстуры, узлы, скелеты и поддерживаемые SAN-анимации. Рабочее дерево — **0.7.0**; [последний перенесённый релиз — 0.5.0](https://github.com/AnDi-SD/SparkplugEngineResearch/releases/tag/smoviewer-v0.5.0).

## Начало работы

1. Откройте SMO через интерфейс или передайте путь при запуске.
2. В панели **Ресурсы** выберите объект; двойной щелчок кадрирует камеру.
3. В **Слоях** включите скелет, коллизии и другие вспомогательные объекты.
4. В **Анимациях** выберите совместимую SAN-анимацию.

Кнопки **Экспорт…** и **Импорт…** открывают отдельные SmoExporter и SmoImporter. Операции изменения ресурсов описаны в инструкциях этих программ.

```powershell
dotnet run --project tools/SmoViewer/SmoViewer/SmoViewer.csproj -- path/to/model.smo
```

Запускать из корня полного репозитория. Нужны Windows x64, .NET и общая native DLL; [сборка](../../CONTRIBUTING.md).
