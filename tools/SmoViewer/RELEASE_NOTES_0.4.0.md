# SmoViewer 0.4.0

Релиз добавляет проверку SMO непосредственно кодом Winx Club и уточняет
назначение материалов и текстур.

## Главное

- новая вкладка **Игра** выполняет быстрый нативный smoke-test либо контекстную
  проверку выбранной модели без изменения файлов установленной игры;
- `WinxClub.exe` распознаётся по внутреннему коду и masked-сигнатурам, а не по
  SHA-256, поэтому известные и пользовательские патчи сами по себе не блокируют тест;
- каждый запуск использует изолированную временную папку и оконный
  `fullScreen=false`; результат показан компактной цветной карточкой, подробный
  trace сохраняется в JSONL;
- почти чёрный diffuse-placeholder больше не скрывает текстуру персонажа;
  восстановлен atlas mesh `[86]` у `Troll.smo`;
- точная reference-only связь материала с текстурой сохраняет общий atlas
  `stella_x` после безопасной перестановки visual branches;
- поля ввода вкладки «Игра» больше не теряют `_`, `+`, `-` и другие символы из-за
  глобальных camera shortcuts;
- в благодарности добавлен `kotwys`, автор
  [STX GIMP plugin](https://github.com/kotwys/stx-gimp-plugin).

## Комплект

Пользовательский архив `SmoViewer-0.4.0-suite-win-x64.zip` использует новую
стандартную структуру:

- `SmoViewer.exe` — загрузчик, проверяющий Microsoft .NET 8 Desktop Runtime x64;
- `app/SmoViewer.exe` — framework-dependent single-file SmoViewer 0.4.0;
- `tools/SmoExporter/SmoExporter.Gui.exe` — SmoExporter 0.2.1;
- `tools/SmoImporter/SmoImporter.Gui.exe` — SmoImporter 0.3.0;
- документация каждого приложения находится в его каталоге `docs`.

`SmoNativeValidator.Core` встроен в SmoViewer. Его Core, CLI и тесты остаются в
исходниках, но отдельный Validator EXE, архив или GitHub Release не создаётся.
Игровые файлы и установщик .NET в архив не входят.

## Границы проверки

Успешный быстрый тест подтверждает нативное чтение FFPS, создание ресурса и окно
стабильности. Он не доказывает работу модели с конкретными gameplay-скриптами и
анимациями; для этого предназначен контекстный маршрут и ручная проверка в игре.

Пакет прошёл ручную проверку запуска Viewer, вкладки «Игра» и переходов в
Importer/Exporter из общего комплекта. Перед заменой игровых ресурсов всё равно
сохраняйте оригинальные файлы и проверяйте визуальный результат в игре.
