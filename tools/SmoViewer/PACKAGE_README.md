# SmoViewer

Открывает модели и уровни PC SMO, показывает материалы, скелет и SAN-анимацию.

1. Распакуйте весь архив и запустите корневой `SmoViewer.exe`.
2. Откройте SMO. Для анимации добавьте подходящий SAN с теми же именами костей.
3. Выберите нужные объекты, слои и клип. Диагностика сообщает о неподдерживаемых
   или неоднозначных данных.

Комплект включает Exporter, Importer и Hair Patcher в `tools/`; каждый имеет
собственную инструкцию. Общий FBX runtime находится в `native/`. Сохраняйте
структуру распакованного каталога.

Требуется Windows x64 и .NET 8 Desktop Runtime. Если runtime отсутствует,
корневой launcher предложит установить его после подтверждения.

Поддерживаются подтверждённые варианты PC SMO/SAN. Не все игровые эффекты
материалов и события воспроизводятся в просмотрщике.
