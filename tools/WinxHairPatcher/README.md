# Winx Hair Patcher 0.2.0

GUI-патчер PC-версий `WinxClub.exe`, содержащих подтверждённые hair-блоки.

Версия 0.2.0 является новой функциональной линией: версии 0.1.x управляли только
игровой моделью и не эквивалентны 0.2.0. Уже пропатченный ими EXE при этом можно
безопасно открыть в 0.2.0 и дополнить menu-блоком без ручного восстановления.

Он заменяет три gameplay-проверки специальных fashion ID и отдельную проверку
preview-модели в меню костюмов на согласованные битовые маски:

- пропуск поиска `hair_top_*` / `hair_bottom_*`;
- пропуск вызова загрузки и attachment `bloom_hair.smo`;
- пропуск runtime hair update.
- пропуск attachment `Hair_Master` к `Head` в меню выбора костюма.

Одна галочка управляет обоими представлениями Bloom: игровым персонажем и
отдельной preview-моделью меню. Патчи 0.1.x, в которых были изменены только три
gameplay-блока, распознаются и при следующем применении безопасно дополняются
четвёртым menu-блоком.

Патчер выпускается отдельно и входит в полный комплект SmoViewer. Во Viewer он
открывается кнопкой **Отключить волосы Блум** в секции **Патчи** вкладки **Игра**.

Разделение масок существенно: Bloom X (ID 1) штатно загружает и прикрепляет
`bloom_hair.smo`, но пропускает обычные attachment/runtime-вычисления. Winter
(ID 5) полностью пропускает внешние волосы. Jeans использует ID 0.

Перед изменением EXE создаётся резервная копия с временной меткой. Неизвестные версии и посторонние патчи отклоняются по сигнатурам.

```powershell
dotnet run --project tools/WinxHairPatcher/WinxHairPatcher.Gui
```

Путь к игре можно передать первым аргументом; он будет проверен и подставлен в
окно, после чего при необходимости его всё равно можно заменить кнопкой выбора:

```powershell
dotnet run --project tools/WinxHairPatcher/WinxHairPatcher.Gui -- "X:\Games\Winx Club\WinxClub.exe"
```

## Ограничения 0.2.0

- MD5 и фиксированные file offsets не используются. Каждый блок должен иметь
  ровно одно совпадение исходной или совместимой пропатченной сигнатуры.
- EXE с отсутствующими, частично изменёнными или неоднозначными hair-блоками
  намеренно отклоняются.
- Маски gameplay и меню костюмов должны совпадать; рассогласованный патч
  отклоняется до записи.
- Патчер ещё требует практической проверки каждой комбинации в игре.
- Перед каждой записью рядом с EXE создаётся резервная копия.
