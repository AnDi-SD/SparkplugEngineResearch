# Winx Hair Patcher 0.1.0

GUI-патчер подтверждённой PC-сборки `WinxClub.exe` (MD5 `3bbb8d47516ca7f7d7dcb8f5067380f5`).

Он заменяет три проверки специальных fashion ID на две согласованные битовые маски:

- пропуск поиска `hair_top_*` / `hair_bottom_*`;
- пропуск вызова загрузки и attachment `bloom_hair.smo`;
- пропуск runtime hair update.

Разделение масок существенно: Bloom X (ID 1) штатно загружает и прикрепляет
`bloom_hair.smo`, но пропускает обычные attachment/runtime-вычисления. Winter
(ID 5) полностью пропускает внешние волосы. Jeans использует ID 0.

Перед изменением EXE создаётся резервная копия с временной меткой. Неизвестные версии и посторонние патчи отклоняются по сигнатурам.

```powershell
dotnet run --project tools/WinxHairPatcher/WinxHairPatcher.Gui
```

## Ограничения 0.1.0

- Поддерживается только подтверждённый PC EXE с MD5
  `3bbb8d47516ca7f7d7dcb8f5067380f5`.
- Неизвестные и сторонне модифицированные EXE намеренно отклоняются.
- Патчер ещё требует практической проверки каждой комбинации в игре.
- Перед каждой записью рядом с EXE создаётся резервная копия.
