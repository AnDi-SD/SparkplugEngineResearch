# Changelog

## 0.2.0 — 2026-08-22

- Найден отдельный путь внешних волос preview-модели в меню выбора костюма.
- Добавлен четвёртый сигнатурный блок: выбранная маска теперь пропускает
  attachment `Hair_Master` к `Head` и в меню костюмов.
- Сохранена миграция с патчей 0.1.x, изменявших только три gameplay-блока.
- Проверка EXE отклоняет рассогласованные gameplay/menu-маски и частичные патчи.
- Интерфейс явно сообщает, что одна галочка управляет волосами в обоих контекстах.
- Regression harness расширен проверками menu-site, миграции, повторного патча,
  сдвинутых сигнатур, повреждений и записи только в четыре разрешённых диапазона.
- Патчер включён в полный комплект SmoViewer и запускается кнопкой в верхней
  части вкладки «Игра».
- Необязательный первый аргумент принимает путь к `WinxClub.exe`, автоматически
  загружает его в окно и не мешает выбрать другой файл вручную.

## 0.1.2 — 2026-08-13

- версия выделена для стандартизированной пользовательской упаковки: чистый корень, single-file приложение и общий загрузчик Microsoft .NET 8 Desktop Runtime;
- логика поиска и патча hair-блоков не изменялась.

## 0.1.1 — 2026-08-11

- Удалена обязательная проверка MD5 конкретной сборки.
- Три исходных или уже пропатченных hair-блока теперь ищутся по всему EXE.
- Патч применяется по найденным смещениям, а не по фиксированным file offsets.
- Нулевые и неоднозначные совпадения отклоняются как небезопасные.

## 0.1.0 — 2026-08-11

- Добавлен WPF-интерфейс для независимого управления внешними волосами 16 fashion ID Bloom.
- Учтён Jeans как ID 0 и особая семантика Bloom X как ID 1.
- Реализованы отдельные маски загрузки `bloom_hair.smo` и управляющей/runtime-логики.
- Добавлена строгая проверка оригинального MD5 и трёх машинных сигнатур.
- Поддержано повторное изменение совместимого патча.
- Перед заменой EXE автоматически создаётся резервная копия.
- Добавлены проверки чистого, пропатченного, повторно пропатченного и повреждённого EXE.
