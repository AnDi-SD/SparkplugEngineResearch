# Changelog

## 0.1.0 — 2026-08-11

- Добавлен WPF-интерфейс для независимого управления внешними волосами 16 fashion ID Bloom.
- Учтён Jeans как ID 0 и особая семантика Bloom X как ID 1.
- Реализованы отдельные маски загрузки `bloom_hair.smo` и управляющей/runtime-логики.
- Добавлена строгая проверка оригинального MD5 и трёх машинных сигнатур.
- Поддержано повторное изменение совместимого патча.
- Перед заменой EXE автоматически создаётся резервная копия.
- Добавлены проверки чистого, пропатченного, повторно пропатченного и повреждённого EXE.
