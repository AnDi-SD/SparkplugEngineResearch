# Winx Hair Patcher 0.1.0

Первый экспериментальный выпуск патчера внешних волос Bloom.

## Возможности

- Галочки для Jeans/Bloom X и остальных fashion-моделей Bloom.
- Независимое отключение загрузки и attachment `bloom_hair.smo`.
- Сохранение штатной упрощённой логики Bloom X.
- Автоматическая резервная копия выбранного EXE.
- Повторная настройка ранее применённого совместимого патча.

## Совместимость

Поддерживается только PC `WinxClub.exe` с MD5
`3bbb8d47516ca7f7d7dcb8f5067380f5`. Это намеренное ограничение первого
выпуска: неизвестная версия не должна получать патч по приблизительным
адресам. Если найдутся другие EXE, для них потребуются образец хеша и
подтверждение трёх hair-сигнатур.

Выпуск считается экспериментальным до проверки выбранных комбинаций в игре.
