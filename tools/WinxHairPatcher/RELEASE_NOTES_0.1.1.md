# Winx Hair Patcher 0.1.1

Обновление совместимости EXE.

## Изменения

- Удалена привязка к MD5 одной сборки `WinxClub.exe`.
- Удалена запись по фиксированным file offsets.
- Патчер сканирует весь файл и ищет три подтверждённых hair-блока.
- Распознаются как оригинальные блоки, так и совместимый патч 0.1.x.
- Для безопасности каждый блок должен быть найден ровно один раз.
- Частично изменённые и неоднозначные файлы отклоняются без записи.

Проверено на `local-data/dubteam/Winx Club/WinxClub.exe`, который не принимался
версией 0.1.0 из-за другой контрольной суммы. Все 12 assertions пройдены,
включая применение патча к искусственно сдвинутым сигнатурам.
