# SmoImporter

Перенос модели, текстур и материалов в целевой PC SMO. Рабочее дерево — **0.6.1**, опубликованная линия — **0.6.0**. Исходный SMO и донор сохраняются; результат записывается отдельной проверенной копией.

## Последовательность

1. Откройте целевой SMO и модель-донора.
2. Выберите подходящий режим: подготовленная модель, адаптация существующего скелета или создание весов для человеческого персонажа. Для нативного SMO используется прямой перенос визуального графа.
3. Проверьте соответствие костей, геометрию, материалы и текстуры в preview.
4. Сохраните результат. После строгого чтения временный файл устанавливается по выбранному пути; прежний output получает `.bak`.

Неизвестная weighted-кость и неподдерживаемое преобразование не заменяются догадкой. Создание весов ограничено человеческими персонажами. Донор с несколькими material passes/layers не представим текущим `ImportedScene` и отклоняется с `MATERIAL_IMPORT_SHAPE`; прямой SMO-перенос использует другой путь.

```powershell
dotnet run --project tools/SmoImporter/SmoImporter.Gui/SmoImporter.Gui.csproj
```

Запуск из корня полного репозитория; [зависимости сборки](../../CONTRIBUTING.md).
