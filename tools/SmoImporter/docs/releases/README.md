# SmoImporter

Заменяет модель в существующем PC SMO данными SMO, OBJ, GLB или FBX.

1. Запустите корневой `SmoImporter.Gui.exe` и откройте целевой SMO.
2. Откройте донора и выберите подготовленную модель, адаптацию скелета,
   создание весов либо статический импорт без костей.
3. Настройте геометрию и позу; в режиме создания весов проверьте области
   тела и итоговый preview.
4. Сохраните новый SMO и проверьте его в Viewer с подходящим SAN.

Для неподдерживаемого шаблона или неизвестного соответствия костей программа
покажет причину отказа. Автоматическая подгонка человеческой модели требует
подходящей ориентации и различимых частей тела; доступна ручная настройка позы.

Сохраняйте структуру архива: FBX использует `native/`. Корневой launcher
использует .NET 8 Desktop Runtime x64 и предлагает установку при его отсутствии.
Изменения: [0.6.1](RELEASE_NOTES_0.6.1.md).
