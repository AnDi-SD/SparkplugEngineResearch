# SmoExporter 0.5.0

SmoExporter 0.5.0 добавляет экспорт собранных SMO-уровней и сохраняет общую
геометрию повторяемых объектов там, где это допускает целевой формат.

## Профили и режимы

GUI автоматически отличает персонажа от уровня по skin/static graph и
reference-only placements. Рядом с форматом доступен явный профиль
`Авто / Персонаж / Уровень`; автоматический анализ остаётся режимом по умолчанию
и не теряется при ручном переопределении.

Для уровня доступны:

- экспорт всех поддерживаемых ресурсов и полной сцены;
- только физическая геометрия уровня;
- уровень и предметы с полностью запечёнными копиями;
- уровень с mesh-инстансами;
- пакетный экспорт выбранных физических мешей в отдельные файлы.

## Форматы

- GLB записывает несколько nodes со ссылкой на одну запись `meshes[]`.
- FBX назначает нескольким `FbxNode` общий `FbxMesh`; отдельный baked-режим
  создаёт независимую геометрию каждого размещения.
- OBJ не имеет штатной семантики инстансов, поэтому разворачивает transforms в
  вершины и записывает предупреждение; несовместимый режим блокируется в GUI.
- Нативный FBX writer сохраняет RGBA `COLOR_0`, включая vertex alpha.
- Выбор формата отключает skeleton, service nodes, animations и другие опции,
  которые целевой контейнер не способен представить достоверно.

В контрольном `Alfea03.smo` анализ находит 510 физических мешей, 1 267
размещений и 757 ссылочных копий. Instance-GLB содержит 510 определений mesh и
1 267 mesh nodes; baked-вариант содержит независимую геометрию всех размещений.

## Проверка

- 65 format assertions на skinned-персонаже `bloom_princess.smo`;
- 16 level assertions на pristine `Alfea03.smo`;
- native FBX instance/baked regressions и проверка структуры GLB/OBJ;
- исходные SMO открываются только для чтения и не изменяются.

Камеры, lights, morph targets, неподтверждённые SAN events, MASK/alpha cutoff и
additive blending намеренно не синтезируются. Для наиболее полного сохранения
сцены и ссылок рекомендуется GLB или FBX.
