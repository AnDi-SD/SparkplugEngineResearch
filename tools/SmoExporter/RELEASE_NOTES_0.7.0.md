# SmoExporter 0.7.0

Кандидат от 2026-09-08, подготовлен локально. Публикация не выполнена.

- FBX учитывает совместное действие прозрачности текстуры и материала.
  Исправлены импорт bind hierarchy в Blender и представление alpha-текстуры.
- Общий SAN sampler сохраняет scale, поддерживает редкие scalar/cubic ключи,
  раздельные оси и корректные границы интервалов.
- Исправлены привязки повторных target names, экспорт отрицательного времени
  и выбор несовместимого SAN. Неизвестные track encodings отклоняются.
- Сохраняются режимы инстансов и запечённых размещений уровней.

Проверки включают чтение GLB/FBX и сравнение поз в Blender. Скачки анимации
на произвольных subframe-временах Blender имеют документированное ограничение;
точное непрерывное воспроизведение всех скачков не заявляется. OBJ предназначен
для статической геометрии, без skin и анимации.

Запускайте корневой `SmoExporter.Gui.exe`. Для FBX сохраняйте каталог `native/`.
Инструкция: [README](README.md).
