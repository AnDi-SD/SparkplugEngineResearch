# SmoExporter

Экспортирует поддерживаемые PC SMO в GLB, OBJ и FBX.

1. Запустите корневой `SmoExporter.Gui.exe` и выберите исходный SMO.
2. Выберите формат и ресурсы. Профиль `Авто / Персонаж / Уровень` определяет
   доступные настройки; для персонажа можно добавить подходящие SAN.
3. Для уровня выберите сохранение инстансов либо запекание размещений.
4. Сохраните экспорт в отдельный каталог и проверьте его в целевой программе.

OBJ не сохраняет skeleton или анимацию. GLB/FBX поддерживают проверенные skin
и SAN-варианты; неизвестные события, morphs и игровые эффекты исключены.

Для FBX нужен включённый в архив каталог `native/`. Сохраняйте всю структуру
архива. Launcher использует .NET 8 Desktop Runtime x64 и предлагает установку
при его отсутствии. Изменения: [0.7.0](RELEASE_NOTES_0.7.0.md).
