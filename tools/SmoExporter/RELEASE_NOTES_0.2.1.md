# SmoExporter 0.2.1

Исправляющее обновление Exporter.

- расширен автоматический поиск Blender и добавлен сохраняемый ручной путь;
- синхронизированы compact skinning, texture bindings и material data с Viewer Core;
- rigid-меши сохраняют связь с анимируемыми render nodes в GLB/FBX;
- alpha-blend материалы и двухслойные UV0/UV1 материалы экспортируются явно;
- добавлены модельные регрессии Spirit, Knut, knutBoss и BloomX.
