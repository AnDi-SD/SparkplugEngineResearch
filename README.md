## Устройство репозитория

```text
docs/           публичная база знаний: engine, game, formats, reference
Sparkplug/      восстановленный код движка и общий слой совместимости
Winx/           восстановленный игровой код
tools/          наши приложения, общие мосты и служебные инструменты
release/        сценарии упаковки программ
.private/       непубличные журналы, планы, материалы и рабочие эксперименты
local-data/     локальные игровые файлы, базы и прочие пользовательские данные
```

`.private/` и `local-data/` исключены из Git и отсутствуют в обычном клоне. Документация и сборка публичного кода не требуют закрытого архива; проверки на оригинальных ресурсах требуют своей копии игры.

SmoViewer и SMOTextureTool входят в этот репозиторий обычными каталогами. Клонируйте репозиторий целиком: приложения используют общие библиотеки из соседних каталогов. Готовые сборки находятся в [Releases](https://github.com/AnDi-SD/SparkplugEngineResearch/releases); версия рабочего дерева может быть новее опубликованной.
