# 2026-08-08 — подготовка релиза SmoViewer 0.1.0

## Состояние релиза

Первый исследовательский релиз подготовлен из отдельного репозитория
`tools/SmoViewer`. Feature-ветка переведена fast-forward в `master`; release commit:
`119d8aa` (`Release SmoViewer 0.1.0`), локальный annotated tag: `v0.1.0`.

Версия приложения задана в `SmoViewer.csproj` как `0.1.0`; добавлен `CHANGELOG.md`,
актуализирован README и перечень известных ограничений.

## Состав 0.1.0

- строгий FFPS/object-directory parser;
- PC mesh и texture layouts, UV0, material/vertex colors;
- node и static-render-object transforms;
- handedness conversion для WPF;
- Blender/fly camera;
- object tree, relation highlighting, 3D picking и focus по двойному клику;
- многострочный журнал состояния;
- corpus regression runner.

## Проверка

- `dotnet build SmoViewer.slnx -c Release --no-restore` — успешно;
- `Alfea02.smo` — 2832 assertions, PASS;
- пять выбранных level SMO проходили corpus tests на этапе реализации;
- `git diff --check` — без ошибок whitespace.

## Известные ограничения

- root-level prototype assets ещё не всегда отделяются от baked world geometry;
- не восстановлены skin/skeleton, animations и полный SPT/SPL gameplay layer;
- игровые файлы не входят в репозиторий и release archive.

GitHub Release должен публиковаться из тега `v0.1.0` с framework-dependent Windows x64
архивом. Для запуска требуется установленный .NET 8 Desktop Runtime.
