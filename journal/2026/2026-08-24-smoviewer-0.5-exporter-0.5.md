# 2026-08-24 — выпуск SmoViewer 0.5.0 и SmoExporter 0.5.0

## Цель цикла

Перейти от исправлений отдельных персонажей к достоверному просмотру и экспорту
составных уровней: восстановить serializer placements, повторяемые объекты,
текстуры, vertex diffuse и прозрачные проходы без CPU-перезапекания всей сцены.
Параллельно был начат отдельный трек 2D/GUI-ресурсов, который станет основой для
будущего `SMOlvlcreator`.

## SmoViewer 0.5.0

- основной viewport переведён на OpenGL 3.3 для rigid/skinned geometry,
  GPU palette skinning, SAN-позы, texture sequences и подтверждённых effect layers;
- исходные geometry, UV и diffuse передаются GPU напрямую; для `Alfea03.smo`
  shared placements используют общие VBO/EBO и отдельные model matrices;
- исправлены transforms partitioned-уровня, shared material references,
  повторяющиеся UV, vertex tint, alpha/depth, вертикальная ориентация текстур и
  mouse picking;
- распознаны 510 физических мешей и 757 reference-only placements `Alfea03`;
- добавлены структурный профиль 2D/GUI, выбор root screen/state/collision и
  диагностическое представление node-only `gameover.smo`;
- панель слоёв получила общий scroll и переключаемое MSAA до 8×.

Подробная история отдельных экспериментов сохранена в записях про
`igmenu_opt_pc.smo`, `gameover.smo`, transforms `Alfea02.smo` и прямой GPU-render.

## SmoExporter 0.5.0

- GUI автоматически отличает персонажа от уровня и позволяет при необходимости
  вручную выбрать профиль рядом с форматом;
- добавлены экспорт всей сцены, физического уровня, baked-объектов, настоящих
  mesh-инстансов и выбранных мешей в отдельные файлы;
- GLB хранит несколько nodes с общей записью mesh, FBX — несколько `FbxNode` с
  общим `FbxMesh`; OBJ честно разворачивает копии и предупреждает об ограничении;
- формат отключает несовместимые параметры, а CLI получил эквивалентные флаги;
- нативный FBX payload/version обновлён для placements и RGBA vertex colors.

Контрольный `Alfea03.smo` даёт 510 физических мешей, 1 267 размещений и 757
ссылочных копий. Instance- и baked-структуры проверяются отдельно.

## Проверка

- Release-сборки Viewer, Exporter и их core/test-проектов завершены без
  предупреждений и ошибок;
- Viewer FormatTests прошли на `igmenu_opt_pc.smo`, `gameover.smo`,
  `Alfea01.smo`, `Alfea02.smo`, `Alfea03.smo`, `Alfea_broken_01.smo` и
  `bloom_princess.smo`; в частности, 2 310 assertions для меню, 4 660 для
  `Alfea01` и 464 для princess fixture;
- Exporter: 65 assertions на `bloom_princess.smo` и 16 level assertions на
  `Alfea03.smo`, включая GLB/FBX instance/baked и OBJ expansion;
- единый упаковщик повторно собрал native FBX bridge, проверил release layout и
  отсутствие дублирующихся файлов;
- оба `release.json` и Windows file metadata содержат версию `0.5.0`.
