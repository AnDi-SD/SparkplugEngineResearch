# 2026-09-08 — Viewer 0.7.0 и классы Sparkplug

После закрытого цикла CP137 пользователь попросил переработать ядро просмотра:
предпочесть прямое использование Sparkplug, C# переносить только при необходимости.
Интерфейс отложен.

Подключён существующий C++ `SparkplugEngine` через x64 DLL и P/Invoke. Реальный
обработчик Viewer использует serializer/animation, transform evaluator/controller,
node world update и skin palette. C# остаётся адаптером SMO и отображения.

Первое независимое сравнение Icy выявило ошибку старого reference и неточность
восстановленного SLERP. Ограниченный probe оригинальных PC инструкций установил
конкретный x87 порядок округлений. После исправления все 64 трека контрольного
момента совпали точно. Отрицательные прогоны сохранены локально; допуски не расширены.

Проверены C++ suites, владение/буферы interop, выбранные модели и реальные GUI
обработчики с независимой геометрией. Сборщик выпуска теперь учитывает обязательную
DLL, проверяет её при повторном использовании. Локальный пакет и suite handoff прошли.
Ninja исправлен для локализованного compiler include-prefix, чтобы заголовки
действительно вызывали пересборку.

[Досье и границы переноса](../../docs/research/tool-viewer-sparkplug-core-2026-09-08.md).
