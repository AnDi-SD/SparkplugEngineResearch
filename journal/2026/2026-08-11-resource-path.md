# 2026-08-11 — MediaPath и глобальный корень ресурсов

## Вопрос

Почему несколько независимых установок Winx Club PC загружают ресурсы из одной папки и как executable строит абсолютные пути?

## Корпус

Локальный отчёт `WinxClub_Resource_Path_MediaPath_Research.txt` и исследованная PE32-сборка `WinxClub.exe` размером 22 065 152 байта. Игровые файлы и полный дизассемблерный листинг остаются в игнорируемом `local-data/`.

## Наблюдение

- функция `0x00592F70` читает `MediaPath` из `HKLM\Software\Konami\Winx Club` и сохраняет его в resource manager;
- при отсутствии значения найденная ветка завершает запуск без fallback к каталогу EXE;
- из того же ключа читается `LanguageID`;
- функция `0x00592C50` строит путь как `MediaPath + каталог типа + подкаталог + язык + имя`;
- вызов для `bloom_hair.smo` с индексами `2` и `1` даёт `MediaPath + Characters\ + Bloom\ + bloom_hair.smo`;
- между `MediaPath` и первым каталогом разделитель не вставляется, поэтому registry value должен завершаться `\`.

## Вывод

Корень ресурсов глобален для всех копий игры, потому что зависит от общего registry key, а не от расположения конкретного `WinxClub.exe`. Подтверждённый итог перенесён в [`docs/engine/resource-loading.md`](../../docs/engine/resource-loading.md).

## Что не подтверждено

Не установлено, перечитывается ли `MediaPath` после начальной инициализации, существует ли скрытый override и каково назначение всех элементов второй таблицы каталогов.

## Следующий эксперимент

Трассировать обращения к registry после запуска и проверить две параллельные копии игры с переключением `MediaPath` между стартами.
