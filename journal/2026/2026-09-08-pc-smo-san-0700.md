### CP101 — план нового whole-file execution profile

После CP100 вводится отдельный профиль `file`: 1 млн инструкций / 8 секунд на
вызов, внешний процесс 30 секунд, heap в первом опыте 128 КиБ. Причина:
исторический `gameover.smo` останавливался точно на 100 000 инструкций при третьей
Node factory; два объекта укладывались примерно в 90 000. Лимит не доказывает
ошибку данных. Первым представителем выбран целый `bflower.san` через оригинальный
`422B50`, затем решение по фактическому результату. Старые micro probes остаются
отключёнными; сохранённый stopped guest не используется. Новых seams не
планируется. Перед опытом проверяются оба профиля и прежние ограничения памяти,
инструкций и доступа к ОС.

Результат: [6 whole-file сравнений прошли](../../docs/research/native-pc-whole-file-profile.md).
`bflower/barrel/bw` потребовали 112–134 тысячи инструкций; исходный C++ `barrel`
принят оригиналом. Целые `object.smo` / `gameover.smo`: 109 653 / 234 449 инструкций,
точные 2 / 6 Node records. Всего 221 native assertion, 3479 SAN значений,
8 Node records, все allocations освобождены. Предыдущий лимит действительно
мешал этой выборке; native поведения не подменялись. Проверяющий код исправлен
для float-типов JSON без изменения допуска. Class score пока не изменён.

### CP102 — startup, локализация следующих ограничений

Fresh manager factory `422F40` в file-профиле остановилась на 1 млн инструкций
в `888D5D`, успев выделить manager44, list24 и FAT88. Предел не повышается.
Fresh Animation initializer `6D1C10` прошёл native RTTI manager construction,
но запросил allocation `0xE000` (57 344 байта) через `470EF2`; старый предел
одного выделения 32 КиБ остановил опыт на 8319 инструкциях. Диагностический
запуск подтвердил конкретный размер и caller. Для отдельной новой startup-пробы
выбран предел одного allocation 64 КиБ при общей arena 128 КиБ; micro default
32 КиБ сохраняется. Это новый явно заданный профиль памяти, исходные stops
сохраняются локально. Проверка результата продолжается.

Новый startup-профиль принял запрос 57 344 байта, но затем остановился на
1 млн инструкций в `88C14E`; arena занята 57 440 байт. Полный startup остаётся
неподтверждённым. Увеличение execution budget не продолжается. Сохранены локальные
`startup-manager.json`, `startup-rtti-diagnostic.txt`, `startup-rtti.json`;
последний относится к 64-КиБ allocation profile. Это локализация ограничений,
без успешных native cases и без повышения score. Следующий участок — целый
SMO с мешами, используя уже проверенные hook/mesh/graph adapters.
